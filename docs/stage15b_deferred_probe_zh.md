# 15B事后工程探针：停止层不再计算局部细化指标

日期：2026-11-20。本探针由已完成的288条正式路径启发，属于**事后开发优化**，不是新的独立确认集；不得替换、修改或合并原正式门槛。

发现：原DWR循环每层同时计算全局目标误差估计和体/面局部化，随后才判断停止。在已经通过全局核验的最后一层，局部指标不再用于任何细化。此项成本可以由常规程序顺序调整消除，与AI无关。

仅修改执行顺序：先计算含代数项的全局估计，执行与原版相同的线性、容限和资源验收；仅在仍需标记时计算强式局部化。缓存当前富集伴随缺陷，不重复求解主/对偶或完整全局估计。方程、求积、标记公式、θ、τ和停止安全系数均不变。实现存于新文件，原源码继续冻结。

使用原六材料、两容限及相同初始网格/资源配置；每组合同时重跑原版、新版各3次，共72条路径。每组按重复编号和组合编号交替旧/新顺序；两版固定小规模预热，费用单列。禁止把不同批次的原正式时间直接当作本次对照。

每个旧/新配对必须具有相同状态序列、目标值、选择单元、网格及最终解哈希；数值容许目标差不超过1e−12的浮点尺度，同时记录实际最大差。若不同，优化失败，保留全部记录，不宣称同一算法提速。离线精度继续用原冻结参考验收。

效率仅报告每组合三次配对时间比的中位、范围及其明细；不设临时统计显著性门槛，不将六固定材料称独立随机总体。计时包括相同在线操作与记录准备，排除离线参考及输出写盘；新局部化费用单列。所有可省工作只归于经典工程优化。

交付新源码/测试、配置与源码哈希、72条原始路径、逐对等价检查和报告。原288路径完整保留。若优化有效，后续学习对照必须使用优化后的经典方法；若算法本身已在毫秒级完成，则下一步首先核算绝对可节省时间和推理/核验成本，不扩大网络。
