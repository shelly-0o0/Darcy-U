# 第八阶段结论：保留机制信息，停止当前路线的扩展

日期：2026-11-19。**本轮已完成最后一次预算诊断；按照运行前规则停止独立确认和学习训练，将研究投入转到新问题的有限筛查。** 停止是对当前问题族和研究预算的决定，不是证明学习辅助PDE求解没有价值。

## 1. 实际执行与成本边界

本轮没有训练或调用AI。固定五种方法：SciPy AMG-PCG加历史四解、事件自实现PCG对照、首步冻结4维空间全步使用、当前系统4维参考、当前系统8维参考。参考方向由同一当前系统已经完成的基础PCG轨迹提取；直接参考解仅参与质量诊断，未作为方向输入或生成轨迹的历史解。

当前参考不是可在线部署的算法。两个网格的方向全部预先生成、存储并加载到内存后才开始计时；参考路径计入矩阵组装、历史初值、AMG、正交化、初值投影、平衡算子构造和每次应用、PCG、真残差与维护，但排除方向获取和磁盘加载。已有方向常驻内存的条件不能省略。

完成98项单元测试、100次小网格功能求解；正式开发为128网格三个新几何、256网格复用其中两个，每法重复三次、每序列20步，共75条完整序列、1,500次路径求解。独立开发几何总数是三个，不能把重复计时或跨网格复用算作新独立样本。其中900次为因果对照路径，600次为事后参考路径。全部达到 `1e-8` 最终相对真残差，最大 `9.988265e-9`；无PCG失败、直接恢复或最终精度失败。

另有100次基础PCG参考生成和100次直接参考求解，不能并入在线性能样本。100个系统上的两种参考实际秩均符合4/8维要求；10次预定缓存检查通过。小网格功能检查曾出现8维请求只能得到4维的情况，该失败被保留并触发不合格判定，没有静默降秩。

## 2. 有正向机制信息，但未通过预定投入门槛

下表先对完整20步求和，再取同几何三次重复中位，最后计算逐几何时间比并汇总。比值小于1表示本次测量更快；参考路径不含方向获取。

| 方法 | 128网格配对时间比中位数 | 256网格配对时间比中位数 |
|---|---:|---:|
| 事件自实现PCG / SciPy | 1.008095 | 1.000601 |
| 首步冻结4维 / SciPy | 1.031959 | 1.065588 |
| 当前4维参考 / SciPy | **0.785472** | **0.782694** |
| 当前8维参考 / SciPy | 0.820643 | 0.855451 |

4维当前参考减少约20%–22%的路径时间，说明适配当前系统的方向确实可能有价值。基线迭代的序列中位数为530/662，4维参考降为307/367.5；8维参考进一步降为279/335，但路径时间更长。更多方向和更少迭代都不能替代完整成本指标。

运行前固定的继续条件是：同一个维数在两个网格全部开发几何中，时间比均不超过0.8；只有通过才允许一次独立确认。4维的五个网格–几何比值为 `0.800845, 0.785472, 0.784810, 0.780050, 0.785337`，4/5过线；8维0/5过线。因此没有预选维数，也没有执行确认或训练。没有通过改变阈值、增加维数或重跑不利几何来改变结论。

**4维失败是边界性的。** 128网格第一个几何仅比0.8高0.000845，按20步计差0.461毫秒。这不是统计显著性结论，不能据此声称“完全没有正向信息”。停止的原因是工程门槛未通过、实际方向预测成本尚未实现且预算紧、此前多轮完整收益不足，而不是断言这0.461毫秒是稳定的物理障碍。

定义尚可用于实际方向预测/构造的增量预算为 `0.8 × 基线完整时间 − 参考路径时间`。参考路径已经支付的正交化、投影和应用不再重复扣除。

共同参考获取费用为128网格4.500秒、256网格17.142秒，包含基础PCG与两种维数、首步冻结空间的提取；不是单个维数的独立获取费用。另付直接解2.182/10.720秒、质量核验1.301/3.789秒、存储0.112/0.301秒，全阶段统一加载0.406秒。全部保留，不能将参考路径改善表述为支付这些费用后已经获得加速。

## 3. 参考质量限制了可以得出的结论

在共同基础历史初值上，4维参考一次投影后的剩余误差能量比为0.990455/0.995884，首步冻结4维为0.961218/0.943124；8维当前参考为0.835726/0.892457。口径为每几何20系统中位后再取几何中位。当前4维参考并没有在总能量去除上优于冻结空间，但其后续平衡求解明显减少迭代，进一步说明总误差能量不是可靠的求解成本替代指标。

这里没有使用完整谱分解，也没有证明提取到精确最慢空间。有限右端轨迹只探索其激发的子空间；实际A/M作用下的特征残差按协议记录为描述量，没有事后增加质量阈值来筛掉样本。结构、正交性和真残差检查通过，并不让该参考变成“所有方法的最优上界”。故本轮能支持停止当前投入，不能否定所有空间构造、所有问题分布或所有学习预条件器。

## 4. 失败复盘和项目决定

前七阶段的完整证据与限制见[路线复盘](route_retrospective_zh.md)。主要原因是：最初学习对象的成本份额不足；训练目标与关键收敛分量、完整时间不一致；方向构造和每次应用的额外费用抵消迭代收益；强AMG与历史初值已经有效。现有结果不能唯一归因为网络容量或训练数据不足，因此不继续追加网络宽度、损失分支和训练种子。

当前Darcy问题族上的学习低秩加速扩展到此归档。保留全部原始数据、冻结代码、权重和经典工程收益；不把失败写成成功，也不把事后参考写成AI实测。只有将来出现独立的新证据或实质不同的成本结构，才另立新协议考虑重启。

## 5. 转向的明确问题与AI算法

**进入有限筛查的候选是：非线性PDE内层求解精度的动作条件成本学习。** 对单位正方形上的

\[
-\varepsilon\Delta u+\boldsymbol\beta\cdot\nabla u+u+\gamma u^3=f,
\qquad u|_{\partial\Omega}=0,\quad \gamma\ge0,
\]

固定离散、Newton线搜索、线性求解器和最终真残差。研究问题是：只使用当前迭代已有信息，预测不同内层容差的后续成本，能否在未见参数和更细网格上，包含推理与回退后超过强经典容差规则？

最小算法为两个64宽隐藏层的MLP，输入已有残差历史、线搜索信息、内层迭代量、无量纲参数和候选容差倍率，输出该动作的预计剩余成本。倍率先考虑经典Eisenstat–Walker容差的 `{1/4, 1/2, 1, 2, 4}`；从训练状态分支执行一个动作，再用固定EW策略继续至收敛以产生标签。模型估计的是固定续接策略下的动作成本，不是最优价值。数值残差检查和线搜索继续由经典算法执行。

这与当前低秩研究改变了优化对象：调整非线性求解中线性问题所花的精度预算，而不再预测高维空间。但**“学习容差”已有2020年的直接论文，当前新颖性尚未成立**。[Oladokun等出版社摘要](https://www.earthdoc.org/content/papers/10.3997/2214-4609.202035089)、[Eisenstat–Walker原论文](https://users.wpi.edu/~walker/Papers/forcing_terms%2CSISC_17%2C1996%2C16-32.pdf)。本轮只读到2020论文的公开摘要，未取得付费全文，不能凭摘要缺少某细节便宣布创新。

下一阶段先做经典基线与有限分支机会筛查，再决定是否训练；同时核对直接近邻。预备两周计划设置独立的性能和新颖性停止线：没有可区分的成本机会就不训练；闭环净收益或实质文献差异不足就关闭该题。树模型、直接容差回归和调优经典控制器必须保留。详细动作、标签、分组、成本、精度和停止条件见[转向调研与实验计划](stage8_pivot_literature_zh.md)。新方案尚未实现或获得正面结果；15%等候选门槛需在该阶段执行前正式冻结。
