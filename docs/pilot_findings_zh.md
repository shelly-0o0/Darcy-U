# 首轮实验结论与下一步研究判断

本文件解读 `results/pilot_cpu/` 的实际结果。方案的核心代码和模型在测试前固定，本轮没有依据测试表现调参。测试只覆盖三个独立合成几何，不能声称统计显著性或一般化性能。

## 可以确认的结果

1. 本机 CPU 上完成了 63 次完整序列运行、1,260 次线性求解。最大最终相对真残差为约 `9.984e-9`，满足 `1e-8` 要求；没有触发直接求解恢复。相对稀疏直接参考解的最大能量误差约为 `6.849e-11`。这些是离散系统的求解精度，不是连续 PDE 的网格离散误差。
2. 三个模型的平均子空间覆盖验证损失相对不新增方向降低约 91.8%–93.8%。因此网络学到了标签里的部分缺失方向。
3. U-Net 候选在全部计时运行中通过 9/36 次检查，平滑候选为 0/12。前者包含三个模型和重复计时，后者不含模型种子，不能把这些计数视作同等数量的独立几何样本，更不能据此建立置信区间。
4. 整条序列时间中位数为：AMG 0.767 秒、全谱重建 15.924 秒、谱复用 9.295 秒、平滑增量 9.295 秒、U-Net 增量 9.364 秒。计时包含初始构造、矩阵组装、网络、接纳检查、谱修复、预条件器设置和 PCG。

进一步按“几何—时刻—局部块”去重，36 次网络检查实际上只涉及 4 个不同案例，均在第 15 步堵塞事件触发。其中一个案例在三个模型及全部重复中通过，另外三个全部失败。故 25% 是 1/4 个局部案例的描述，不能被包装成有 36 个独立样本支持的可靠接纳率。

## 目前不能成立的论文主张

**尚未证明 AI 比有效传统方法更快。** U-Net 与谱复用/平滑增量的差距很小且没有稳定的耗时优势；AMG 在本次问题上明显更快。U-Net 相对每步全谱重建的配对时间比约为 1.70，但传统复用本身已实现相近节省，把这部分全部算作 AI 收益不成立。

**学习损失不是接纳条件。** 完整矩阵条件约束所有方向，高对比下的很低能量方向尤其敏感。平均覆盖损失小，并不能保证最坏方向满足阈值；数学反例见 [局部分析](local_analysis_zh.md)。本轮网络有一定接纳成功率，但这没有抵消其他成本。

**三个几何不足以判断投稿价值。** 本轮只用于检验实现和识别瓶颈，没有完成最近邻学习算法复现、充分基线调优、不同右端、对比度外推或全局鲁棒性理论。

## 建议下一轮先回答的问题

按以下顺序推进，并先使用训练/验证集合；下一轮正式测试应使用新的未见几何。

1. 用当前时间分解判断哪部分占主要成本，优先降低全局预条件应用和重复局部组装成本。即使候选生成完全免费，是否存在超过 AMG 或强传统复用方法的空间，应先计算成本上限。
2. 在验证集上比较平均覆盖损失与面向低能量最坏方向的损失。增加目标模式的能量权重、困难失败样本和已学习空间的滚动训练都是可检验方向；这些仍是研究假设，不是已实现的改进。
3. 共享完全相同的检查与回退机制，比较网络、平滑误差、直接谱更新及谱回收，并记录每条序列的候选调用次数。当前候选调用稀少时，网络潜在收益本来就受到限制。
4. 只有验证阶段显示可重复的端到端收益后，再扩大到至少数十条独立测试几何、多个对比度与网格，并复现最近邻学习方法。保持同样真残差标准，保留全部失败。

本轮代码、权重和负结果均保留。当前更合理的论文定位是继续验证“旧空间条件下的增量方向能否带来独立收益”，而不是把已完成的预实验包装成成功的 AI 加速论文。
