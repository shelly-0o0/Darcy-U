# 第十五阶段C：新几何的经典方法确认与分支停止协议

## 1. 固定问题与新几何

保持15B方程、源、单目标、齐次边界和两个绝对容限τ={1e−3,3e−4}。源中心(.25,.5)，观测中心(.75,.5)，半径.18，均单位积分。初始P1 n=8。只改变材料几何；不将同时改变目标、源和材料的效果混在一起。仍为材料对齐二维开发范围，不代表任意几何或应用分布。

生成器`stage15c_cases.py`使用种子1520261123+材料族编号，每族从明确有限池中无放回选六个不同几何，共24个。按抽取序号交替赋予对比度10、1000，每族各三例。分层：七条八分位线中选三条，交替高低渗透；屏障：纵向低渗条带，宽1/8或2/8；通道：横向高渗条带，宽1/8、2/8或3/8；包含体：内部矩形，横宽1/8至3/8、纵宽1/8至4/8。界面只取1/8至7/8，剔除15B对应几何（无论其对比度）。抽样不读取解、指标或速度。

生成的几何坐标及材料参数写入冻结文件。24个几何是分析单位；两个容限和三次计时均为重复测量。有限池分层无放回抽样不是任意材料的独立同分布样本；本轮不声称总体显著性。

## 2. 数值与运行预算

参考层级、求积、稳定性阈值及交叉核验完全继承15B：P2 n=32/64/128/256，10阶；最细18阶；P1 n=512交叉。相邻级差、求积差、交叉差分别≤0.05、0.01、0.1倍最小τ；差序列不显著反号、绝对值不增长超过10%和舍入余量。参考失败保留，继续记录在线路径但不批准同精度优势，不临时加密。

在线最多13个状态，P1自由度70000，每路径60秒软上限，θ=.5、核验安全系数.5。除DWR每层核验，其余自适应在第0层、层号3的倍数、或相邻目标变化≤.5τ时付费求P2伴随核验。只有真实线性验收通过且含代数项的全局估计≤.5τ才可停止；参考仅用于退出后q验收。经验核验不是连续误差证书。

24几何×2容限×9方法×3重复=1296条路径；同一组内轮换方法顺序、单线程BLAS。整体运行软上限90分钟，仅在单路径/单参考之间检查，达到则保存部分数据并以未完成结束，不删失败或重启替换。新增正式求解最多一批，训练预算为零。

## 3. 九方法及新增廉价伴随恢复

沿用统一细化direct/AMG、系数、主残差、联合残差、优化DWR与固定P1 n=256 direct。固定细解仅作为预定分辨率参照，精度不足记失败；本轮不重复15B已经较慢的固定AMG路径。所有自适应共享相同核验实现，并在停止后不再计算无用的标记指标。

另加`recovered_dwr3`、`recovered_dwr8`：P1主问题与伴随共用分解求两个右端，提升P1伴随到当前P2空间，以固定ω=2/3做3或8步Jacobi，边界保持零：

`z^(m+1)_I = z^m_I + (2/3) diag(A2_II)^(-1) (g2_I − A2_II z^m_I)`。

用恢复向量减去其P1节点插值构造缺陷，再使用相同强式体/面分解形成局部绝对分数。恢复仅用于标记，不能依据其残差或全局值决定成功。若当前层已按计划支付P2精确伴随核验，继续层的标记仍用恢复向量，不临时换成精确指标；P2装配在该层复用一次。固定3/8步是事前对照，不根据本轮结果挑迭代次数。

这属于代数伴随恢复/平滑对照，不冒称Zienkiewicz–Zhu补丁恢复，不是新的AI方法。松弛的平滑角色可参照[PyAMG官方文档](https://pyamg.readthedocs.io/en/latest/generated/pyamg.relaxation.html)；固定阻尼和步数不保证高对比材料下的恢复质量，也不提供严格误差上界。主/对偶残差框架参照[FPZ作者原文](https://arxiv.org/abs/1505.04536)，不自动继承其定理假设。

P2装配、粗伴随、全部固定迭代、局部化和付费核验均计入在线成本。恢复步骤不是已收敛线性求解器调用，其次数和矩阵向量乘单列。离线参考、写盘另计；包括算法记录准备和哈希费用。失败、超限、零指标、异常和q>1全部保留。

## 4. 运行前确定的有限投入判据

先按几何/容限/方法汇总三次耗时中位、范围、q、自由度、失败和成本。对照集合为八种非DWR方法，包括两种恢复和预定细解。逐设置事后最快成功对照仅是一个严格的研究筛查参照，不能当作在线可部署选择器。

为避免从两个容限中只挑有利结果，**几何必须在两个容限都满足条件，才计一次通过**。同一材料族至少4/6几何通过，才保留该材料族进行下一次最小学习可行性设计。条件如下：

1. **数值资格：**该几何参考合格，DWR及全部八对照的三次运行均成功。任何方法失败，本几何不批准（仍报告成功子集辅助数据及失败原因）。
2. **成本必要条件：**优化DWR中继续细化层的P2装配、伴随、全局估计和局部化占总时间的三次比例中位≥30%；在假设轨迹不变、这些中间项免费且最终核验保留时，剩余时间的三次中位≤最快对照中位的0.80。
3. **付费目标信息条件：**DWR完整时间中位≤最快对照的0.90，或者DWR最终P1自由度≤该最快对照最终P1自由度的0.75。第二项只支持网格选择的信息价值，不意味着DWR已更快，也不能单独批准学习。

上述30%、20%、10%、25%和4/6为项目投入筛查标准，不是定理、显著性检验或发表标准。达到条件最多允许限定材料族的小模型可行性设计；G3学习优势完全未测。没有材料族通过则停止当前“替代中间目标估计”AI主线，不增加数据/模型规模来追逐结果。若参考或停止问题主导失败，先形成数值失败报告，不以训练掩盖。

该成本情景从完成后的轨迹识别哪些是中间层，实际算法不能免费预知最后一层；尚未加入模型特征、推理、核验触发、回退和不同轨迹的成本。因此通过筛查也不是G1完整批准、实测AI净收益或新颖性证明。平衡通量与数据振荡、高对比认证、一般未对齐材料、多目标循环算法仍在当前宣称范围之外。
