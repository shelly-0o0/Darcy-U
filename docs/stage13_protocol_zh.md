# 第十三阶段运行前协议：去除全局 Schur 后的在线成本可行性

本文件与运行器、代理分数公式和数值实现须在正式结果产生前核对并写入冻结清单。冻结后不得按正式结果更换方法、特征、求解容差、预算、门槛或样本。烟雾实验只用于程序正确性和可承受的运行规模检查；发生错误须保留失败目录和记录，修正后用新目录运行。

## 1. 问题与结论边界

第十二阶段的联合细化动作出现了同自由度准确性空间，但完整搜索约为一次直接细解的两个数量级。即使从账面删除整段搜索，保留全局 Schur 设置的路径仍慢于直接细解。本阶段检验一个更基础的问题：**仅使用廉价确定性网格提议，不构造全局 Schur、不运行联合候选搜索，并直接装配约束适应有限元系统后，完整在线成本是否低到足以继续研究学习网格提议？**

本阶段不训练、不加载或调整 AI 权重，不使用参考细解指导网格选择。廉价代理的准确性全部报告，但没有假设它们能保留第十二阶段动作搜索的准确性。成本门槛只决定当前流程是否存在继续开发的时间空间，不能证明未来神经网络可在该时间内运行，也不能证明同等误差下的求解加速。

## 2. PDE、样本、尺度与预算

沿用二维零 Dirichlet Darcy 方程、SW→NE P1 三角形、历史系数生成函数、四个载荷和细积分规则。第 0 个载荷为源项，第 1、2、3 个载荷为线性目标；一次主问题求解同时产生三个目标。目标不是三个独立样本。

正式样本为全新的 32 个独立几何：ID 54000–54015，高对比 54100–54115。ID 对比度仍从 5/20 取值，高对比从 100/1000 取值。每个几何同时使用 `nc=16,32,64`，对应指定细参考 `nf=2*nc`。因此有 96 个几何/网格上下文，但只有 32 个独立几何，不把尺度重复或计时重复扩大为独立样本量。系数和载荷只随其既定生成规则与采样尺度变化，不为不同方法重新生成不同物理输入。

检查新几何与历史训练、验证、测试的身份及可比较采样上的系数哈希，不允许非预期重叠。若出现冲突则停止，不在看到结果后换几何。历史阶段一至十二的代码、协议、模型与正式结果保持不变。

所有局部细化方法的新增独立自由度预算固定为 `B=nc*nc/4`：三个尺度分别为 64、256、1024；适应自由度分别为 289、1217、4993。细直接及 AMG-PCG 参照的自由度分别为 961、3969、16129，不匹配适应预算。选中粗方格增加一个中心自由度，每对相邻选中方格释放一个共享内部边中点；边界为零，其他非一致接口中点施加悬挂约束。预算计实际独立自由度，不计选中方格数。

## 3. 直接局部装配及同网格一致性

新装配器直接积累混合粗细三角形上的约束矩阵与四个载荷，不先装配完整 `Af` 再求 `T.T @ Af @ T`。它仍须使用与指定细参考完全一致的系数和积分；未细化粗三角形内的细积分子片不能被一个重新采样的粗系数替代。全域系数采样和所需细求积仍收费，不能称该路径完全消除了细尺度工作。

对于任意选中集合，直接装配的系统须与历史路径 `T.T @ Af @ T`、`T.T @ loads.T` 在同一独立节点顺序下相等至数值容差。独立数值测试覆盖空集合、全部细化、单格、相邻块、边界、悬挂约束、高对比、正负载荷和预算终端集合。正式实验对同网格控制逐几何检查选中方格、实际预算、目标值和解的一致性；将数值误差与装配成本差异分开。

在线交付物为三个目标值及适应空间系数；直接路径只在在线求解结束之后，为离线评价构造其在细网格上的表示或参考对象。同网格 Galerkin 控制的细场提升和能量评价同样在计时外，不给一条路径额外收费。若直接装配本身确需稀疏约束结构，该构造收费；Galerkin 路径实际求解所需的 T 及转换也收费，不得把实际求解所需的工作挪到评价之外。两条路径均在在线计时内计算所求系统的实际线性残差；适应方程的残差不是全域细方程的残差。

## 4. 固定方法与网格提议

方法固定为以下六种。不能在正式结果产生后选择更有利的主候选。

1. `fine_direct`：细算子和四个载荷完整装配，稀疏直接分解后只求一次主问题并评价三个目标；没有不必要的粗层或三个伴随分解。细矩阵使用 `_full_cell_matrix`，四载荷使用与直接局部路径相同的 `prepare_loads` 内核，完整支付一次公共求积点构造和四个函数评价，取其细自由节点载荷。不能让局部方法独享公共求积点复用或向量化积累的通用优化而让强基线重复计算。
2. `fine_amg_pcg`：采用与 `fine_direct` 相同的 `_full_cell_matrix` 和新 `prepare_loads` 四载荷内核，固定对称 AMG V-cycle 预条件器和 PCG 求一次主问题；完整支付 AMG 设置、全部迭代、真实残差更新与必要重启以及目标评价。沿用 `FixedAMGHierarchy` 的对称配置，层级种子固定51700。使用 `numerics.solve_pcg`，`rtol=1e-10, maxiter=1000, max_restarts=3`，沿用该函数已经冻结的实际残差刷新和停止定义。本方法不得免费使用参考直接分解或其他方法的层级。
3. `jacobi8`：沿用第十一阶段的八步阻尼 Jacobi、Q 投影、三目标归一化指标及预算排序。完整计入全域细装配、粗主/伴随求解、残差、指标、约束空间及适应求解，作为既有实现的准确性和成本参照。该历史实现连同其原载荷内核保持不变，所以它与新路径的成本差同时包含通用实现差别；不得单凭此对比归因于新的网格提议或局部装配。成本门槛以已统一载荷内核的两个细求解基线为准。
4. `coefficient_local`：只用给定系数的局部跳跃/变化统计产生单元分数，经固定预算解码后，使用直接局部装配并求一次适应主问题。对粗格 C 对应的2×2细系数，记 `m_C=mean(log(k))`、`v_C=std(log(k))`，标准差为总体标准差；分数固定为 `v_C + sum_{D in N(C)} abs(m_C-m_D)`，N 为上下左右有效邻格。边界缺失邻居贡献0。它不求粗解或读取精确误差，不在正式测试选择特征或调节权重。
5. **`coarse_goal_local`：成本门槛的唯一主候选。** 直接装配粗系统，复用一次粗分解求一个主问题和三个粗伴随。每粗格 C 的两个 P1 三角形 t 上，计算主解与三个伴随的梯度模长，分数固定为 `h² * mean_C(k) * (1+std_C(log(k))) * mean_{t in C}(norm(grad(u_c)|t) * sum_j(norm(grad(z_c,j)|t)/s_j))`，其中 `h=1/nc`，`mean_C(k)` 为2×2细系数的算术均值，`s_j=max(abs(J_j(u_c)),1e-12*max_l(abs(J_l(u_c))),1e-30)`。经相同预算解码后直接局部装配并求一次适应主问题。首次粗装配已支付的四载荷求积数据可在同一次 pipeline 的适应装配复用；该复用两种装配后端一致。代理使用梯度模长，既不是精确 Schur 目标变化，也没有第十二阶段的符号耦合搜索保证。
6. `coarse_goal_galerkin`：唯一同网格实现控制，使用与 `coarse_goal_local` 完全相同的提议信息、分数和预算解码，最终改为完整 `Af` 及 `T.T @ Af @ T` 路径。每次从新输入独立重算选择，不能由直接路径免费提供选中集合。该控制只改变最终装配后端，不重复无用的粗装配或已经支付且可共享的载荷准备；实际需要的细矩阵、T 和转换全部收费。两条路径的分阶段差仅用于解释装配实现成本；完整时间仍包含各自所有实际工作。

所有提议使用历史 `budget_mark`：按分数降序、同分按较小方格索引排序，每次支付一个中心及与已选邻格相连的共享边；预算不能超支。若贪心不能用完预算，使用已冻结的两个棋盘子集完成规则并记录回退。预算精确是必要核验；回退不隐去、不改变样本，也不能把成本门槛改写成准确性声明。相同分数与确定性规则应在全部重复中产生相同网格。

## 5. 数值准确性、评价与强基线

独立评价对每个上下文计算细直接参考和一致的粗解。三个尺度各有自己的指定细离散参考，不能把不同尺度的相对误差当作相对于同一个连续真解。

沿用尺度 `s_j=max(abs(J_j(u_c)), 1e-12*max_l(abs(J_l(u_c))), 1e-30)`，报告三个带符号目标误差、缩放绝对误差范数以及

`E = norm((J(u_f)-J(u_ad))/s) / norm((J(u_f)-J(u_c))/s)`。

粗解为 `E=1`，细直接参考为 `E=0`。如粗误差分母小于 `1e-12`，保留原始值和退化标记，相对比记为 null，整个通过门槛不通过，不删除或替换样本。报告能量误差相对粗解的比、预算、选中集合、回退、求解残差、迭代次数及空间标识。

每次主问题和必要粗求解均须有限且残差合格。适应方程相对二范数残差 ≤`1e-8`，细直接参考残差 ≤`1e-8`；四个粗右端分别计算相对二范数残差，并检查其最大值 ≤`1e-8`。PCG 另外要求 `info==0`、`solve_pcg` 的 `converged` 为真，因而其实际细方程残差应达到预定 `rtol=1e-10`，不能只信库的退出标志。报告 PCG 相对细直接的目标偏差与能量偏差，不能简单把迭代细解的误差写成 0。由于一般欧氏残差本身不是目标误差证书，每次 PCG 重复的 `E` 还必须 ≤`1e-5`，即它的缩放目标偏差相对粗解误差足够小；这些条件纳入逐重复数值有效性记录。任何 PCG 失败完整保留，并使成本通过门槛不通过，不能把一次失败的快速返回当作有效基线。

所有适应空间包含粗空间，因此能量误差平方相对粗解 ≤`1+1e-8`。在线粗目标与独立参考粗目标的差，按三个目标尺度归一化后的二范数须 ≤`1e-8`。同网格控制的选中集合、预算、独立节点对应关系必须一致；在细网格表示上的解差二范数除以 Galerkin 解二范数须 ≤`1e-8`，两者目标差按三个目标尺度归一化后的二范数须 ≤`1e-8`。任一数值失败都完整记录，不能把失败基线的耗时或未收敛结果当作主候选获胜的依据。

廉价分数若误差不降或比 `jacobi8` 更差，仍保留全部几何。它们的当前准确性不能代表未来学习器能够达到的准确性，也不能传承第十二阶段 oracle 的结果。固定预算误差、完整耗时和数值一致性各自报告。

## 6. 计时与预定继续门槛

CPU、BLAS、PyTorch 固定一个线程；记录软件、硬件、线程池和环境。每个方法/上下文从全新对象开始计时三次，共576条方法/上下文记录、1728次完整路径计时。不跨方法、重复或几何共享已装配矩阵、分解、AMG 层级、提议、积分缓存或求解结果。计时包括几何采样、积分/装配、必要粗解、特征、分数、解码、约束空间、适应装配/分解/主解和三个目标评价。离线参考、报告、序列化分开计时。

对每个上下文，以 `54991+geometry+nc` 初始化方法顺序随机流，依次生成三次方法排列；方法内算法随机种子固定，防止顺序随机化改变数学结果。预热几何固定 54950，正式所用各尺度与各方法执行一次，预热时间单列。烟雾检查用 ID 54970、高对比 54980、`nc=8`、预算16、每方法一次，不进入正式统计。

三次重复的选中方格须完全相同，目标值满足 `rtol=1e-12, atol=1e-15` 的一致性检查；重复不一致则停止并保留失败记录，不用选择较有利的一次来完成统计。

先取每个方法/几何/尺度三次完整时间的中位数，再与同一几何同一尺度的基线取配对比；最后在 ID 与高对比组内各取跨几何中位数。不能用两个不配对的跨几何中位数相除。报告三个尺度、全部方法、重复的范围及配对分布；三次重复仅描述本机当前暖运行成本，不证明跨硬件普适速度。

**成本可行性门槛只在 `nc=64` 判定。** `coarse_goal_local` 必须同时满足：

1. ID 和高对比两组，相对 `fine_direct` 的逐几何完整时间比中位数均 ≤0.80，各至少12/16个几何严格更快。
2. 两组相对 `fine_amg_pcg` 的同类配对中位数也均 ≤0.80，各至少12/16个几何严格更快。
3. 所有数值、精确预算、同网格一致性、冻结输入与重复确定性检查通过；强基线不能以未收敛或不完整计费参加通过判定。不得改用某个次要提议方法替换未通过的主候选。

20% 及12/16是开发决策阈值，不是显著性或发表标准。此门槛没有等精度要求，所以即使通过，也仅支持继续研究更有效的网格提议。报告可额外给出相对逐几何更快细基线的实际剩余时间，作为未来推理和其他新开销可参考的预算；这不构成尚未实现学习器的速度结果。

若未通过，停止在当前“粗求解＋单轮适应”的实现上直接加网络宣称加速；先总结哪一段在线成本无法被训练消除，决定是否转向新的成本结构或研究目标。若通过，下一阶段仍须使用全新训练/验证/确认划分，实际训练与计入推理费用，并同时达到准确性和完整成本要求，不能用本轮成本替代那些实测。
