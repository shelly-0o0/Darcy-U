# 经典数值理论、强基线与当前选题边界

检索与核查日期：2026-11-20。本次仅调研、阅读代码和设计方案，没有运行新 PDE 实验。以下“文献结论”“本项目事实”“推断/建议”分开陈述。它是有目的的深读，不是穷尽性系统综述，也不能据“未检索到”证明首创。

## 1. 判断：问题合理，但目前的问法不能构成创新点

“预算不够覆盖全部材料界面时，观测目标能否改变细化优先级”有数值意义，可用作机制验证；**目标信息应参与网格分配这一原理已被目标导向自适应有限元（GOAFEM）和对偶加权残差（DWR）研究了数十年**。本项目尚未证明的，是有限预算、受限动作和实际完整成本下，某个具体学习算法能否胜过正确实现的传统方法，而非目标条件本身有没有用。[Becker–Rannacher 2001](https://doi.org/10.1017/S0962492901000010)、[Mommer–Stevenson 2009](https://doi.org/10.1137/060675666)、[Feischl–Praetorius–van der Zee 2016](https://doi.org/10.1137/15M1021982)。

对称椭圆问题设双线性型为 \(a_k\)，主解为 \(u\)，线性目标为 \(J\)，伴随满足 \(a_k(v,z)=J(v)\)。对于同空间 Galerkin 解，标准恒等式为

\[
J(u)-J(u_h)=a_k(u-u_h,z-z_h)=R_h(z-z_h),\qquad R_h(v)=F(v)-a_k(u_h,v).
\]

它说明需要的是**主问题的未解析误差与目标敏感性缺陷的相互作用**。同空间粗伴随有 \(R_h(z_h)=0\)；仅把 \(|\nabla u_h|\)、\(|\nabla z_h|\) 相乘，不会因此成为 DWR。富集伴随缺陷、主/对偶残差估计、通量重构才是不同的有效路线。恒等式的假设是同一双线性型和载荷下的精确 Galerkin 关系；代数、求积、系数近似误差必须另行计入。上述恒等式在 [FPZ 原文 §1.2，式(4)–(7)](https://arxiv.org/html/1505.04536v1)可复核。

**最新近邻改变了对多目标成本的判断。** 2026-10-29 发表的 NGO-AFEM 通过循环目标，每层只解一个主问题和一个对偶问题，并给出多目标估计子乘积的收敛理论。因此“多个目标必须每层解全部伴随，AI 能省掉这些求解”不能作为未经比较的前提。[Becker 等 2026](https://doi.org/10.1007/s00211-026-01576-w)。

这些理论不等于“任意固定小预算下，经典方法已经找到真实目标误差的全局最优网格”，也不自动保证对比度独立常数。因此仍可研究特定的、可证伪的有限预算算法问题；但必须明确差异和强基线。

**C1–C3：已解决到哪一步。** DWR 用对偶敏感性加权局部残差；主/对偶估计子乘积则给出另一条收敛分析路径。C2 的误差上界和近似类分析不是精确目标误差的双边估计。C3 的最优代数率以估计子稳定性、缩减、可靠性等条件及网格细化性质为基础；其§4.1具体扩散张量假设为全局 \(W^{1,\infty}\)。不能把定理未经修改移植给当前“粗三角形内部有细像素跳跃”的系数。

**C4–C5：高对比不是一句“残差加权”就处理完。** C4 的可靠性对比度独立需要相应系数拟单调条件；局部效率与可靠性是不同命题。C5 的平衡通量构造给出能量可靠上界，而跳跃独立的局部效率在所述标量情形仍需拟单调。它假设每单元系数常值，载荷若不能在指定多项式空间精确表示须处理数据振荡。当前平滑高斯载荷、悬挂点约束与粗格内部跳跃都要适配，不能直接宣称“有证书”。

**C6：要区分求解误差和材料表示误差。** 该文用有限 \(L^q\) 系数扰动替代过强的 \(L^\infty\) 精确界面对齐要求；Theorem 2.1 对应 \(\nabla u\in L^p\)、\(q=2p/(p-2)\) 的条件。它支持把材料近似和有限元误差分别审计，而不是宣称任何像素化都不影响结论。定理常数依赖椭圆性等信息，并非自动对所有高对比介质均匀。

**C7：多目标聚合和符号问题已有方案。** 该文构造多目标误差聚合，采用富集空间估计未知信息并做PU局部化。合并目标时必须考虑单个目标误差符号，不能简单相加造成相消；文中也明确讨论富集求解成本。它是多目标DWR的重要基线，但不等于所有有限预算场景下的最优选择器。

**C8：完整计算成本已进入经典理论。** 该文把迭代求解停止与离散估计子平衡；工作量是所有网格/求解步骤累计，而非末层自由度。最优率还依赖收缩求解器、合适参数和近线性各模块成本。它不能直接给出本机墙钟最优保证，却否定了“传统方法只看DOF、不看求解开销”的泛化描述。

**C9：最新多目标方法必须比较。** 循环目标方案在每层只求一个对偶，修改标记以防个别目标被长期忽略，并控制主估计子乘各对偶估计子之和。收敛定理有参数及估计子公理要求；具体残差要求每个单元内系数 \(W^{1,\infty}\)，常数并未宣称对比度无关。文中“估计子拟单调性”与C4/C5“材料系数拟单调性”不是同一条件。其数值例说明前渐近阶段可较长，但不能因此推定本项目的小预算必有学习优势。

## 3. 对当前代码与第十四阶段结论的审视

以下由项目代码和既有结果核实，不归于上述文献。参考：[第十四阶段结论](stage14_findings_zh.md)、[第十四阶段协议](stage14_protocol_zh.md)、[几何与目标生成器](../stage10_experiment.py)、[动作与预算](../stage11_adaptive.py)、[粗梯度提议](../stage13_experiment.py)。

1. **离散参考不是连续真解。** 当前比较是在同一 `nf=128` 的像素系数、载荷求积和细P1系统内进行的子空间选择。这样可干净检验离散代数机制，却不能单凭该结果声称连续Darcy误差降低。若重采样 `nf=256/512`，系数界面表示也随之变化：应分别检验“固定像素系数、加密求解”和“固定解析几何、提高材料表示分辨率”，避免把两类误差混在一起。
2. **一层动作表达力很窄。** 每粗格只能不细化/一次red细化，边中点仅在相邻两格都细化时独立。它是合规的约束P1子空间，却不具备任意多层NVB、各向异性、界面拟合或粗空间富集能力；有限bank失败只覆盖这组可实现动作。经典多层GOAFEM的定理不能自动继承。
3. **实际预算不是选格数。** 当前新增DOF为 `D(S)=|S|+选中格之间的水平/垂直邻接边数`。边界自由度另受Dirichlet约束。邻接格既额外花费DOF又释放共享边中点，故固定分数的单遍贪心会把动作耦合与评分质量混在一起；需要同解码器对照和小尺度穷举/交换搜索上界。更复杂解码器的时间也必须收费。不能未经证明假设其误差收益是可加或次模的。
4. **“覆盖全部界面”目前只是离散标签。** I识别2×2细像素同时含两相的粗格，遗漏沿粗格边界的界面；即使全选I，也没有连续界面拟合。用 `B/D(I)` 分层可以，但应称“内部界面格自由度预算比”，不是物理界面已被完全解析的证据。
5. **现有目标族较平滑且相关。** 每例一个圆与一个轴对齐矩形，三目标和源来自同一正高斯族（中心在[.2,.8]²，宽度 .08–.18）。它适合最小验证，但多个目标可能有相近敏感区。换目标的机制检查应固定几何与源，预先定义分离的区域平均/有界线性观测；不要直接引入二维H¹中不连续的点值泛函而仍沿用原理论。
6. **粗梯度失败不等于GOAFEM失败。** `coarse_goal_scores` 自己已注明 unsigned gradient proxy；它不是富集DWR或鲁棒主/对偶误差估计。Jacobi8也是特定近似缺陷策略，不代表经典方法的上限。将这两者作为唯一传统基线会使学习优势难以成立。
7. **目标相消与尺度需要独立审计。** 三个误差先平方聚合避免了跨目标正负相消，但单目标内部仍可相消；用粗目标值缩放和粗误差归一化也可能放大近零量。除历史E外，下一协议应报告物理单位绝对误差、预定容差归一化误差、各目标误差、最坏目标及尾部，保留带符号误差。能量误差单调不意味着QoI误差逐步单调。
8. **重复查询存在更强复用基线。** 固定同一系数/源而只换目标时，矩阵分解或AMG层级可复用；若已求出足够精确的主解，多个线性观测仅需积分。不能令传统方法每次重建全部系统而让AI摊销训练/预处理。单次新问题和大量重复查询必须分别定义成本。

上述第1、3、5、7、8点的“下一步如何测”是本次研究设计建议；尚未用新实验量化其实际影响。

## 4. 最低强基线集合及公平比较方式

| 比较层 | 必要方法 | 实现/解释要求 |
|---|---|---|
| 几何信息 | 当前系数分数、显式内部界面优先、统一/随机 | 同实际DOF；预先固定tie-break；保留强系数基线 |
| 无目标数值信息 | 正确的主问题残差/通量误差指示 | 包含内部材料跳跃与数据项；不能只对粗平均系数计算后冒充原问题残差 |
| 真正目标导向 | 富集伴随DWR；主/对偶残差联合标记 | 富集求解/恢复与标记完整计时；同时报告signed sum和绝对局部贡献，不能把真值误差用于在线排名 |
| 高对比健壮性 | 至少一个适配后的平衡通量参考 | 先在满足假设的小验证问题核对平衡、可靠性与effectivity；未验证适配前仅称指标，不能称认证 |
| 多目标 | 付费的多伴随聚合；C9循环目标NGO-AFEM | 后者需要多层网格，若当前只能一层动作则先设计实现，而非声称已与之比较；不能用一次任意轮换代替原算法 |
| 求解成本 | 细直接、AMG，以及同精度的传统自适应 | 报共同精度下的完整成本曲线；允许同样的分解/层级复用和早停；末层DOF相同只解决一个局部比较问题 |

两层比较应同时存在：A是限制所有方法使用当前动作族，隔离学习的评分/解码贡献；B是允许传统成熟自适应算法发挥其正常能力，回答最终是否值得使用。A胜出不能自动替代B。实现工作可先分批完成，但在B缺失前不写“超过传统GOAFEM”。

### 下一阶段最低可行实现：两周内的无学习审查

**先建立一个多层、系数与单元对齐的验证组。** 使用可明确对齐的分片常值材料分区和可控观测（例如轴对齐分区，而非一开始便要求任意圆界面精确拟合），初始网格解析材料界面，之后采用多层NVB或已验证的等效合规细化。在此验证主/对偶残差联合标记、富集DWR以及至少一个平衡通量实现。首要产出是残差恒等式、局部守恒/平衡、effectivity与参考精度检查，不以其运行快慢选择有利问题。它与旧双包含体的一层问题并列报告，不覆盖旧结果。

**旧像素问题保留为未对齐诊断。** 以弱形式残差在细子单元上积分，是优先可行途径；它通过原系数的分片积分保留内部跳跃的作用。若转成强形式局部残差，必须包含粗单元内部材料子面的通量跳跃项，不能只保留粗网格边上的跳跃。弱式积分与强式体/面分解应核对同一残差，不能把已在弱式内计入的界面项再次重复相加。富集伴随必须独立于参考真值，不能把完整细参考伴随标成廉价在线指标。

**最小方法顺序：** 先系数排序、无目标主残差、主/对偶联合标记、富集DWR、细直接与AMG；验证后补平衡通量和原生多层循环目标NGO-AFEM。若两周内不能正确实现某个强基线，结论应是基线审查未完成，不启动“超过它”的AI训练主张。严格等DOF只用于动作族内的受控比较；原生多层方法以达到共同误差容限的完整成本比较，允许合理预算上限，保留每次实际自由度。

**多查询成本单列。** 对同一矩阵给传统方法同样的分解/AMG层级复用权利，多RHS求解不能按多次重装配重分解计价；多目标还须与C9循环伴随比较。系数和源均固定且已获得细主解时，换线性观测只需积分，这应单独作为“先付一次高精度主解”的摊销基线。只有计入这些比较后仍有完整成本空间，才考虑学习低成本指标或伴随缺陷；其架构新颖性仍需另行审查。

## 5. 可保留的研究缺口与下一步优先级

更合理的候选研究问题是：**对指定的高对比Darcy查询分布，能否在不读取细参考的在线阶段，以比强经典目标导向策略更低的完整时间，达到预定的多目标误差容限，并对失效样本可靠识别和回退？** 其科学内容可能落在廉价目标敏感性近似、有限步动作交互、误差认证与回退成本；“高对比＋目标＋预算＋图网络”这几个名词的组合不是新颖性证明。本次经典调研未证明该候选问题在机器学习文献中仍属空白。

下一步先做研究资格检查，而不是立即训练：

1. 固定问题定义：目标有实际含义；明确连续问题或固定离散参考；注明同一次新几何/重复查询场景和允许复用内容。预算采用 `D(S)≤B` 更接近资源上限，历史严格等式可保留作受控对照，但不要为凑满预算引入无益动作后归咎模型。
2. 在很小的独立开发集上验证材料/求积/参考误差与真正DWR。检查富集误差的effectivity及残差结构，再确定大实验需要的精度，而非沿用“一个细网格等于真值”。
3. 同一几何、源项下预设不同观测；比较系数、可靠经典策略和小尺度可枚举动作最优值。把“目标可识别地改变较优动作”“正确经典方法已经提取多少”“剩余空间是否足以支付学习/推理”拆成三个问题。若第二步已耗尽空间，结束AI选择器路线。
4. 只有存在超过强经典基线的可重复空间，再确定学习模型和标签。用新几何、新目标布局和新对比度确认；训练/验证/确认按几何分组，多目标与多预算仍是同一独立几何的重复观测。
5. 论文主要终点采用误差–完整成本的Pareto曲线、失败率和最坏目标；新增DOF、网络推理时间、有限bank oracle都是解释指标。若同精度成本没有优势，诚实定位为数值机制或误差估计研究，不宣称AI求解器加速。

当前最应停止的，是把“降低预算后出现目标差异”直接升级为新模型的发表依据。应保留第十三阶段直接装配和第十四阶段求解器验收作为工程资产，重建有效经典比较，再决定是否训练。
