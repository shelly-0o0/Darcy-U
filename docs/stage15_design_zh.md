# 第十五阶段设计：强经典基线与学习必要性的资格检查

设计日期：2026-11-20。依据：[选题重新审查](research_review_decision_zh.md)、[经典原文核查](research_review_classical_zh.md)、[学习近邻核查](research_review_learning_zh.md)。

**当前为可执行研究设计，不是已冻结的确认实验协议，也没有新实验结果。** 两周指下一轮开始后的工作时间上限，不是已预约后台运行。先完成小型开发核验，再将实际种子、尺度、容差、实现版本和主终点写入独立冻结协议；不得读过确认结果后改阈值。

## 1. 唯一主问题与三个拆开的假设

主问题：**学习模型能否减少高对比Darcy的目标误差估计成本，并在计入核验和回退后，比强经典自适应更快达到同一组目标容限？**

- H1，数值前提：参考、残差与目标误差估计可信；此项失败先修数值问题，不训练AI。
- H2，成本前提：正确实现和合理复用后，仍存在可替代的昂贵估计环节；没有该瓶颈就停止“估计器替代”路线。
- H3，学习前提：便宜特征可以提取这个环节中的有效信息，在未见几何、目标和对比度上保留决策质量；后续用最小学习实验检验。

不要求学习器在固定自由度下必然比富集DWR更准；若以明显更低估计成本达到同一目标精度，同样有价值。但复制已有E2N范式仍需额外贡献和近邻比较，不能直接包装为新架构。

## 2. 明确的数学问题与观测

主方程仍取单位正方形上的标量问题

\[
-\nabla\cdot(k(x)\nabla u)=f,\qquad u|_{\partial\Omega}=0,
\quad 0<k_{\min}\le k(x)\le k_{\max}.
\]

第一轮使用三个分离的区域平均观测

\[
J_j(u)=\int_\Omega w_j u\,dx,\qquad w_j\ge0,\quad \int_\Omega w_j\,dx=1,
\]

其中 \(w_j\) 是固定半径内的有界光滑权重。源位置、观测中心和半径在开发后预先固定规则；目标与源不再强制来自同一随机生成族。零边界下这些观测解释为指定区域的平均压力。目标交换时固定k和f，只变w；它是因果诊断，统计独立单位仍为材料几何。

预设容限 \(\tau_j>0\)，主要误差指标为

\[
q=\max_j\frac{|J_j(u_{\rm ref})-J_j(u_h)|}{\tau_j}.
\]

报告每个目标带符号绝对误差、q、失败率、能量误差和尾部；q≤1表示相对所采用参考满足容限。旧E仅作为与历史结果连接的辅助量，不再依赖粗误差作主归一化。容限必须按无量纲物理尺度预先给定，不按每个确认样本的未知真解选择。

q只用于离线验收。每个算法必须按预先固定、可部署的估计/核验规则停止；禁止事后寻找首次q≤1的网格并据此截断在线耗时。若获得了有效参考误差上界δref,j，连续精度验收需满足 \(|J_j(u_{\rm ref})-J_j(u_h)|+\delta_{{\rm ref},j}\le\tau_j\)；只有相邻网格差时，不把它冒充严格δref,j，只称相对已核查参考的精度。

### 2.1 制造解校验，不用随机算例代替数学正确性

取只依赖x的分层常系数k(x)，界面对齐初始网格。令

\[
c=\frac{\int_0^1t/k(t)\,dt}{\int_0^1 1/k(t)\,dt},\quad
v(x)=\int_0^x\frac{c-t}{k(t)}\,dt,\quad
u(x,y)=v(x)\sin(\pi y).
\]

则v(0)=v(1)=0，u连续，界面法向通量 \(k\partial_xu=(c-x)\sin(\pi y)\) 连续；每层内

\[
f(x,y)=[1+\pi^2 k(x)v(x)]\sin(\pi y).
\]

这是一项直接构造，非新的数值理论。先验证主解收敛、通量跳跃、载荷求积和目标积分。另加平滑系数制造解作对照。该f不一定落在通量估计器要求的多项式空间内，必须计载荷振荡；若先以投影载荷校验，则明确解的是投影后的问题，不能拿它冒充原f。

### 2.2 材料和尺度分组

| 组 | 作用 | 开发期建议范围 |
|---|---|---|
| A 分层对齐材料 | 实现/定理假设校验 | 常系数、对比度10/100/1000；多层细化 |
| B 历史双包含体 | 与现有结论衔接 | 保留原生成器与B=1024负对照；另看预算曲线 |
| C 屏障/通道 | 检查导通结构与目标敏感性 | 固定几何后分别改变材料强弱；不同时改所有因素 |
| D SPE10二维层 | 后续外部压力测试 | 仅在A–C通过后；不是第十五阶段必须完成项 |

建议开发集上限24个独立几何，A/B/C各8个；预算/目标变体是重复测量。首先做小尺度校验，再在约10⁴、5×10⁴、2×10⁵主问题自由度上测成本范围；以实际合法网格记录DOF，不硬凑精确数量。均为设计建议，需开发时按资源核验并冻结，不能逐步扩大规模直到得到有利结果。

## 3. 先补齐数值和基线

### 3.1 参考精度

分别运行两条收敛检查：固定高分辨率分片常值k，加密求解空间；固定解析材料定义，提高材料表示/积分精度。两者不可混为一个“网格泛化”实验。

至少用三个嵌套空间并在少量案例上增加独立阶次或通量离散交叉核验。最细两级各目标差建议小于0.1τj；这只是经验参考准入指标，不是连续误差严格上界。若差值不稳定、偶然相消或交叉核验不一致，继续提高参考或降低宣称范围。制造解组可直接检验真误差；高对比组不能由线性残差推断离散精度。

沿用第十四阶段的原矩阵实际残差与分量后向误差验收作起点，所有方法同样检查；再验证代数误差远小于τj。必要时采取与误差估计匹配的非精确求解策略，但须双方相同且计入成本。

### 3.2 两个实验层级

**层级A：受限动作诊断。** 所有方法共用现有的一层细化动作和实际DOF解码器，识别指标是否有信息。可在极小实例枚举可行动作子集；较大实例只能报告有限搜索的最好值，不称全局最优。更换解码器必须单独消融并计时。

**层级B：实际求解比较。** 建立多层合规自适应；优先采用已有成熟细化实现，允许经典方法使用正常的细化/停止规则。以达到q≤1的完整时间比较，而非强迫它使用历史受限动作。论文中的求解效率结论必须来自这一层。

### 3.3 基线优先顺序

| 优先级 | 方法 | 必须核验的内容 |
|---|---|---|
| 必须 | 系数/内部界面排序、统一细化 | 保留便宜且强的旧基线 |
| 必须 | 正确的主问题残差及主/对偶联合标记 | 包含体残差、面通量跳跃、材料和载荷数据项 |
| 必须 | 富集伴随DWR | 独立求富集伴随，不读参考真解；计入全部富集与局部化费用 |
| 必须 | 细直接、缩放AMG-PCG | 相同线性验收，允许分解/层级复用 |
| 高对比主张前必须 | 平衡通量估计对照 | 先对齐组检查局部平衡、可靠性和振荡项，再讨论未对齐适配 |
| 多目标效率主张前必须 | 原生循环目标NGO-AFEM | 按原算法实现多层循环与MARK规则；不能用任意轮换冒名 |
| 进入学习后必须 | E2N风格MLP、学习标记参数 | 同一信息、训练集、容差和完整成本；称适配版，不称原作者已复现 |

富集DWR的全局核验使用 \(R_H(z^+-I_Hz^+)\)。局部指标采用一致的体/面分解或分片单位局部化，验证其总和；不能仅依据任意局部分拆排序。对粗单元内部的像素跳跃，弱式细子单元积分与强式内部子面跳跃应相互核对，避免漏计或重复计数。

上述插值必须落在满足悬挂点及边界约束的粗空间。非精确代数解下，\(R_H(I_Hz^+)\)不必为零；应将它单列为代数项并保留/控制，不能把Galerkin正交当作数值上自动成立的条件。总估计与目标修正采用同一误差分解。

deal.II step-14可作富集DWR实现参照，但它的平滑Laplace示例不自动解决本项目材料跳跃与约束网格。[官方示例](https://dealii.org/9.7.0/doxygen/deal.II/step_14.html)。若某强基线两周内不能正确完成，结论是资格检查未完成；可形成基线修复任务，但不得跳过后开始宣称AI超过它。

## 4. 成本账本和学习空间

每条可部署路径统一统计

\[
T_{\rm total}=\sum_\ell(T_{\rm assembly}+T_{\rm primal}+T_{\rm dual}
+T_{\rm estimator}+T_{\rm features}+T_{\rm model}+T_{\rm mark}
+T_{\rm mesh}+T_{\rm checks}+T_{\rm fallback})_\ell.
\]

包含CPU/GPU搬运和同步；模型加载分别给冷启动与常驻使用数，不能只计GPU核。参考真解只在离线评价使用，其成本单列。若部署时依赖完整DWR核验，必须放回在线账本；无需核验的消融不能继承可靠性说法。

分别定义：新k、新f的单次问题；同k多f可复用矩阵的问题；同k同f仅多目标查询。最后一项必须与“一次高精度主解＋后续积分”比较。训练和标签成本分别报告，使用

\[
N_{\rm break-even}=\frac{T_{\rm label}+T_{\rm train}}{T_{\rm classical}-T_{\rm learned}}
\]

仅在分母为正、查询分布和复用设置一致时给摊销次数；否则没有此意义下的盈亏平衡点。

第一轮先测可替代环节占比p。对于**网格轨迹不变、只替代估计环节**的方案，即使把该环节成本降到零，时间比也不低于1−p。该简单下界不约束另行改进网格轨迹的算法。为争取20%完整时间下降，建议要求可替代占比至少30%以留出推理与核验余量；这是项目投入标准，不是数学定律或文献公认门槛。

多目标G1的参照必须已包含合理的分解复用和循环目标强算法。若两周内尚未完成NGO-AFEM，只能作明确限定的单目标/实现核验，不能从较慢的全伴随路径推断多目标AI机会已成立。平衡通量尚未完成时同样不得批准“高对比认证”的主张。

## 5. 通过资格检查后，具体使用什么AI

### 5.1 先做可以被简单方法否定的最小模型

**输入：** 当前单元/邻边的log k与对比度、尺寸和形状、可得到的内部材料统计、正确残差/通量跳跃、粗主解与粗伴随局部量、观测权重及当前目标容限。所有特征来源必须是已支付的粗层计算；若读细材料子格，计入读取和积分费用，不隐藏细求解或全局Schur设置。

新目标需要的粗伴随求解全额计时。若模型每层读取全部目标伴随，它就必须支付这些求解；比较NGO-AFEM时不能强迫循环算法也算齐全部伴随。必要时缩减模型输入，而不是扩大基线成本。

**输出：** 每单元、每目标对廉价指标的修正，形成 \(\widehat\eta_{T,j}=\eta^0_{T,j}+s_{T,j}c_\theta(x_{T,j})\)。尺度s从开发集/当前廉价残差确定，不能使用确认参考误差。第一网络采用两层64宽MLP；输入维数由特征审计确定。它是**E2N风格的适配基线**，不是本项目创新命名。

**监督：** 离线富集DWR局部指标。以稳定尺度归一化后的局部Huber损失为主，加总量一致性项；误差接近零时使用固定尺度下限。带符号和绝对值两个版本分开比较，不能预设符号必然有收益。全局误差准确度、局部标记质量、实际细化后q、完整时间分别评价，避免重复第十阶段的推断失误。

**可选图模型：** 只有MLP的失败可定位为邻域/材料连接信息缺失时，试3层、64宽的消息传递网络；边特征加入材料通量传递信息和几何，所有比较保持近似参数/训练预算。采用无目标、目标置乱、去掉边材料信息、仅MLP、增加经典恢复阶次等消融。图网络本身、全局上下文或通量特征不主张首创。

**另一条轻量对照：** 保留正确DWR，仅学习标记参数（开发期固定有限参数集），判断收益是否来自使用指标的方式。如果这已达到同样效果，不扩展图网络。

### 5.2 核验与回退的边界

模型只提出标记或估计，不修改主问题方程和边界。对训练分布外、估计不一致或数值失败的情形，转回经典估计/标记；最终停止必须使用已验证的数值估计与预设规则，且其费用计时。

残差小、置信度高、回退存在，都**不等于目标误差认证**。只有在平衡通量/主对偶上界的假设和实现满足时才能给数学误差保证；统计校准也不能保证任意分布外输入。若核验成本抹平速度优势，应接受失败，而不是删除核验后保留可靠性声称。此版本暂不主张AI每步都改善QoI，目标误差也可因相消而非单调变化。

### 5.3 资源控制

最初学习试验建议128–256训练几何、32验证几何、3训练种子，先在中等网格离线取少量自适应轨迹；按几何划分，所有目标/预算/网格变体同属一个划分。先跑32几何试算标签成本，再确定数量；不预设“标签免费”。此处数量为开发建议，不能替代基于方差的确认集设计。

检查经典教师轨迹与模型自身轨迹的状态差异。需要补充模型轨迹标签时，仅从训练划分采样并把额外标签费用入账；不能读取确认轨迹真值后再训练，也不能把部署分布漂移直接归因为缺少图结构。

一张消费GPU足以容纳这些小模型的计划规模，但标签生成、稀疏求解和网格程序是主要工程工作；目前没有测得这套新方案的实际训练小时数。首轮训练与调参预算建议不超过24 GPU小时，标签生成独立限额和记录。没有正向信息不增加网络规模、RL轮数或超参数搜索。

## 6. 两周资格检查的日程与停止规则

| 工作时间 | 工作 | 具体交付 |
|---|---|---|
| 第1–3天 | 对齐制造解、固定材料参考层级、DWR恒等式和求积检查 | `reference_audit`：逐目标误差、参考变化、失败样本 |
| 第4–7天 | 多层主/对偶标记、富集DWR、系数及细解基线；核验通量与循环算法的实现范围 | `classical_baseline`：方法定义、误差—DOF曲线与对照 |
| 第8–10天 | 一次新问题/复用查询成本；目标交换、预算曲线与小尺度动作诊断 | `cost_opportunity`：完整成本、可替代占比、廉价恢复差距 |
| 第11–14天 | 独立复核、选择主终点、冻结下一阶段或停止 | `go_no_go`：证据、决定、缺失基线、资源上限 |

**G0 数值正确性。** 制造解与界面通量检查通过；参考精度有依据；未出现未解释的估计失真。未通过则只修基线，H2/H3不评价。

**G1 可替代成本。** 在预定应用范围内，正确强经典方案的可替代估计成本建议占比≥30%，且存在实际完整成本节省的余量。若主要成本是主解、装配或材料读取，则停止这一估计器替代主线；不能拿较慢的无复用实现制造瓶颈。

**G2 可用信息。** 付费富集DWR相对便宜指标的改进可重复，材料/目标特征有可识别关系；廉价经典恢复若已达到同样的误差—成本曲线，则学习必要性不成立。此关口只批准小模型检验，不能证明可学习或新颖。

**G3 后续学习确认。** 在新几何上达到同一组τ，完整时间配对中位比建议≤0.80，按几何聚类得到的95%区间上端<1；预定各材料族分别报告，不能合并掩盖高对比失败。计入回退后所有被宣称成功的样本均通过目标/线性验收；超过时间/DOF上限的样本记失败，不删掉重算。该门槛是工程决策，零观测失败也不是总体零风险保证。

建议主确认门槛要求全部预定样本在计入回退后成功；任一方法出现失败时先报告失败率和原因，不能只在共同成功子集上宣称总门槛通过。超时按预定上限记为右删失成本，未达精度但正常退出也记失败，不将其短耗时作为速度收益。共同成功子集的时间比仅作明确标注的辅助分析。若应用允许非零失败率，必须在确认前另冻结可接受差异及其区间检验，不在事后放宽。

G3至少在新的独立确认集上执行，不复用阶段14确认几何。确认规模按开发方差和预期效应设定，建议每个主要材料族至少32个新几何；它们的目标/预算变体不能算额外独立样本。报告完整配对分布、95分位退化、最坏目标、失败数及置信区间。基线配置用开发集选定；测试集逐例最优方法只能作为离线参照，不能伪装成可部署算法。

## 7. 通过之后的3–6个月路径

1. 第1个月：完成资格检查与少量学习试验；同时固定近邻差异。若只复现E2N或学习标记，无新机制则不启动“大实验＋写论文”流程。
2. 第2–3个月：只围绕一项新增机制做理论/数值解释、模型消融和未见目标/对比度验证；在资格检查已完成的强基线上扩展尺度，加入预先选定外部材料组。任何新范围所需基线必须先完成，再认可该范围的学习收益。
3. 第3–4个月：冻结模型和实验配置，独立确认，核算标签/训练摊销与失效边界，整理可复现资产。
4. 第4–6个月：依据结果写作和补审稿所需证据；若结果不支持同精度加速，改写结论或停止投稿主线，不用美化有限oracle替代可部署结果。

这些是工作安排与投入上限，不是成功概率或发表承诺。若G1/G2反复失败，两周后结束该分支，先形成负面机制报告，再针对具体应用的重复正问题或反问题单独调研；不自动回到已停止的低秩、容差动作或更大图模型路线。
