# 第十四阶段补充：失败分支的下一研究问题与文献边界

核查日期：2026-11-20。本文先读了[第十二阶段动作学习近邻](stage12_action_related_work_zh.md)，本次补充目标导向误差学习和网格形状学习，不重复其 RL/GNN-AMR 清单。文献核查及条件式建议在读取本阶段正式确认统计之前完成；最终决定见[第十四阶段结论](stage14_findings_zh.md)。本文件不修改冻结 gate，也不报告任何新模型训练结果。

## 1. 四篇直接相关的原始研究

**Fidkowski、Chen，Metric-based, goal-oriented mesh adaptation using machine learning，JCP 426:109957，2021。** 用主解、伴随与误差特征学习各向异性度量，元素尺寸仍由伴随加权残差控制，学习部分补充伸长程度和方向。故“目标条件＋各向异性神经网络”本身已有先例，不能作为本项目的独创架构。依据[出版社原始摘要](https://www.sciencedirect.com/science/article/pii/S0021999120307312)及[作者发表目录](https://public.websites.umich.edu/kfid/publications.html)核对；此次出版社全文受限，作者 PDF 也未成功解析，没有假称完成全文复现。

**Wallwork 等，E2N: Error Estimation Networks for Goal-Oriented Mesh Adaptation，作者预印本，2022。** 在元素层面以粗 DWR、物理、网格及解场信息预测目标误差指标，替代昂贵的加密伴随误差估计步骤；保留经典求解器和适应流程，示例涉及潮汐机组功率。研究已直接触及“用便宜学习器代替目标导向误差计算”，本项目不能仅换成 Darcy 就认定方法新颖。已核查[作者全文第2–3节](https://arxiv.org/html/2207.11233v1)，未据此宣称其结果适用于当前高对比 Darcy。

**Zhang 等，Towards Universal Mesh Movement Networks，NeurIPS 2024。** UM2N 从网格和 monitor 值学习节点移动，使用 Graph Transformer 与 GAT；不增加整体自由度。正文明确由外部 monitor 指定所需密度，局限部分承认 monitor 仍需人工选定且没有完全防缠结的理论保证。因此，它提供了“给定重要性后如何移动网格”的近邻，不替我们证明“哪个 Darcy 界面对某个目标最重要”。已核查[正式会议记录](https://proceedings.neurips.cc/paper_files/paper/2024/hash/1b0da24d136f46bfaee78e8da907127e-Abstract-Conference.html)与[作者全文第4节及局限](https://arxiv.org/html/2407.00382v4)。

**Carpio、Prieto、Bermejo，Anisotropic “Goal-Oriented” Mesh Adaptivity for Elliptic Problems，SIAM JSC，2013。** 这是传统数值基线线索：对稳态线性对流扩散反应问题用 DWR 构造各向异性度量，并用局部高阶恢复估计权重。它说明目标导向形状优化已有经典路线；不是高对比界面 Darcy 上的现成性能保证。此次核查范围为[出版社原始摘要](https://epubs.siam.org/doi/10.1137/120874606)，未获取完整方法或实现。

这四篇的用途是限定主张和确定比较对象，不是穷尽检索；没有核实“界面感知＋预算＋目标条件”的任何具体组合尚无人研究。发表潜力仍需更完整检索、实际复现与证据。

## 2. 条件式转向：先证明目标条件有价值

**建议下一研究问题：在细化预算不足以完整解析所有材料界面的二维 Darcy 问题中，改变源项或观测目标时，目标条件是否能稳定改善相同自由度预算下的网格选择，并超过简单系数／界面排序及经典目标导向指标？**

这是对第十三阶段“简单双包含体、给定预算下系数排序覆盖全部内部界面”的限制提出检验，不是先假设复杂介质必然需要 AI。当前系数基线强，可能说明原问题的主要决策已被廉价几何信息解决；也可能是候选动作族太窄。第十四阶段的有限 bank 若失败，只能否定该预定候选族所检验的收益门槛，不能证明所有目标导向策略都没有空间。

先区分失败来源：若只因数值有效性 gate 失败，先处理数值问题，不能将其解释为选题无精度空间；若主精度条件失败而 coverage 有信号，优先检查界面邻域自由状态；若两者均无实质信号，停止给当前固定 bank 追加网络，再启动下述独立小试验。

## 3. 改变问题族与改进方法必须分开

| 改变 | 对应假设 | 不能归功于什么 |
|---|---|---|
| 保留当前系数族，降低预算 | 无法完整覆盖界面时，重要性排序才成为主要瓶颈 | 不能把新预算带来的可改善空间称为模型改进 |
| 新增多包含体／连通通道，并保留原族作负对照 | 几何复杂度使界面覆盖与目标影响不再同义 | 不能只挑系数排序最差的介质来报告优势 |
| 同一个系数与源项，更换若干局部观测权函数 | 不同目标应产生可测的动作偏好差异 | 不能把几何变化造成的差别当成目标条件价值 |
| 保持数据和动作族不变，再引入学习器 | 学习器能便宜地利用已证实有用的信息 | 不能把更大候选库或额外细参考当成学习收益 |

建议先只改变预算，再单独增加一种几何族，避免同时引入各向异性张量、时变问题和网格移动。它们会改变离散器、强基线和误差分析，超出目前直接局部装配已验证的范围。若以后确有方向性误差的证据，再把各向异性动作当作独立研究支线。

## 4. 一次小规模、可停止的筛选

1. 先写独立协议，在开发几何上比较固定预算档位，并确保涵盖不能完整覆盖界面的范围（例如nc=64下B=16/32/64/128，再保留B=1024负对照；这是规划示例，尚未冻结）。报告 `B/覆盖全部界面所需DOF` 分层；同一配对各方法必须使用相同实际 DOF。预算档位不得根据确认效果回选。
2. 固定系数与源项，切换预先定义的观测位置／权函数；对每种目标设置均保留同一组候选生成规则。以几何为独立样本，目标设置和预算重复不扩充样本量。
3. 强传统基线至少包括系数变化排序、显式界面优先排序、廉价源／目标加权系数排序、合适的残差与 DWR 策略；DWR 的伴随／恢复成本必须计入。既有 Jacobi8 可保留，但不能充当唯一比较对象。新各向异性动作若启用，需再补相同动作能力的经典度量方法。
4. 先测有限动作空间的离线可改善幅度，连同随机等候选数对照、未参与选择的目标、逐目标带符号误差、能量误差及尾部失败一起报告。有限 oracle 仍不证明可学习性；若连预先规定的实质改善都没有，就停止此支线。
5. 只有出现跨几何稳定空间，再训练最小模型，并做同结构“有目标输入／无目标输入”及“有粗解／无粗解”消融。训练、验证、确认按几何分离，旧确认数据不回流后继续充当未见数据。

若值得训练，可先用小型网格图网络输入系数、源／目标描述和预算，预测待细化格的收益，再交给确定性精确预算解码器；粗解信息作为付费消融。这个框架是可执行的候选，不是创新性结论，需与 E2N 类指标学习及第十二阶段直接动作学习路线实际比较。尤其要检验目标输入是否超越廉价的显式加权，而非仅比无条件网络好。

最终问题应落在可复核的精度—完整成本曲线上：系数采样、特征、数据转移、推理、解码、装配、求解和共同数值验收全部收费，另列训练与标签成本。单独的低 DOF 或推理很快不能称为同等精度加速；观测量改善也不自动意味着场误差或其他目标改善。
