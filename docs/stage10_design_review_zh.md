# 第十阶段设计审查：从逐目标误差预测转向有结构的双线性误差算子

审查日期：2026-11-19。本文是文献核查与模型设计说明，不是实验结果，也不是创新性或期刊分区承诺。第十阶段目前定位为一个有限预算的结构验证实验；不等同于完整自适应网格算法，不预先声称端到端加速或统计优势。

## 1. 应当承认的早期设计问题

此前研究路线对“模型是否值得学”的审查晚于具体模型设计：低秩空间能减少迭代，并不意味着采集、提取、构造和应用的总成本下降；局部动作有改善，也不意味着胜过整组实例上选定的强经典基线。后续阶段补齐了这些对照，但最初应先完成成本分解、固定强基线和低成本机会筛查，再决定是否训练。

创新性核查也需要前置。“用网络近似伴随”“学习富集误差”“新目标量泛化”“多目标共享计算”都有直接或接近的先例。把这些组件换成 GNN、FNO 或更大网络，不能自动形成独立贡献。第九阶段的容差学习又遇到直接近邻且部分全文未取得；缺失全文不能成为新颖性依据。

已有停止决定是资源决策，不是科学上的普遍否定。第九阶段只检验了当前 PDE 族、n32/n64 网格、当前 Jacobian 的 ILU 配置以及一次容差动作后接固定策略；其阴性结果不能否定所有非线性求解控制。第八阶段也只否定相应冻结设置达到既定收益线的假设。后续若改变假设，应说明改变的机制和独立验证方式，不应不断更换 PDE、网格或指标直到出现有利结果。

## 3. 最窄的可研究问题

在**嵌套 Galerkin 网格上的 SPD 标量扩散问题**中，固定数据预算与多层表示，系数条件的对称正定残差算子，是否比同表示的非对称线性模型、非线性模型和廉价经典恢复，更准确地估计未见系数场及带符号局部目标量的两层 QoI 误差？这一差异是否仍存在于接近抵消的目标组合和跨网格测试中？

这是一项可检验的结构假设。目标不是先发明名称，也不是预设硬约束一定更好。即便结果为正，仍须补足 SuperAdjoint、NGO 及经典误差恢复对照，才能讨论论文贡献；当前不能宣称原创新方法或已达到国际一区发表条件。

这里重新使用 SPD 扩散方程，是为了使误差表示、互易性和结构消融可独立核验。研究对象已由求解器低秩回收改为离散误差估计；它不自动恢复此前已失败的加速主张。

## 4. 数学对象及成立条件

设细层刚度矩阵 \(A=A_f\) 对称正定，\(P\) 为满列秩粗到细插值，且必须有

\[
A_c=P^TAP,\qquad B=P A_c^{-1}P^T,\qquad S=I-AB.
\]

载荷向量 \(f\) 与线性目标向量 \(g\) 均在同一细层离散空间中定义。粗解和参考细解分别为 \(u_c=A_c^{-1}P^Tf\)、\(u_f=A^{-1}f\)，目标为 \(J_g(u)=g^Tu\)。令

\[
r_f=Sf,\quad r_g=Sg,\quad E=A^{-1}-B.
\]

则由 Galerkin 代数直接得到

\[
J_g(u_f)-J_g(Pu_c)=g^TEf=r_f^TA^{-1}r_g,
\qquad E=S^TA^{-1}S\succeq0.
\]

这是既有 Galerkin 结构的代数推论，不是模型创新。\(E\) 一般只是半正定：粗空间已能准确表示的分量应有零误差。独立重离散粗系数、不同载荷积分、非嵌套网格或不准确粗解会破坏上述精确关系，必须另计离散/代数误差，不能继续原样引用。

这里的“误差”首先是**粗解相对于指定细层解的差**。它不自动等于相对于连续 PDE 真解的误差。若要升级到连续误差控制，需要独立更细参考、饱和性分析或其他可靠估计；不能把细层标签称为严格误差证书。

## 5. 当前模型、标签与可验证的性质

当前 `stage10_error_model.py` 的对称模型可写为

\[
H_\theta(k,h)=D^{-1/2}\left[
\operatorname{diag}(d_\theta(k,h))+
\sum_{\ell=0}^{L-1}C_\ell^T
\operatorname{diag}(w_{\theta,\ell}(k,h))C_\ell
\right]D^{-1/2},
\]

其中 \(D=\operatorname{diag}(A)\)，\(C_\ell\) 是到该层为止的无偏置线性卷积分析链，合成链使用其精确转置。门控只接收系数/几何信息；三类输入为节点平均 \(\log k/\log20\)、去均值的对角项对数、节点到最近边界的物理距离 \(\min(x,y,1-x,1-y)\)。第三通道在正式运行前替代了仅随网格改变的常量标记，避免训练时恒为零、分辨率测试时才激活未训练输入。门控经 softplus 加正下限，层权重取正。残差通道没有激活或偏置。正对角底项避免所有分析算子的共同零空间，使有限且数值有效的参数下 \(H_\theta\) 为 SPD；只有多层半正定项的求和通常不足以声称严格正定。

对于多组载荷/目标的残差列 \(R=[r_1,\ldots,r_m]\)，学习

\[
Z_\star=A^{-1}R,\qquad K_\star=R^TZ_\star,
\qquad \widehat Z=H_\theta R,\qquad \widehat K=R^T\widehat Z.
\]

当前损失设计是**残差修正的相对能量误差加 0.25 倍归一化 Gram 矩阵误差**。每列、每实例的归一化及近零分母处理必须在协议中固定。细层求解只用于离线标签和评估，不得作为部署输入或模型特征。

这种构造直接保证：固定 \(k,h\) 下对 \(f,g\) 双线性、交换二者不变、相同载荷与目标时预测非负。对应的完整误差近似是 \(\widehat E=S^TH_\theta S\)，而非把 \(H_\theta\) 本身等同于 \(E\)。这些结构测试是实现正确性检查，不是实验上的学习胜利；常数对角矩阵也能满足相同性质。

当前另设两个对照：分离分析/合成权重的 **untied 线性模型**，以及在残差路径加入激活的 **nonlinear 模型**。前者仍应保持载荷线性但不硬保证对称；后者用于检验放宽线性约束的效果。它们参数量和优化难度并不天然完全相等，应同时报告参数量、训练预算和初始化方式，不能把所有差异都归因于单一结构。

## 6. 结构保证不等于精度、可靠性或 AMR 能力

即使 \(H_\theta\succ0\)，它仍可能把每个误差预测放大一百倍。正定性既不给误差上界，也不给目标误差相对精度。对带符号目标，真实误差可能由于抵消接近零；不能只报告相对误差或删掉难例，应同时报告预先定义的绝对/能量尺度归一化误差和符号判断，接近零的判定区间需固定。

一个可检查的充分条件是残差子空间上的能量归一化算子误差小。若
\(\|A^{1/2}H_\theta A^{1/2}-I\|\le\epsilon\)，则

\[
|r_f^T(H_\theta-A^{-1})r_g|
\le\epsilon\|r_f\|_{A^{-1}}\|r_g\|_{A^{-1}}.
\]

这只给绝对误差尺度，不能保证抵消目标的相对误差小。训练样本的平均损失也不证明上述全空间条件；本轮最多通过独立样本诊断其是否改善。

已见目标的线性组合测试主要验证结构一致性，并不是强分布外泛化。真正泛化应按独立系数场划分，加入未见目标位置/尺度、训练目标张成空间之外的形状，以及独立网格。不能将同一系数场的不同目标随机分到训练与测试后声称跨问题泛化。本轮的 `narrow_load` 是四个右端同时变窄，且共同作为源项与目标，因此称为“窄载荷”测试；它不是固定同一源项、只改变目标量的隔离实验。局部标记指标只针对源项编号 0 与四个目标的配对。

此外，全局误差矩阵不直接给出可信的单元标记。将其应用于 AMR 还需定义局部化、处理正负抵消，并检查相同真实 QoI 精度下的完整适应路径。本轮不把单次误差预测实验称为已经完成的目标导向网格加密。

## 7. 强对照和全成本边界

共享同一个主问题的多个目标，并非学习方法独占的优势。固定 \(f\) 时，经典方法只需一次求解

\[
A e_f=r_f,
\]

随后全部目标的两层误差都是 \(g_j^Te_f\)。因此必须对比**一次细主问题/误差修正求解覆盖全部目标**，而不能只以“每个目标分别解一个细伴随”为基线。该推导同时说明，多目标数目增大并不必然产生神经方法的额外摊销优势。

本轮应保留廉价经典对照，例如对角近似、固定预算对称松弛/多重网格或局部恢复，以及相同表示下不使用神经系数映射的简单拟合。后续若要主张实际用途，再加入适配后的 E2N、SuperAdjoint/NGO 风格方法，并分清“作者实现复现”与“依据论文设计的本地对照”。

在线成本须包含系数特征、矩阵/层级准备、粗解与残差、模型构造和推理、目标评估、核验与回退。数据生成和训练另报，并给实际复用次数下的摊销；离线预计算不可悄悄移出一个方法的计时。学习模型没有胜过一次精确修正求解或廉价恢复时，不宣称加速。

## 8. 假设失效后的决策

| 观察到的失败 | 应得结论与允许的下一步 |
|---|---|
| 转置、双线性或 Gram 非负测试失败 | 是实现错误，先修复；不能用训练掩盖。 |
| 结构测试通过，但平均/尾部精度不及简单经典近似 | 当前表示或学习目标没有实用价值。先区分分析基底表达能力与系数映射能力，可作小规模固定基底最优拟合诊断；若最优拟合也差，停止扩大网络。 |
| 对称模型与 untied/nonlinear 没有稳定精度差异 | 保留结构作为可解释的设计约束，但不主张它带来泛化收益。若简单线性模型足够，应采用更简单结论。 |
| 只在已见目标线性组合上领先 | 只能说明硬约束实现正确；扩大到预先确定的独立系数与新目标支撑测试，不能把组合一致性包装为 OOD 成功。 |
| 平均预测不错，抵消目标或某些系数下失效 | 明确可靠性局限；检查绝对误差尺度和残差子空间覆盖，不能通过删例改变结论。 |
| 预测改善，但准备/核验成本吃掉节省 | 仅保留误差预测发现，不转写成求解加速。若一次细主问题已足够便宜，应停止完整 AMR 扩展。 |
| 最强近邻已覆盖剩余机制 | 将本轮作为复核/结构基准，不继续声称原创新架构。只有出现明确、独立可验证的剩余问题才另立协议。 |

本轮合理的交付是：正确的两层误差标签、可核验的结构实现、独立划分上的机制消融，以及诚实的可行性结论。是否形成论文研究问题，取决于这些证据和后续直接近邻核验，而非模型名称、单个有利案例或目标期刊等级。
