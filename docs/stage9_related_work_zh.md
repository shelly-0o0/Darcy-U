## 2. 已核实的EW公式，以及本项目应明确的适配

### 2.1 记号与两类原始公式

令 \(F_k=F(u_k)\)、\(J_k=F'(u_k)\)、\(R_k=\|F_k\|\)，上一实际接受步为 \(s_{k-1}=u_k-u_{k-1}\)，上一点的线性模型残差为

\[
\ell_{k-1}=F_{k-1}+J_{k-1}s_{k-1}.
\]

以下对应原文印刷页19、20和23；原论文实验使用EW1的式(2.2)。[EW作者全文](https://users.wpi.edu/~walker/Papers/forcing_terms,SISC_17,1996,16-32.pdf)

| 控制器 | 未保护的 \(\widehat\eta_k\)，\(k\ge1\) | 原文位置 |
|---|---|---|
| EW1，向量差版本 | \(\|F_k-\ell_{k-1}\|/R_{k-1}\) | 式(2.1) |
| EW1，范数差版本，本阶段采用 | \(\big|R_k-\|\ell_{k-1}\|\big|/R_{k-1}\) | 式(2.2) |
| EW2 | \(\gamma(R_k/R_{k-1})^\alpha\)，\(0<\gamma\le1\)、\(1<\alpha\le2\) | 式(2.6) |

EW1的两种形式不能混用名称而不说明。范数差版本必须取绝对值；不能将其中的线性模型残差直接替换为上次目标容差乘以上次非线性残差。

### 2.2 保护规则与参数

定义

\[
h_k=\begin{cases}
\eta_{k-1}^{(1+\sqrt5)/2},&\mathrm{EW1},\\
\gamma\eta_{k-1}^{\alpha},&\mathrm{EW2}.
\end{cases}
\]

仅当 \(h_k>0.1\) 时，将 \(\widehat\eta_k\) 替换为 \(\max(\widehat\eta_k,h_k)\)；再用 \(\eta_{\max}<1\) 限制上端。原实验取 \(\eta_0=0.5\)、\(\eta_{\max}=0.9\)，EW2比较了 \(\gamma\in\{1,0.9,0.5\}\)、\(\alpha\in\{2,(1+\sqrt5)/2\}\)。因此本项目的 \((\gamma,\alpha)=(0.9,2)\) 是明确选定的常用配置，不是原文唯一参数，也不能据此宣称穷尽EW的最好表现。[EW §2.1、§3.1](https://users.wpi.edu/~walker/Papers/forcing_terms,SISC_17,1996,16-32.pdf)

### 2.3 本项目实现约束：与原论文声明分开

以下是本项目的实现要求与数学核查，不是声称原论文逐条采用这些实现细节：

- 内层验收依据 \(\|J_kd_k+F_k\|\le\eta_k\|F_k\|\)，显式计算同一个未预条件范数。预条件GMRES回调值不能自动视为这个真残差；不满足就记录失败或继续统一的精度修正流程，并计入费用。
- 若统一线搜索接受 \(s_k=\lambda_kd_k\)，EW1下一步必须使用 \(F_k+J_ks_k\)。可以由缓存的 \(J_kd_k\) 乘以 \(\lambda_k\) 得到；使用未缩短的 \(d_k\) 会把模型比较点错配。
- 原文§3.1使用其专门的inexact-Newton backtracking算法。本阶段使用统一Armijo线搜索时，应称“EW容差控制器在统一全局化下的适配”，不能称完整复现原论文算法或直接继承其全局收敛结论。
- 对缩短步，三角不等式给出 \(\|F_k+J_ks_k\|/\|F_k\|\le1-\lambda_k(1-\eta_k)\)。这说明请求的内层容差、接受步对应的实际线性模型残差比、以及回溯后的容差上界是不同量。应分别保存，预先明确保护递推中的`eta_prev`使用哪个量；不要把 \(\lambda_k\eta_k\) 当作缩短步的容差。
- 在残差已达到停止线时停止，不再计算除以零的残差比。若设置浮点容差下限，应记录为本项目的数值保护，不能把固定下限下的有限精度实验包装为原论文的渐近收敛证明。
- 首轮采用同一个 \(\eta_0\)、相同Jacobian/ILU构造、GMRES预算、线搜索和最终验收；控制器的额外残差、统计量和保护计算全部计时。固定容差与直接Newton仍是独立对照，而不是故意削弱预条件器来放大学习空间。

## 3. 2020直接近邻：能确认什么，不能确认什么

出版社摘要已经明确：方法预测线性容差，输入包含非线性残差、Newton次数和基于Ritz值的条件信息；目标同时考虑线性及非线性迭代；还比较了由学习分析得到的启发式，应用于二维两相至三维热组分油藏问题。摘要报告线性迭代减少且没有增加非线性迭代。这些已足以否定“第一次用学习选内层容差”“首次关注内外总体成本”之类宽泛主张。[2020原始摘要](https://www.earthdoc.org/content/papers/10.3997/2214-4609.202035089)

下表左栏只写摘要确实支持的内容；“未核实”不等于原文没有做。

| 比较维度 | 2020论文：本次原始来源可核实范围 | 本项目候选设计与当前边界 |
|---|---|---|
| 状态 | 残差、Newton次数、Ritz条件信息等 | 现有残差/线搜索/迭代与无量纲信息；特征变化不是新颖性证据 |
| 动作 | 预测或选择线性容差 | 有限容差动作；动作集合、倍率和裁剪必须预先冻结 |
| 标签 | **未核实**生成方法、分支方法、目标容差标签或成本标签 | 保存训练状态，从同一状态执行一个动作，再由固定EW策略续接至相同精度 |
| 代价 | 明确同时考虑内外迭代；精确目标权重及完整计时定义**未核实** | 动作条件的完整后续时间/工作量；包含构造、线搜索、验收与失败成本 |
| 估计对象 | 精确回归/选择形式**未核实** | \(Q^{\pi_{EW}}(s,a)\)：固定续接策略下的动作成本，不是最优价值 |
| 模型与消融 | 公开摘要未给出足以复现的模型/超参数 | 若以后允许训练，先比较小MLP、树和直接容差回归；不能靠网络名称区分 |
| 泛化与保护 | 精确训练/测试分组、跨网格迁移、拒答/保护机制**未核实** | 实例级划分、跨参数/网格验证及保守返回经典方法均待实际验证 |

**当前不能确认的核心差异正是标签和代价定义。** 固定EW续接的动作条件成本是可实施的候选研究对象，但在取得直接近邻全文前，不能声称对方没有这种设计。近邻研究也可能已采用类似oracle、分支评估或加权成本；本次不作肯定或否定判断。

## 4. Botti缺失意味着什么

Botti的机构摘要确认，它提出自适应forcing选择，考虑inexact Newton及伪瞬态延拓，并在不可压缩流问题中比较固定与自适应选择的残差历史和计算时间。[作者机构原始记录](https://unibg.unifind.cineca.it/resource/item/43611)

本次未取得可核验公式，因而本阶段**不实现一个凭二手表述拼出的“Botti式”策略**。之前计划中的“Botti类预测–校正基线”目前只是一项待补材料，不能在实现清单中算作已完成，也不能声称已覆盖其预测器、校正器或保护条件。

这项缺口有不对称后果：

1. 若有限动作诊断相对已实现的可靠经典对照都没有足够机会，可以按冻结预算停止当前候选。这是有限动作库、状态和问题族的资源筛查结论，不需要假设Botti较弱。
2. 若诊断有正信号，只允许继续核实缺失控制器、调参公平性和直接近邻；**不足以宣布超过完整强基线集合，不自动授权训练，更不能支撑新算法优越性论文。**
3. 将来合法取得全文后，先按原文核对公式、参数和适用范围，再决定如何在相同全局化与代价口径下比较。如果其原始问题为伪瞬态延拓，也不能不加说明地把改写版当作原文性能。

## 5. 本阶段筛查可以回答的问题

本阶段先比较EW1、EW2、明确冻结的固定容差及直接Newton，并限制状态与分支数量。每个分支独立执行一个动作，随后使用同一固定EW控制器直到同一最终验收；完整时间从该状态开始计算，不能把不同状态上的最优分支时间拼成一条可执行轨迹。最优分支是离线机会诊断，选择本身没有因果可用性。

如果将初始状态动作的最好分支与开发选定的最佳固定经典方法比较，必须明确：得到的是“当前有限动作和固定续接下的潜在优势”，既不是所有控制策略的上界，也不是已经实现的学习收益。完整轨迹重复先在实例内聚合，再逐实例配对；Newton步不能当作独立测试样本。具体实例、动作、预算和停止线以第九阶段执行前冻结协议为准，本文件不替代实验协议。

截至本文核查，候选题目的新颖性仍未成立。任何正结果都必须同时跨过完整成本、强基线覆盖和直接近邻实质差异三个门槛；只换PDE、网络类型、特征名称或改写计时口径不够。取得全文前应保留“不确定”，而非把访问限制转化为论文贡献。
