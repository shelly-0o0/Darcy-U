# 第三阶段数学说明：初值校正能够保证什么

本文件说明当前算法中的有限维线性代数性质。它不提出新颖性声明，不证明对网格或系数对比度一致的收敛定理，也不把浮点检查等同于严格认证。实际算法、数据隔离与计时口径以 [第三阶段协议](stage3_protocol_zh.md) 为准。

## 1. 当前系统与两种“能量”

固定序列中的一个时刻，记离散系统为

\[
A x_* = b,\qquad A=A^T\succ0.
\]

正系数 Darcy 方程采用当前 P1 离散，去除齐次 Dirichlet 边界自由度后满足此正定假设。这里的结论针对当前矩阵；不能用旧矩阵的内积替代当前矩阵后直接沿用。

定义当前近似解 \(x\) 的误差、残差和二次目标：

\[
e=x_*-x,\qquad r=b-Ax=Ae,\qquad
J(x)=\tfrac12x^TAx-b^Tx.
\]

误差能量范数平方为 \(\|e\|_A^2=e^TAe\)，并有

\[
J(x)-J(x_*)=\tfrac12\|x-x_*\|_A^2.
\]

因此，减小 \(J\) 与减小当前系统的误差能量等价，但二者变化量相差因子 2。`sequence_baselines.py` 中线搜索的 `energy_change` 记录的是 \(J\) 的变化量；不能直接把它称为误差能量范数平方的变化量。上述误差属于离散线性系统，不是连续 PDE 的离散误差。

## 2. 一维能量线搜索的准确性质

给定任意非零校正方向 \(d\)，它可以来自神经网络、经典迭代或其他仅使用可用信息的构造。沿该方向设置

\[
x(\alpha)=x+\alpha d,\qquad
g=d^Tr,\qquad q=d^TAd>0.
\]

直接展开可得

\[
J(x+\alpha d)-J(x)=-\alpha g+\tfrac12\alpha^2q.
\]

于是唯一最优步长为

\[
\alpha_* = \frac{d^Tr}{d^TAd}.
\]

该步长可以为负，不是把网络输出限制到 \([0,1]\) 的插值系数。精确算术下，更新后的误差能量满足恒等式

\[
\boxed{\;
\|x_*-(x+\alpha_*d)\|_A^2
=\|x_*-x\|_A^2-\frac{(d^Tr)^2}{d^TAd}.
\;}
\]

相应的目标下降量为 \(-g^2/(2q)\)。由 A 内积下的 Cauchy–Schwarz 不等式，\(g^2/q\leq\|e\|_A^2\)，所以公式中的右侧非负。更新后的残差满足 \(d^Tr_{\mathrm{new}}=0\)。若 \(d^Tr=0\)，最优校正为零；若 \(d=0\)，约定保持原初值。

线搜索在全部实数步长中优化，因此还可同时比较 \(\alpha=0\) 和 \(\alpha=1\)：

\[
\|x_*-x_{\mathrm{new}}\|_A^2
\leq \min\{\|x_*-x\|_A^2,
             \|x_*-(x+d)\|_A^2\}.
\]

这说明，在相同当前矩阵和相同物理方向下，精确线搜索的误差能量不会劣于直接使用原预测。但它只是一维优化，不能保证得到其他可能校正方向中的最优解。

本实现先缩放方向以降低溢出风险，再计算步长和二次目标变化；非有限值、非正方向能量或检查失败时拒绝该校正。这些是浮点保护。计算得到的 `energy_change <= 0` 不包含对全部舍入误差的严格上界，不能表述为经区间算术认证的单调性。最终仍须显式计算当前系统的真残差。

## 3. 历史 Galerkin 初值及秩截断的边界

设历史列矩阵为 \(V=[v_1,\ldots,v_p]\)，列向量仅来自已经完成的求解。若其列线性无关，则

\[
x_H=V(V^TAV)^{-1}V^Tb
\]

是 \(J\) 在线性空间 \(\mathcal S=\operatorname{range}(V)\) 上的唯一极小点，也是在该空间中与 \(x_*\) 的 A 距离最小的向量。它满足

\[
V^T(b-Ax_H)=0.
\]

对于任意 \(y\in\mathcal S\)，A 正交性给出

\[
\|x_*-y\|_A^2
=\|x_*-x_H\|_A^2+\|x_H-y\|_A^2.
\]

这是“当前矩阵上的历史子空间最优”，不是“所有可能初值中的最优”。当前代码优化的是经过原点的历史线性空间，不能未经说明改写成以某个已有初值为中心的仿射空间校正。只有当比较用的旧初值确实属于保留空间时，才能据此保证历史投影的误差能量不大于该旧初值。

实现先对有效历史列进行尺度归一化，再对小 Gram 矩阵 \(G=V^TAV\) 作特征分解。设保留的特征向量与正特征值为 \(U_+\) 和 \(\Lambda_+\)，则保留空间可写为

\[
\mathcal S_+=\operatorname{range}(VU_+),\qquad
Q=VU_+\Lambda_+^{-1/2},\qquad Q^TAQ=I.
\]

在精确算术下，该截断对应的初值是 \(x_+=QQ^Tb\)，最小化结论适用于 \(\mathcal S_+\)。按相对阈值删除的方向可能是数学上独立但数值上接近相关的方向；最多保留最近若干历史向量也会丢弃较早信息。因此不能把数值保留空间的最优性扩展到未截断的全部历史空间，也不能保证上一步解在截断之后仍精确属于保留空间。

零向量、无效列或未通过数值保护的候选会被丢弃；空空间对应零初值。因为零向量属于任意线性子空间，精确的保留空间极小点不劣于零初值的 \(J\)，但这不推出它不劣于任意给定的非零热启动。

## 4. 为什么可以继续使用普通 PCG

记预条件器的实际作用为线性算子 \(C\)，它近似 \(A^{-1}\)。普通 PCG 的标准前提是当前系统 \(A\) 对称正定，且在这一次求解中 \(C=C^T\succ0\) 保持固定。等价对称系统为

\[
(C^{1/2}AC^{1/2})y=C^{1/2}b,\qquad x=C^{1/2}y.
\]

神经网络和历史投影仅用于 PCG 开始前构造初值。初值构造可以是非线性的；这本身不改变 PCG 迭代中固定线性预条件器的性质，也不因使用了网络初值就必须采用灵活 Krylov 方法。

不同序列时刻可以建立不同预条件器，关键是一次 PCG 内不改变它。使用首步矩阵构造的固定 SPD 预条件器作用于另一个当前 SPD 系统，在代数上仍符合这一前提，但可能非常低效。冻结插值后重建当前 Galerkin 矩阵也必须完成相应光滑器与粗解设置，并在进入 PCG 后保持固定。

对称光滑、适当的粗空间秩与粗解等条件是分析 SPD 预条件器构造的组成部分。不能仅凭配置项名称含有 `symmetric` 就宣称任意实现一定满足数学假设；算子作用、对称性、正性和残差检查提供实现证据。有限个随机向量上的正性测试仍不是对所有向量的严格证明。本文件也不由这些性质推导对比度无关或网格无关的条件数界。

## 5. 较好的初值为何不保证更少迭代

误差能量 \(\|e\|_A\) 与欧氏真残差 \(\|r\|_2=\|Ae\|_2\) 是不同指标。一维能量线搜索一般不会同时最小化二者，因此能量下降不自动推出欧氏残差下降。

即使两个指标都下降，也不保证 PCG 所需迭代数更少。一个简单的精确算术反例是 \(A=\operatorname{diag}(1,4)\)，使用恒等预条件器。取两种初始误差

\[
e^{(1)}=(1,0)^T,\qquad e^{(2)}=(0.1,0.1)^T.
\]

第一种误差的能量平方为 1、残差范数为 1；第二种分别为 0.05 和 \(\sqrt{0.17}<1\)。但第一种误差只沿一个特征方向，CG 一步即可消除；第二种含两个不同特征方向，一般需要两步才能精确终止。对足够严格且两者初值均未满足的共同停止阈值，也可以出现同样的迭代次序。

标准条件数估计会把当前初始能量误差作为乘性因子，因此较小初始误差可能改善一个上界；它不在不同误差谱分布之间给出实际迭代次数的单调排序。有限精度、真残差刷新与最终停止判定还会影响观测次数。

即使迭代次数减少，端到端时间也未必减少。特征构造、历史投影、推理、CPU/GPU 传输与同步、方向处理、当前矩阵作用和线搜索均有成本。必须比较这些新增开销与实际减少的求解成本，并保留失败恢复时间。单独的推理耗时、初始残差比或迭代节省不能代替完整序列计时。

## 6. 两种训练损失及其解释限制

令基础初值为 \(x_0\)，真实校正为 \(\delta_*=x_*-x_0\)。取仅由可用输入决定的正尺度 \(s\)，训练标签为 \(t=\delta_*/s\)，模型输出为 \(\widehat t\)，对应物理方向 \(d=s\widehat t\)。特征中的基础初值必须与标签使用相同的 \(x_0\)；不能用真实当前解决定归一化尺度。

代码使用的相对能量损失为

\[
L_E=\frac{\|\widehat t-t\|_A^2}
{\max\{\|t\|_A^2,\varepsilon\}}.
\]

当分母下限没有激活时，它等于未做线搜索的物理校正相对误差能量平方。分母下限激活时，仍然是明确的训练目标，但不能继续当作通常的相对误差；同时，固定下限会破坏任意缩放下的精确不变性。这个损失衡量当前离散误差，不直接衡量最终求解时间。

令 \(D=\operatorname{diag}(A)\)，对角加权残差项为

\[
L_R=\frac{[A(\widehat t-t)]^TD^{-1}[A(\widehat t-t)]}
{\max\{(At)^TD^{-1}(At),\varepsilon\}}.
\]

其分子是 \((\widehat t-t)^TAD^{-1}A(\widehat t-t)\)，不等于欧氏残差平方，也不等于能量误差平方。若记 \(H=D^{-1/2}AD^{-1/2}\)，对任意向量 \(v\) 有

\[
\lambda_{\min}(H)\,v^TAv
\leq v^TAD^{-1}Av
\leq\lambda_{\max}(H)\,v^TAv.
\]

这一有限维比较说明两个二次型相关，但谱常数可能随网格与系数变化。残差项在该缩放意义下更强调高谱分量；它没有自动获得独立于对比度的控制，也不是实际 PCG 时间的替代证明。

预定混合目标 \(L_E+0.1L_R\) 是可验证的训练选择。它可能改变预测的误差谱分布，也可能降低一种损失同时增加另一种成本。网络之后的线搜索、可选 Jacobi 处理和真实在线历史还会改变实际使用的初值，因此训练损失下降不自动意味着部署时更快。纯能量续训与混合损失续训须保持相同起点和预算，并在未参与训练选择的完整求解流程中比较。

## 7. 可以据此写入结果的结论范围

上述分析支持的是：当前 SPD 系统上的精确一维能量最小化、保留历史空间内的 Galerkin 最优性，以及固定 SPD 预条件器下普通 PCG 的兼容性。浮点实现仍需数值核验，实际性能仍需完整成本实验。

它不支持从“初值更准”“训练损失更低”或“某一步迭代更少”直接推导普遍加速，也不支持自动宣称方法创新、一般化能力或对比度无关收敛。最终应分别报告正确性、独立几何上的完整时间、失败与回退，以及网络带来的增量收益。
