# 本机试验的实际实现与复现说明

本文依据 `fields.py`、`numerics.py`、`learning.py` 和 `run_experiment.py` 的当前实现编写。它说明已经实现的算法与试验配置；性能结论以运行结束后保存的原始测量和报告为准。研究计划中的后续功能不应视为已经实现。

## 1. 离散问题与局部空间

求解单位正方形上的 `-div(k grad p)=f`，边界条件为 `p=0`。每个正方形单元沿西南—东北方向分为两个三角形，使用一次有限元。系数在正方形单元内常数。主试验每个方向 128 个单元，包含 16,129 个内部自由度，使用 `f=1`。

有限元刚度矩阵、局部矩阵、特征分解、正交化与最终线性求解使用 float64。另提供正弦制造解与平滑源汇右端，用于正确性和后续泛化试验。

主试验将区域分为 8×8 个核心子域，每个核心为 16×16 个单元，向各方向增加 2 层单元重叠。局部节点权重是该节点被覆盖次数的倒数，记为对角矩阵 `Xi`。实际局部矩阵为：

- `A_N`：仅组装子域内单元，在人工边界采用自然边界；移除物理 Dirichlet 边界节点。
- `A_D`：当前全局刚度矩阵对应自由度的主子矩阵。
- `B = A_N + Xi A_D Xi`：局部正定度量。

传统局部空间选取广义特征问题 `A_N phi = lambda B phi` 中不大于 0.06 的特征模式。纯 Neumann 子域的常数零模由这个谱空间包含；网络本身没有另外输出强制常数列。物理边界子域的局部矩阵可能已经正定。

全局粗空间由 `Xi Z_i` 的局部延拓列组成。预条件器包含局部 `A_D` 的精确 Cholesky 求解和全局粗矩阵的稀疏 LU 求解。局部因子在矩阵逐项相同时缓存复用；粗矩阵每个时刻重新形成并分解。每次 PCG 过程中预条件器保持固定。

## 2. U-Net 实际学习的内容

网络使用 3 个尺度，通道数为 16、32、64；卷积块包含两层 3×3 卷积、GroupNorm 和 SiLU，解码器采用双线性上采样和跳跃连接。输出 4 个候选方向，共 119,396 个可训练参数。

局部输入补零到 32×32，实际包含以下 6 个通道：

| 通道 | 实际定义 |
|---|---|
| 1 | 当前节点对数渗透率，除以固定的 `log(1e6)` |
| 2 | 当前与旧系数的节点对数差，除以同一固定尺度 |
| 3 | 旧空间欧氏正交投影矩阵的对角线 |
| 4、5 | 局部横纵坐标，线性映射到 [-1,1] |
| 6 | 有效自由节点掩码 |

节点对数渗透率由相邻单元对数值平均得到。第三通道通过旧基的 QR 分解计算，随同一子空间内的基变换保持不变；它是欧氏投影特征，不应描述为代码没有计算的加权投影特征。该对角表示不能完整表达旧空间。

网络在 float32 下计算输出，再转为 float64，并按 `1/sqrt(diag(B))` 缩放。将输出投影到旧空间的 B 正交补，删除数值相关列，得到最多 4 个补充方向。正交化包含两次旧空间投影、Gram 矩阵特征分解和最终 Cholesky 归一化。

监督标签是当前局部参考谱空间。损失为：合并旧空间与候选方向后，仍未覆盖的参考目标空间的 B 能量，除以目标维数。训练时使用 `1e-6` 的小型 Gram 矩阵正则化避免求解退化；在线接纳仍使用独立的谱检查。

训练配置为 AdamW、初始学习率 `1e-3`、权重衰减 `1e-4`、50 轮、批大小 16、余弦学习率衰减至 `1e-5`、梯度范数裁剪 1。检查点按最小验证子空间损失选择，没有用测试序列计时选择模型。训练记录同时保存“完全不补充方向”的平均损失，便于判断学习损失下降的实际幅度。低平均损失不代表最困难方向已被覆盖，也不自动意味着在线接纳或求解加速。

## 3. 数据、划分与部署分布差异

通道几何先在固定 32×32 设计网格生成，再复制到细网格。同一种子在不同细网格上代表同一物理几何。`mixed` 序列结合局部渗透率漂移、夹杂物移动、通道连接和堵断，系数始终为正。

当前数据集按整条序列划分：

| 用途 | 整体几何种子 | 系数对比度 | 实际局部样本数 |
|---|---|---|---|
| 训练 | 100–147，共 48 条 | 根据种子轮换 `1e2、1e3、1e4` | 565 |
| 验证 | 10000–10011，共 12 条 | 同上 | 144 |
| 主试验测试 | 90001、90002、90003 | `1e4` | 每条完整运行 20 步 |

训练从第 5、10、15、19 时刻选取局部变化样本，旧空间来自此前 1、3 或 5 步；每对时刻最多选取 3 个局部区域。训练标签没有使用全局压力解。数据清单记录完整种子和系数序列哈希，并在测试时检查种子交集及完整序列重复。

训练旧空间来自直接特征分解；在线旧空间可能包含此前已接受的学习方向，并可能已经多次复用。这是目前的部署分布差异。代码尚未实现按在线轨迹重新收集训练数据的迭代训练方案。

主试验使用 3 个模型初始化种子：7、17、27。每个测试几何和方法配置重复计时 3 次。重复计时不是独立几何样本；三个模型种子也不能当成额外的独立 PDE 几何。

## 4. 接纳检查和复用

接纳阈值为 `gamma=0.03`，直接谱空间的构造阈值为 `0.06`。旧空间首先通过局部系数比得到保守续用界；系数比较区域包含子域外一层单元，因为 `A_D` 的边界对角元会受到这些单元影响。若续用界达到 0.03，则直接复用。

否则检查完整矩阵

`L = A_N - gamma [B - BZ (Z^T B Z)^(-1) Z^T B]`。

先按 `diag(A_N)+diag(B)` 作对角合同缩放，再检查最小特征值是否不小于 `-5e-10`。这里检查的是完整矩阵，不能替换为只在旧空间正交补上计算 `A_N` 的 Rayleigh 商；对任意学习空间，这种替换会漏掉交叉项。

旧空间检查失败后，候选方法生成补充方向，再执行同样检查。候选失败时，直接用当前的参考谱空间替换该局部空间。直接特征重建的接纳依据是求得的完整低特征值空间；主循环没有再对每次重建额外执行一遍相同的最小特征值检查。检查返回值、容差、局部空间维数和耗时保存在逐步测量的 `check_diagnostics` 中。

另提供 LDL 惯性检查选项；接近舍入精度的模糊枢轴会回退到特征值检查。主试验采用 `eigen`。这两种实现都是浮点数值检查，不是区间算术认证。当前实现也没有据此完成全局、对比度无关的 Schwarz 条件数定理。

当前原型没有单独的学习空间压缩策略；接受候选时会增加局部列数，谱回退时会用参考空间替换。极长序列中的空间增长仍需另行研究。

## 5. 五类对照与计时口径

| 命令行方法 | 实际算法 |
|---|---|
| `amg` | 每步构造 PyAMG smoothed aggregation，使用对称 Gauss–Seidel 和 V 循环 |
| `spectral_full` | 每步重新求所有局部谱空间，未变的局部 Cholesky 因子仍可复用 |
| `spectral_reuse` | 系数界复用、旧空间检查、必要时直接局部谱重建 |
| `smooth_increment` | 同一复用与检查流程，候选为 4 个随机向量经 8 步阻尼 Jacobi 平滑后的方向 |
| `unet_increment` | 同一复用与检查流程，候选来自 U-Net |

各方法使用自己上一步达到停止精度的压力解热启动。参考压力不传入任何在线方法。方法执行顺序按确定性随机排列变化，以减轻顺序偏差。

`total_seconds` 包含当前实现实际执行的矩阵组装、所有局部矩阵构造、复用判断、候选生成、正交化、检查、回退、粗矩阵构造与分解、PCG 和最终真实残差检查；包含首步初始化。`setup_seconds` 内含局部因子和粗矩阵设置时间，不能再把它与这两个子项重复相加。逐步输出写盘和事后误差评估不属于在线求解计时。

参考解逐时刻用稀疏直接法计算，其时间单独保存。在线方法全部完成后计算相对能量误差。数据生成和训练是离线成本，也单独报告。

BLAS 在主程序中限制为单线程；本机 PyTorch 使用两个线程。主实验使用 CPU，没有可用 CUDA。`--device` 参数存在，但 GPU 端到端性能没有由本次 CPU 试验验证。AMG 配置是固定基线，尚未穷尽调参；传统局部谱回退使用直接特征分解，尚未使用优化的旧特征空间迭代求解器。这些限制会影响对绝对性能优势的解释。

AMG 的 `coarse_dimension` 表示其最后一层大小，而 Schwarz 方法的同名字段表示整个两层粗空间的列数，二者不能直接作为同一种粗空间成本指标比较。

## 6. 正确性与失败记录

停止条件使用显式重算的相对残差 `||b-Ap||/||b|| <= 1e-8`，不只依赖迭代器的状态码。若递推残差与真实残差有差距，最多进行 3 次残差刷新续算；总迭代预算仍为 1000，所有续算均计入耗时和迭代数。

迭代仍未达到要求时，保留失败指标，并计时进行稀疏直接求解回退。最终残差和最终是否满足阈值另外记录，不能把回退后的成功误写为 PCG 原本成功。

现有测试覆盖：有限元制造解网格收敛、常数载荷积分、节点映射、分区权重、局部矩阵正定性、谱空间接纳、预条件器对称性和正性、高对比解与直接解比较、因子缓存、真实残差刷新、完整矩阵检查的反例、零模、增量正交化，以及学习损失与独立投影公式的一致性、基变换不变性和梯度。

这些验证区分了实现正确性、离散线性系统精度和连续 PDE 的离散误差。主试验中较小的线性系统误差不等于已经完成高对比界面问题的完整网格收敛研究。

## 7. 支持的运行命令

以下命令在代码目录 `experiments/darcy_incremental` 中运行。应使用已安装 `requirements.txt` 所列依赖的 Python；本机使用 `/home/user/miniconda3/envs/mini-rl/bin/python`，默认系统 Python 不含所需科学计算依赖。

```bash
export OPENBLAS_NUM_THREADS=1
export OMP_NUM_THREADS=1
export MKL_NUM_THREADS=1

python -m unittest test_fields test_numerics tests_audit -v

python run_experiment.py data \
  --n 128 --steps 20 --core 16 --overlap 2 --gamma 0.03 \
  --train-sequences 48 --val-sequences 12

python run_experiment.py train \
  --epochs 50 --batch-size 16 --model-seeds 7 17 27 \
  --directions 4 --device cpu --torch-threads 2

python run_experiment.py benchmark \
  --n 128 --steps 20 --core 16 --overlap 2 --gamma 0.03 \
  --contrast 10000 --family mixed --rhs one --check eigen \
  --rtol 1e-8 --maxiter 1000 --directions 4 --smooth-steps 8 \
  --test-seeds 90001 90002 90003 --model-seeds 7 17 27 \
  --repeats 3 --device cpu --torch-threads 2 --run-name pilot_cpu
```

数据命令写入 `data/pilot.pkl` 和对应清单；训练命令写入模型检查点和训练历史；测量命令写入 `results/<run-name>/`。在复现实验时，更改数据网格、局部划分或阈值后应重新生成与训练对应模型；当前命令行没有自动验证所有跨阶段参数一致性。可用 `--methods` 选择上述方法的子集。已有同名输出会被更新，需要保留旧结果时使用新的运行名称。
