# 第十五阶段A：数值基础资格检查协议

日期：2026-11-20。状态：运行前制定；实际执行时保存代码、协议和配置摘要。父方案见[第十五阶段设计](stage15_design_zh.md)。本轮完成其中首项可交付工作：制造解、材料对齐、多层网格、P1/P2富集DWR的数值核验。它不是整套两周审查完成，也不是AI对比实验。

## 1. 范围与避免误判

仅使用六个确定性制造解：常系数、平滑指数系数、交替分层高导材料对比度10/100/1000，以及对比度1000的低渗分层。各层界面x=.25/.5/.75与初始网格对齐，材料函数不随网格加密而重采样。分层解和载荷由父方案公式给出；平滑例取k=exp(.5x+.25y)、u=sin(πx)sin(πy)。制造载荷随材料变化，因此这些例子不代表独立物理查询分布，不用于学习泛化或成本优势推断。

三个观测采用归一化紧支撑tensor权重，中心(.25,.25)、(.75,.25)、(.5,.75)，半径.22；一维权重为max(1−s²,0)^4/(.22×256/315)。解析解的目标值由分段一维Gauss积分独立获得，64点与96点交叉核对。目标可解释为三个区域的加权平均压力。

引入固定版本scikit-fem 12.0.2，仅负责三角网格、P1/P2基函数与装配；主线性求解复用第十四阶段的实际残差和后向误差验收。库与官方说明：[发布记录](https://pypi.org/project/scikit-fem/12.0.2/)、[API](https://scikit-fem.readthedocs.io/en/stable/api.html)。该库的成熟网格接口不自动保证本项目DWR正确，仍需独立核验。

## 2. 预定矩阵

- 六案例×n=8/16/32/64/128，共30个均匀网格上下文；每个分别装配P1和P2，同一10阶三角求积，求解主问题及三个伴随，共用一次分解。
- 每个案例在n=128的P2上另用18阶求积，核对目标与载荷积分敏感性。
- 每例n=64的P1/P2各核验一次缩放AMG，与直接法相同验收，共12次AMG调用。该比较检验求解正确性，不是完整速度排名。
- 每例从n=8出发执行3轮局部细化（4个网格状态），只验证网格对齐、系统一致和富集恒等式；标记规则及可用局部化版本随最终配置冻结。不从解析真值选择标记或提前停止。

采用1线程BLAS，所有实际装配、求解、估计工作记录时间。诊断时间只有一次测量，不用于速度优势的统计推断。模型训练数为0。

## 3. 运行前验收条件

输入尺度U=1/k_min，仅由材料给定。τ=1e−5 U用于参考精度核查，不是部署自适应停止门槛。

| 检查 | 准入条件 |
|---|---|
| 解析目标积分 | 64/96点目标差≤1e−12 U |
| 制造解边界/界面 | 独立测试零边界及单侧法向通量连续；无未解释跳跃 |
| 数值线性求解 | 所有直接/AMG记录满足原矩阵相对残差≤1e−9、分量后向误差≤1e−12且求解状态成功 |
| P1/P2嵌套 | 同求积下PᵀA₂P=A₁、Pᵀb₂=b₁的相对差≤1e−11 |
| DWR恒等式 | 包含代数项后，与同网格P2−P1目标差的最大差≤1e−10 U；弱局部总和、强/弱全局差与代数分解差也各≤1e−10 U |
| 最细两级收敛阶 | P1 L2≥1.8、能量≥.85；P2 L2≥2.7、能量≥1.7；低于舍入分辨率则单独记录不可判定，不强行计算 |
| 最细P2目标参考 | 与解析目标的绝对差≤0.1τ；18阶与10阶求积得到的目标差≤.01τ |
| DWR效能 | 最细P1目标真误差显著大于舍入量时，估计/真误差逐目标在[.9,1.1]；近零分母单列，不删除 |
| 局部细化 | 无跨越已知材料层的单元；边界与面积合规；每轮嵌套/DWR/线性验收仍通过 |

这些门槛只评价本轮平滑/对齐制造解，不证明不对齐双包含体、高对比任意拓扑、误差认证或学习机会。若出现失败，保留原始行、失败原因和原门槛；修复实现后用新目录再运行，保留此前记录。

## 4. 代数、求积和局部化

同空间粗伴随残差配对只在代数解足够准确时近零。DWR须同时记录R(z₂−I_Hz₂)与R(I_Hz₂)；故意扰动主解的独立测试必须识别不能省掉的代数项。

P1/P2使用相同求积以隔离离散恒等式；另加高阶求积检查，防止“自洽但共同有偏”。单元弱式贡献的和可用作恒等式核验，但不据此声称逐单元排序最佳。若实现体/面局部化，须核对通量跳跃符号、两侧分摊和全局残差一致性，并区分不同合法局部化。

## 5. 输出与下一步条件

保存`freeze.json`、逐上下文数值和求解诊断、局部细化轨迹、独立报告、图表、测试日志及哈希清单。报告由原始记录独立聚合，不依赖人工挑选案例。

24个局部细化网格状态保存网格坐标/连接及强式局部贡献；18次实际决策另存分数和选中单元，报告程序重新计算Dörfler规则并重建下一网格。均匀网格的大数组只保留摘要及哈希，完整重算需运行复现脚本；不把哈希本身称为独立数值复核。

本轮通过只批准继续构建强经典基线：下一步仍需未对齐材料积分、真实源/目标分布、平衡通量与循环多目标方法，以及相同精度的完整成本比较。G1成本空间、G2可用信息和G3学习确认在本轮均为**未评价**，禁止用制造解上的DWR成本占比直接批准训练。
