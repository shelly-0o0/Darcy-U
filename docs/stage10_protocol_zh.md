# 第十阶段运行前协议：重新定义学习对象的结构消融

本阶段保留 Darcy 方程，停止继续微调此前低秩方向或容差策略。问题改为：**在相同训练数据和训练预算下，硬保持线性、互易性与正性的残差误差算子，能否比同骨架的无对称约束和非线性模型，更准确地预测新系数、新目标组合的粗细网格离散误差？** 这是可证伪的结构假设，不是已成立的创新，不是完整自适应算法或加速实验。原有九阶段文件保持原样。

## 数学对象

二维单位正方形，零 Dirichlet 边界，`-div(k grad u)=f`，k>0。粗 P1 网格每边16个方格，细网格32，每个方格沿SW→NE对角线拆成两三角形。P是真正的三角形分片线性插值；`Ac=P.T Af P`，粗载荷和目标均用P转置限制，避免重新离散系数/积分不一致。测试另用32/64网格，网格数表示方格数。

令`r_f=f−Af P Ac^{-1} P.T f`，`r_g=g−Af P Ac^{-1} P.T g`。细离散目标差等于 `r_f.T Af^{-1} r_g`。误差算子 `E=Af^{-1}−P Ac^{-1}P.T` 为半正定；本阶段以四个右端共同作为源项/目标，形成4×4误差矩阵。标签为`delta_g=Af^{-1}r_g`，不是整场解，也不是迭代次数或时间。

该恒等式针对同一嵌套离散系统，不等于连续真误差。`r_f.T P=0`，因此给预测伴随添加昂贵的粗空间消除投影不会改变全局误差估计；本模型不加入这一无直接全局收益的层。局部指标使用固定的元素弱残差分解，不能将任意重分配后的标记分数当成全局误差改善。

## 三个模型与共同预算

系数支路的三个输入是节点平均log(k)/log(20)、去均值log(细矩阵对角)、节点物理坐标到最近边界的距离。它们不依赖源项或目标。系数支路为3×3卷积→SiLU→3×3卷积，宽8；softplus门控加1e-4。残差支路三层3×3分析卷积，步长1/2/2，各8通道，零填充，无bias；插值仅用于系数门控。

主候选`symmetric`使用精确转置卷积合成，

`Hθ = D^{-1/2} [ diag(g0) + Σ_l exp(s_l) C_l.T diag(g_l) C_l ] D^{-1/2}`。

所有g严格为正，细层正对角底项保证Hθ正定（有限参数的实数运算意义），输出`delta_hat=Hθ r_g`。预测误差为`r_f.T Hθ r_g`，对源项和目标双线性、互易，对f=g非负。这些性质不保证预测准确，也不提供误差上界。float32实测会有舍入误差。

`untied`使用独立可训练合成卷积，仍对残差线性，移除互易/正性保证。`nonlinear`在untied的分析和中间合成支路加入SiLU，移除线性保证。三个模型同尺度、宽度、训练数据、epoch和优化器；untied/nonlinear参数更多，报告实数，不声称等参数量。它们是本项目内部消融，不是对E2N、SuperAdjoint或Neural Green's Operators的完整复现。

共同训练损失为：每右端相对A能量误差的平均，加0.25倍误差矩阵逐项均方误差（分母为两个对角真误差之积）。矩阵标签只来自训练或验证数据。固定mesh尺度nfine²用于数值缩放，不使用目标相关归一化改变线性。

每模型60轮，AdamW学习率0.002、weight_decay=1e-5，余弦衰减到1e-4，梯度范数裁到10；每批4个几何、每几何4个右端。三个初始化种子51001/51002/51003，依次训练三种模型，共9个模型。按验证总损失选epoch，不能根据最终测试挑模型种子、改loss或扩训练。正式前可运行独立smoke检查程序错误；smoke不是性能证据。

## 数据与划分

每个k由一个圆、一个矩形的高值区域和低幅平滑背景组成。位置/大小/背景相位按几何种子固定，ID对比度从5/20取值，OOD为100/1000。载荷为峰值1的高斯，中心在[0.2,0.8]^2，宽度在[0.08,0.18]。四个载荷由该几何另一个确定性随机流产生，独立几何而不是四个载荷作为统计单位。

- 训练64个几何：50000–50063；验证12个：50100–50111。
- ID测试16个：50200–50215；高对比OOD另16个：50300–50315。
- 窄载荷测试复用ID的16个几何（四个源项与目标一起变窄，不是固定源项的纯目标泛化），宽度[0.025,0.045]；分辨率测试同样复用ID几何、改用32/64网格。后两者不是32个新的独立几何。
- 每测试几何额外检查固定组合权重`[1,-1,0,0]`、`[.5,.5,-.5,-.5]`、`[-3,0,0,0]`、`[0,10,-5,1]`。组合不进入训练/验证。相同系数下改变目标必须重新推理，不能人为用线性组合输出冒充网络结果。

训练/验证构造和所有checkpoint冻结之后才生成测试实例并评价。记录系数哈希、参考残差、Galerkin残差、矩阵互易误差；训练/验证/测试无重复系数（测试三个变体可复用同一ID系数）。源码、协议、配置在正式运行开始写入freeze，结束核对，无修改后沿用原结果。

## 对照、指标和判读

经典对照为一次Jacobi、八次阻尼Jacobi（omega=2/3）、固定配置的一次对称AMG V-cycle。它们在完全相同残差上估计伴随缺陷，不用参考解作初值。精确细解作为参考。全部经典对照都报告，不按测试实例选最快/最准的一项作主对照。

主指标是每几何4×4误差矩阵的相对Frobenius误差；另报经两个真误差能量归一的矩阵RMSE、伴随缺陷相对能量误差、符号组合误差、线性/互易性缺陷和预测矩阵对称部最小特征值。先对同几何三个训练种子取中位，再跨几何汇总；三个种子不是三倍独立测试样本，并保留逐种子结果。

混合目标同时保存权重、原始真/预测矩阵、原始源项对混合目标的交叉矩阵，以及逐组合的线性缺陷和能量尺度归一RMSE，避免幅值10的组合掩盖抵消目标。经典对照对同样混合残差重新计算，使用完全相同指标。参考标签须有限、正对角、相对容差1e-10内半正定，Galerkin残差≤1e-8、参考缺陷方程相对残差≤1e-8、互易误差≤1e-9；任何不合格则停止，不删除实例。训练后测试前及全部结束时均重新核验源码、协议和checkpoint哈希。

次指标是固定源项为该几何的第一个载荷，对四个目标分别选绝对预测局部指标最高25%粗单元，捕获的真指标绝对质量相对“相同数量、按真指标选取”的比率；另报固定分解的局部指标L1误差。它只是固定网格上的标记一致性，不是局部细化后误差下降率。本轮没有自适应闭环。

事前支持标准：symmetric相对untied的逐几何主指标比的中位数在ID及至少一个OOD测试均≤0.9，其余OOD不超过1.1，且线性/互易缺陷≤1e-5、相对最小特征值≥−1e-5。此10%是本轮结构贡献的开发判据，不是论文显著性标准；不能据此宣称新颖性或Q1可发表。与nonlinear、经典方法的全部结果照实报告；如果AMG更准，不得只展示较弱Jacobi。

未满足此标准时，不宣称硬结构带来准确率优势；保留有用的数值一致性保证，依据具体失效诊断表示能力、训练目标或泛化问题。不得为了过线即时换种子、宽度或测试样本。若结构正确但精度明显落后经典对照，下一步应先解释误差模式和机制，不能直接扩大为大规模AMR或宣称应用收益。

## 成本与研究边界

记录数据生成和训练成本，但本轮不以推理时间作性能结论，不给完整求解加速比。学习器仍需粗解、细算子/残差及系数特征；不能声称不构造富集空间。未来计算成本试验必须包含这些准备、CPU/GPU传输、推理、细化与重求解，并比较局部恢复、经典AMG、细网格直接解等强对照。

固定一个源项、多个目标时，经典方法只需解一次细网格主问题/主缺陷，就能回答所有线性目标；不能把“每目标各做一次细伴随”作为唯一成本对照来制造多目标优势。E2N、SuperAdjoint、Neural Green's Operators及对称学习预条件器已有直接相关设计。本轮建立可测试原型，具体创新位置仍待完整方法对照和新证据。
