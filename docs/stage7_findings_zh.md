# 第七阶段结论：持续作用减少迭代，但仍未获得完整加速

本轮完成了第六阶段提出的在线验证：只在首步提取一次四维空间，此后也在跳变步持续使用。**迭代减少得到确认，完整时间优势没有得到确认。** 主候选在128/256网格相对SciPy强基线的逐几何时间比为 **1.060527 / 1.102328**，分别慢约6.1%和10.2%。本阶段没有训练或调用AI，不能将其写成新的AI模型或AI加速结果。

## 设计与完成情况

运行前固定五种方法：SciPy基础PCG、事件步自实现基础PCG、首步空间仅在非事件持续作用、首步空间在所有后续步持续作用、首步空间在所有后续步仅修正初值。唯一主候选预定为 `frozen_all_balanced4`，开发只检查数值资格，未按时间改选；确认完整保留五种方法。

三个回收方案各自支付首步采集和提取成本。之后源空间只读且不再更新，每个系统按当前A正交化、投影，并按预定策略使用固定平衡B或基础M。后续事件的自实现PCG实际接收所选B/M，但采集容量为零，因此没有把BA缓存当作MA的问题。

**88项测试通过**，其中6项新接线检查包含5方法×20步、共100次小网格求解，使用实际算子对象身份检查及独立真残差重算。正式记录中的 `solver_operator` 核验策略与日志一致性；正式计时未额外逐次加入对象身份检测，实际接线证据来自源码审查和前述功能测试。

三个新开发几何共600次求解；另五个确认几何在128网格各重复三次，256网格使用其中前两个，共2100次确认求解。**全部2700次正式求解达到1e-8真残差，最大9.989423e-9**，无PCG失败、直接恢复或整空间缓存拒绝。81次提取全部位于首步，后续采集和提取均为零；27组同网格/几何/重复中，三个回收方案的首步空间字节哈希全部一致。哈希在完整序列计时后计算，仅用于审计。

## 冻结确认结果

| 方法 | 128网格完整20步中位秒数 | 128迭代中位数 | 256网格完整20步中位秒数 | 256迭代中位数 |
|---|---:|---:|---:|---:|
| SciPy AMG-PCG+历史四解 | 0.563931 | 532 | 2.919033 | 671.5 |
| 事件步自实现PCG，无回收 | 0.568904 | 532 | 2.937222 | 671.5 |
| 首步空间：事件仅初值、非事件持续作用 | 0.602245 | 480 | 3.175113 | 602 |
| **首步空间：所有后续步持续作用（预定主候选）** | **0.596234** | **455** | **3.218154** | **564** |
| 首步空间：所有后续步仅修正初值 | 0.613421 | 527 | 3.159209 | 665 |

所有费用按完整20步求和，再取同几何重复中位数，最后汇总几何。下面的比值先在几何内配对，不能用上表两个汇总中位数相除代替。两组最快有效基础方法均为SciPy，固定同一种基础方法用于组内比较。

| 主候选 / 对照的逐几何时间比中位数 | 128 | 256 |
|---|---:|---:|
| / SciPy基础方法 | 1.060527 | 1.102328 |
| / 自实现基础方法 | 1.057000 | 1.095590 |
| / 事件仅初值、非事件持续作用 | 0.991632 | 1.013419 |
| / 全步仅修正初值 | 0.976374 | 1.018687 |

主候选在所有确认几何均慢于两种基础方法：128为0/5更快，256为0/2更快，均未达到预定20%节省工程线。相对事件仅修正初值的匹配策略，主候选在128只有3/5更快，256为0/2；相对全步仅修正初值，则为5/5与1/2。因此只能说本批数据中迭代收益较一致，不能说持续作用产生稳定完整加速。

## 迭代节省为什么没有转化为时间节省

与事件仅修正初值的同空间策略相比，主候选在后续事件的配对迭代比为 **0.875000 / 0.875668**，约少12.5%。但后续事件配对总时间差为 **−0.003260 / +0.070591秒**，完整序列为 **−0.004681 / +0.043041秒**。各方法沿各自数值历史推进，不能把完整序列差值解释为完全相同后续轨迹下的单次算子因果效应。

与SciPy基础方法相比，完整序列的配对成本差为：

| 费用差：主候选−SciPy，秒/完整序列 | 128 | 256 |
|---|---:|---:|
| 总时间 | +0.035556 | +0.299121 |
| 当前空间处理、投影和B构造 | +0.030896 | +0.139220 |
| 其中首步提取（维护子项） | +0.016967 | +0.091156 |
| PCG求解 | −0.011537 | +0.070338 |

这些是分别聚合的配对中位差，不能相加代替总时间差。256网格不仅有提取和设置负担，PCG求解部分也更慢，说明减少的迭代没有抵消所测接口增加的每次求解工作。尚未做逐算子硬件剖析，不能据此把问题归因于某个特定内核或访存热点。

另做一个明确标为事后的成本情景：固定每次已测轨迹，从完整时间中扣除全部 `correction_seconds` 与 `extraction_seconds`，再按同样的重复、几何和固定基线规则聚合。对SciPy的时间比仍为 **0.976230 / 1.023371**，没有达到20%节省线。这个情景只删除设置与提取费用，没有删除B在PCG中的应用成本；它不是可执行算法、最优方向上界或一般时间下界，也没有用于选择主候选。

## 研究决策与下一项最小实验

暂停围绕当前首步冻结四维空间扩大AI训练，也不继续把仅压低提取费用当作主要突破口。现有证据支持下一阶段同时诊断方向质量与完整成本，不能只用迭代数或子空间覆盖率评价网络；本轮并未证明方向、实现和接口必须同时改善才能产生收益。

下一问题建议固定为：**在当前PDE序列上，当前系统的更高质量近似慢空间，经过同一固定平衡接口并支付全部在线应用费用后，是否能留下足够的方向构造预算？** 这是训练前的预算诊断，尚未执行。

1. 在新的开发几何上离线构造当前系统的近似慢空间，单独记录构造费用与质量；这些方向可使用当前已完成轨迹，只能作事后参考，不能宣称为因果在线方法，也不能视为全体方向的最优上界。
2. 使用这些预存方向测量完整求解路径：保留组装、历史初值、AMG刷新、当前A正交化、投影、每次B应用、真残差与维护费用。只把参考方向的取得费用单列。与同轮强经典基线配对，计算达到20%工程线所剩的构造预算 `0.8*T_baseline − T_reference_path`。
3. 若这个特定高质量参考仍没有正预算，优先重新评估当前问题设置和接口，不启动大规模网络训练；若有正预算，再比较同预算经典更新与轻量学习预测。未来任何学习结论都必须加入实际特征、推理、传输、保护及失败恢复费用，并使用新的冻结确认几何。

本轮只有五个独立确认几何、单一右端和单一对比度，不支持普遍否定学习空间；同样也没有建立模型新颖性、AI优势或期刊录用依据。阶段1–6源码、协议与原始结果均保持不变。
