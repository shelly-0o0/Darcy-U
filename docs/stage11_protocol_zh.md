# 第十一阶段运行前协议：相同新增自由度下的一次真实局部细化

本阶段检验：**冻结第十阶段误差算子，并统一去除粗空间分量之后，学习指标能否在相同新增自由度下，比经典方法取得更小的真实目标量误差，同时不增加完整计算成本？** 第十阶段的局部标记质量已接近饱和，不能再以该代理指标作为主结果。本阶段不重新训练、不挑选有利模型种子、不增加网络容量，不改写前十阶段的协议或结果。

本文件在查看正式结果之前编写，并依据正式冻结前的实现审查补齐恢复模板、精确预算选择细则、数值核验容差与计时边界。所有修订必须在正式运行前完成，并连同源码、配置、九个模型权重一并写入冻结清单。冻结后若发现程序错误，保留失败记录，修正后使用全新的输出目录；不得在原结果上修改协议。

## 问题、模型与独立测试集

沿用二维单位正方形上零 Dirichlet 边界的 SPD Darcy 问题。粗网格每边 16 个方格，指定细参考网格每边 32 个方格，每格沿 SW→NE 对角线拆为两个 P1 三角形。系数、载荷、三角形积分及真正的三角形延拓 P 沿用第十阶段；`Ac=P.T Af P`。所有误差均相对于这个指定细离散解，不是连续 PDE 误差或误差上界。

测试使用 32 个全新独立几何：ID 种子 52000–52015，高对比种子 52100–52115。ID 对比度从 5/20 取值，高对比从 100/1000 取值；几何、低幅平滑背景和高斯载荷采用第十阶段的确定性生成函数。每几何仍生成四个载荷，固定第 0 个为主问题源项，目标仅取第 1、2、3 个。三个目标共用一个细化网格和一次细化后的主问题求解；不把三个目标或三个训练种子当成新的独立几何。

固定载入第十阶段 `symmetric`、`untied`、`nonlinear` 各三个权重，训练种子 51001/51002/51003，共九个模型。`symmetric` 是事前主候选，其余是内部消融。保留各个模型的独立网格和结果，不集成三个种子的输出，也不根据测试表现选种子。检查训练、验证、历史测试及本阶段系数哈希，发现非预期重复立即停止；不得删除实例后补抽。

## 统一投影、多个目标和标记优先级

对三个目标形成细空间粗解残差 `r_j=g_j−Af P Ac^{-1} P.T g_j`。学习模型、Jacobi 与 AMG 均在这些残差上给出伴随缺陷预测。恢复方法从相同粗伴随解构造细空间修正。所有预测统一作用

`Q=I−P Ac^{-1} P.T Af`。

精确参考缺陷也核验其粗空间正交性。局部指标采用第十阶段同一个元素弱残差分解，以主问题源项 0 的粗解残差与投影后各目标缺陷配对，聚合至粗方格。投影是经典 Galerkin 操作，不作为 AI 独有创新。

三个目标的在线尺度固定为 `s_j=max(abs(g_j.T P u_c), 1e-12 max_l abs(g_l.T P u_c), 1e-30)`。载荷为正值高斯；仍检查尺度有限且严格正，非有限则停止。每个粗方格的标记优先级为 `p_K=sum_j abs(eta_K,j)/s_j`。尺度不依赖细参考解；不得用实际误差反馈调整目标权重。

## 真实细化与精确自由度预算

从同一粗网格出发，每种方法只执行一轮局部红细化。选中方格使用指定细参考网格上的四个子方格；非一致接口的边中点施加线性悬挂节点约束，边界保持零值。用稀疏嵌入矩阵 T 把适应空间表示在同一个细空间中，装配 `A_ad=T.T Af T`、`f_ad=T.T f`。不在不同网格上重新采样系数或改变积分，以免把模型差异与离散变化混合。

所有局部细化方法新增 **64 个独立内部自由度**；粗空间有 225 个自由度，适应空间必须恰为 289。直接细解独立列为预算外对照，具有 961 个自由度，即比粗解多 736 个，不能写成零新增自由度。相同标记方格数不等于相同新增自由度：选中方格中心各增加一个自由度，两个选中相邻方格的公共内部边中点再增加一个；边界中点不是未知数。因此预算按实际约束后的维数计数。

预算选择首先按优先级从高到低、稳定行优先编号处理，只有新增代价不超过剩余预算才纳入；新增代价为 `1+已选相邻方格数`。若无法恰好耗尽 64，自始构造两个棋盘奇偶子集：各取该子集中优先级最高的 64 个方格，再选择优先级总和较高者，完全相同则按固定奇偶顺序破同分。棋盘子集没有共享边，保证恰好新增 64 个自由度。记录所有回退、选中方格、精确新增自由度和 T 哈希。该程序是固定预算选择器，不保证最大化实际误差下降或优先级总和。实施若采用不同的确定性等价细则，须在正式冻结前明确修订本段。

最少核验包括：T 满列秩；零边界和悬挂约束成立；粗空间被适应空间包含；未细化重现粗问题，全细化重现细问题；适应矩阵对称正定；求解残差达标；适应解相对细参考的能量误差不高于粗解。运行容差固定为：适应／粗解能量误差平方比不超过 `1+1e-8`；细参考与适应线性求解相对残差不超过 `1e-8`；投影后粗正交归一残差不超过 `1e-8`；粗空间嵌入最大绝对误差不超过 `1e-12`。五次计时重复必须选中完全相同方格，三个目标值满足 `rtol=1e-12, atol=1e-15`。目标量误差没有同样的单调性保证，出现反而变差时必须保留并报告。

## 对照和离线诊断

- `jacobi1`：残差除以细矩阵对角。
- `jacobi8`：从零起八次阻尼 Jacobi，omega=2/3。
- `amg_v1`：沿用固定配置的一次对称 AMG V-cycle；设置成本必须计入。
- `recovery`：从粗伴随场进行固定的三节点张量积二次 Lagrange 插值。每个细节点的单轴坐标记为粗网格单位下的 t，取起点 `clip(floor(t)−1,0,nc−2)` 的三个连续粗节点；两个轴的权重作张量积，边界粗值为零，消去边界行列。以恢复插值与 P 的差作用于三个粗伴随场，再统一投影。每次在线运行重建恢复矩阵并计费，不使用最小二乘拟合，不声称通量守恒或误差认证。
- `geometry_uniform`：用种子 `52900+nc` 生成各粗方格的独立均匀随机优先值，所有几何采用同一组值，得到仅依赖粗网格分辨率的排列；使用同一个精确自由度预算选择器。它只求解必要的粗主问题，不生成粗伴随、伴随缺陷或 Q 投影。名称表示系数和目标无关的空间对照，不代表严格均匀细化。
- `oracle_indicator`：用三个精确细伴随缺陷得到指标，执行同一预算选择器。三次细伴随求解及共同细矩阵分解按实际计费；这是离线诊断，不进入可部署方法的通过门槛，也不是“实际目标误差最优网格”。
- `fine_direct`：直接装配并求解一次细主问题，然后评价全部三个目标。它不需要粗层、粗伴随、指标、细化或逐目标细伴随；不得额外强加这些成本。其离散参考误差为零，仅用作完整成本与准确性边界对照，不计算以零误差为分母的改善比。

对照方法不能根据每个测试实例的结果临时切换。AMG 是主要经典对照，Jacobi8 是事前固定的廉价对照；其余结果全部公开。

## 主结果、聚合与事前继续标准

对同一几何定义三个目标的签名粗误差 `e_c,j=J_j(u_f)−J_j(P u_c)` 和适应误差 `e_ad,j=J_j(u_f)−J_j(T u_ad)`。主指标是

`E=norm(e_ad/s,2)/norm(e_c/s,2)`。

同时保存三个目标的细、粗、适应值，签名误差、绝对误差、尺度、分母、缩放误差向量范数以及能量误差。向量范数不允许不同目标的正负误差互相抵消。若粗误差向量范数低于 `1e-12`，则仍保留该几何、报告原始绝对缩放误差并标记分母退化，主比值保存为 null，不用于过线，整个正式门槛自动判为不通过，不静默删除或更换该几何。配对比较的分母阈值同样预设为 `paired_denominator_floor=1e-12`，作用于经典对照的绝对缩放误差范数 `scaled_error_l2`；小于该阈值时保留原始误差、将配对比值设为 null，并使门槛不通过，不人为除以微小固定值来宣称收益。`fine_direct` 不作该误差配对比值的分母，其零离散误差不会触发可部署自适应方法的退化判定。

对于同一几何，学习方法先对三个训练种子的 E 取中位数，再形成相对经典方法的逐几何配对比值；最后对 16 个独立几何汇总中位数、范围、改善数及逐种子结果。不得用两个跨几何中位数相除冒充配对比值。三次训练种子和五次计时重复均不是独立 PDE 样本。

继续主候选 `symmetric` 的当前 AMR 分支，须同时满足：

1. ID 和高对比两组，相对 `amg_v1` 的逐几何配对 E 比值中位数均 ≤0.90；每组至少 12/16 个几何严格改善。
2. 每一个训练种子在每组中，相对 AMG 的逐几何配对 E 比值中位数均 ≤1.10，不用三个种子的中位数掩盖某一个种子的系统性退化。
3. 两组相对事前固定 `jacobi8` 的逐几何配对 E 比值中位数均 ≤1.00。
4. 两组相对 AMG 的完整在线耗时配对比中位数均 ≤1.00；数值核验全部通过，没有未解决的分母退化。

10% 是本轮开发决策门槛，不是显著性证明或论文接受标准。若只通过准确性而未通过耗时条件，只能称准确性信号，不称效率优势。其他模型即使较好也仅报告为消融结果，不在本轮把它换成事前主候选。保留逐几何结果，不仅展示汇总或最有利图片。

## 完整成本与重复计时

CPU 固定为一个计算线程；数值库线程配置与硬件、软件版本写入清单。每个方法执行五次从新问题对象开始的暖运行；每个几何以种子 `52991+geometry` 建立确定性随机流，每次重复分别生成全体方法的排列顺序，保留每次耗时并取中位数。正式计时前全部分支在单独的几何 52950 上预热。模型进程内加载与库初始化不混入每几何暖耗时，但模型载入及预热总成本单列。此处没有 GPU 推理或传输；不得从本机小规模 CPU 结果外推一般硬件速度。

完整在线路径包含：系数与全部所需载荷生成和装配、细矩阵装配、粗层构建、粗矩阵分解、源项及三个目标粗解、细残差及局部残差构造、特征构造与模型推理或经典方法设置和作用、Q 投影、局部指标与多目标聚合、精确预算标记、适应约束 T 构造、适应矩阵与载荷装配、适应矩阵分解和一次主问题求解、三个目标量评价。共用设置可在同一个方法的三个目标间共享，但不能因前一个方法已建过而免费使用。恢复矩阵缓存如可跨几何共用，须单列一次性构建成本及明确摊销口径；完整冷几何结果不得无说明省略。

`fine_direct` 独立计时其必要路径：系数、源项及目标载荷、细算子装配、一次细主问题分解求解和三个目标评价；不构建 P、Ac、不做粗层求解。离线参考解和核验在在线计时之外，不能将参考已有的分解拿来降低可部署方法耗时。精确指标对照的实际细伴随分解和三个求解单列计入该对照，不作为免费标签。

同时记录总墙钟时间、阶段分量、分量之和与未归类开销，报告共同准备和下游增量两种视角。所有准确性指标来自实际适应求解，不用预测指标代替真实收益；不得仅比较网络前向与 AMG 设置，也不得把对称模型推理时间称作完整求解时间。

## 失败判读与研究边界

若真实细化后学习方法与经典方法基本趋同，或完整成本更高，则结束当前“AI 局部标记带来额外收益”的分支，不再增加训练规模来追过线。结合精确指标、廉价对照、选择器回退、实际网格重合度和每目标误差，区分指标饱和、预算选择、参考尺度及推理成本等可能因素；不能凭单项现象认定唯一原因。

第十阶段的全局目标误差预测正信号可以作为另一项尚待检验的假设保留，但不自动转化为本轮成功，也不能跳过“一次细主问题求解回答所有目标”的完整成本比较。本阶段不声称多轮 AMR 收敛、连续误差认证、跨尺度泛化、已有方法全面领先、新颖性成立或国际一区可发表。
