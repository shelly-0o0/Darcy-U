# 第十四阶段冻结协议：共同求解标准与固定界面空间后的决策潜力

本协议在机制开发和正式确认运行之前写定。求解器实现只在独立开发数据上设计；本阶段不训练或调用 AI，不修改第十三阶段失败判定，不把离线参考选择当作可部署算法。

## 1. 两个问题与证据边界

1. 细直接解与 AMG-PCG 能否在**共同实际残差和分量后向误差标准**下通过全新确认数据？
2. 在系数排序的界面覆盖、界面一圈细化状态与新增自由度预算固定后，有限候选网格中是否还有值得研究的目标精度提升？

第二项的 oracle 需要全部候选实际求解和细参考，只能测定该 bank 的离线潜力。包含基线的最优值不大于基线是恒等事实，因此必须要求非平凡幅度与跨几何一致性。即使通过，也不能证明可学习性、新颖性、全局最优网格或同精度加速。

- 正式确认：ID 55200–55215，高对比55300–55315，各16几何；不参与开发或调参。

## 3. 共同数值要求和实际实现

`stage14_solver.py` 的 `solve_system(A,b,method)` 不读取参考解。direct 使用普通稀疏LU；amg 使用 `DAD y=Db,u=Dy,D=diag(A)^(-1/2)`、固定对称 AMG V-cycle，种子51700。首次CG相对容差1e-10；采用原系统的实际残差修正，最多2次，修正方程CG相对容差1e-3，每个RHS总迭代预算1000。修正复用同次调用已支付的分解或层级。

两方法以及适应、粗系统统一要求：

`||b-Au||₂/||b||₂ <= 1e-9`

`max_i |b-Au|_i / (|A||u|+|b|)_i <= 1e-12`

必须有限、全部线性求解info为0、最终converged为真。矩阵、分解和解仍为float64；仅用平台longdouble（当前64位有效尾数）计算原double矩阵的残差、后向误差和修正右端，同时保存double残差。不是重新高精度装配，也不是连续PDE误差证书。平台longdouble不宽于double时终止。

分量后向误差是经典数值量，其含义及残差修正见 [LAPACK DGERFS](https://www.netlib.org/lapack/explore-html/d5/da4/group__gerfs_gaf9908a6db85a278e5756cbded5f49819.html)；CG接口的残差与info约定见 [SciPy CG文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.sparse.linalg.cg.html)。本实现自行计算上述量，未调用DGERFS，不声称继承其误差界。

新的1e-9标准是基于独立开发的新实验规则，并额外检查逐分量误差；不能用于让第十三阶段补过。正式细AMG相对同批细直接参考的已知目标E还须≤1e-5。直接参考自身须通过共同数值规则。所有失败保留并阻断正式总判定，不换几何、不根据结果放宽阈值。

## 4. 两个固定干预

I为一个粗格内2×2细系数同时出现 `k>2` 和 `k<=2` 的格子。它识别当前两相生成器中穿过粗格内部的界面，遗漏只位于粗格边上的界面，不是所有界面长度的测度。

先用第十三阶段 `coefficient_scores + budget_mark` 得到基线选择S0。若它未覆盖全部I，保留该失败，整个正式gate不通过。记H=I及其上下左右一圈邻格。

- **主干预 locked_ring**：H内选中/未选状态均与S0一致，即mandatory=S0∩H，forbidden=H\S0；只在H外重新分配。I内中心和与四邻共享边中点的自由状态完全固定，不把额外释放界面边自由度当作远处调整的贡献。全局解仍相互耦合，不能说界面解值也固定。
- 次干预 coverage：只强制I全选，其他格可重排。其目标是区分固定二值覆盖与固定界面局部空间；它不排除释放界面边中点带来的作用。

两者用确定性seeded_mark：从mandatory开始，按分数降序、同分小索引优先，每格支付中心及与已选邻格共享边中点，禁止选forbidden。若贪心不能填满，退回原mandatory，选某一棋盘色上既不在mandatory/forbidden也不邻mandatory的格子；这些格相互不邻、每格恰增加1自由度。按分数和选择两棋盘中的较优者，同分取色0。若容量不足显式失败，不能移除mandatory或放松预算。保存fallback。

## 5. 每种干预的14个固定候选

全部分数由给定系数和四个已知函数构造，不含任何解、误差、审计目标或参考。base为第十三阶段系数变化分数；粗格中心计算各函数并以其网格最大绝对值归一化，source为源场、goals为三目标均值。

0. 原系数排序S0（两bank共有）。
1. mandatory条件下按base完成。
2. base×(0.25+source)。
3. base×(0.25+goals)。
4. base×(0.25+0.5×(source+goals))。
5. 全零分数，即同分按格索引的确定性完成。
6–13. 四个固定随机平滑场，各使用beta=0.5和1.5，将base乘exp(beta×field)。field为sin(2πx)、cos(2πy)、sin(2π(x+y))、cos(4π(x−y))的四个标准正态系数线性组合，网格均值去除、标准差归一后截断至[-3,3]；RNG seed=55600+17×geometry+seed_index。

14是slot数；重复网格保留并报告unique数量。同种子两beta及同一几何两个bank相互相关，不能视为独立样本。

## 6. 误差、选择器和取消效应

每网格实际装配与主解求解，求三个已知和三个审计目标，保存逐目标原值与带符号误差。对每个目标三元组分别取 `s_j=max(|J_j(u_c)|,1e-12 max_l|J_l(u_c)|,1e-30)`，E=缩放目标误差二范数/该组三个粗解误差的二范数。分母<1e-12标为退化，ratio为null，阻断相关通过判定，不能加floor假装有效。配对ratio也要求基线scalednorm或energy不小于1e-12。

平方再求和不会在三个目标之间相消，但单个目标内部可能存在空间误差相消。故同时报告max单目标缩放误差、每目标改善/恶化、审计目标和能量误差平方相对粗解。适应空间含粗空间，能量比须在[-1e-12,1+1e-8]。

各bank报告：index0系数基线、index1 seeded系数、index5确定性完成；已知目标offline oracle=最小known scalednorm（同值取较小index）；随机子bank oracle=6–13中最优；offline energy oracle=最小能量误差；随机8 slots均匀选择期望与去重后unique均匀期望。补充等3槽比较：启发式2/3/4最优 vs 随机6/8/10最优。仍不得把有限样本best-of-N写成学习收益。

## 7. 预定门槛与分支决定

先独立重建全部原始目标误差、选择器、预算、I/H状态、哈希与结构。所有正式数值检查、确认基线的三次重复、精确预算、覆盖和主干预H状态须合格；粗分母、基线误差分母非退化。基线重复选择相同、目标满足rtol1e-12/atol1e-15。

**有限bank潜力门槛**只对locked_ring判定：两组各自known oracle / 原系数基线的逐几何scalednorm比中位数≤0.8，且各至少12/16达到ratio≤0.9。数值/结构合格后才可称正式通过。另报告精度条件本身是否满足，避免将求解器失败误写为精度无空间。

**可转移稳健潜力门槛**更强：先通过上述门槛，再要求同一known winner在两组的审计scalednorm比中位数及能量误差平方比中位数均≤1.05，全部相关分母有效。max单目标误差只描述。coverage干预的同类统计仅作次要解释，不能替代未过的主干预。

这些是继续研究的开发阈值，不是显著性或发表标准。若主门槛失败，停止直接在此固定界面远处网格bank上训练选择器；总结限制后转向能产生实质精度空间的问题族/预算或不同研究目标。若仅coverage通过，优先研究界面邻域动作，不能宣称远场重分配有效。若主门槛通过而稳健门槛失败，只能解释为已知目标的特定收益；不宣称场质量或未见目标泛化。通过也不自动授权把oracle标签作为无成本在线算法。

## 8. 成本、复现与审计

三条基线为fine_direct、fine_amg、coefficient_local。每条每重复从新对象开始，完整包含系数、四载荷求积、实际矩阵、必要分数/预算解码、分解/AMG设置、求解及全部残差修正、证实和三个目标评价。共有32×3×3=288完整暖计时。单线程，随机方法顺序；不跨方法共享积分、矩阵、分解或层级。
