# 第九阶段运行前协议：非线性内层精度的有限机会筛查

本协议在正式数值验证、基线计时和分支诊断前冻结。第八阶段已停止Darcy低秩路线；本阶段不训练模型，只检查新候选是否值得继续。结果为开发筛查，不是独立测试或新颖性证明。

## 方程、离散与共同数值条件

单位正方形、零Dirichlet边界：`-eps*Delta(u)+beta·grad(u)+u+gamma*u^3=f`。每轴n个内部节点，h=1/(n+1)，扩散中心差分、常速度一阶迎风差分，beta=(1,0.5)。`f=A*exp(-((x-cx)^2+(y-cy)^2)/(2*0.15^2))+0.1*A*sin(pi*x)*sin(pi*y)`。

12个参数实例来自固定笛卡尔积：eps=[0.003,0.03,0.3]、gamma=[10,1000]、A=[5,50]，按该顺序编号0–11；中心由NumPy default_rng(47000+id)在[0.3,0.7]^2生成。所有实例在32、64网格复用，独立参数实例仍是12个。没有另设确认集，本阶段不能用于最终泛化声明。

初值为零，Newton最多50步，同一残差范数Armijo回溯（常数1e-4，步长折半，最多20次回溯）。最终未预条件非线性真残差不超过max(1e-10,1e-8*初始残差范数)。每个Newton步重新组装实际Jacobian；迭代方法全部使用当前Jacobian的ILU（drop_tol=1e-4,fill_factor=10）和GMRES（restart=50,maxiter=20个重启周期）。独立检查未预条件线性真残差，不能用回调的预条件残差替代。任何失败保留，不静默转直接求解，不降低精度要求。

七种固定经典策略：EW1、EW2、固定eta=0.01/0.1/0.5/0.9、直接Newton。EW初值eta0=0.5，上限0.9、数值下限1e-10；EW1为原文(2.2)的范数差绝对值规则并带黄金比保护；EW2为gamma_EW=0.9、alpha=2及原文保护。EW1线性化残差使用实际接受的阻尼步，所有策略采用同一Armijo流程，并不声称逐行复现原论文的全局化算法。公式来源与基线缺口见[相关工作核查](stage9_related_work_zh.md)。

明确区分请求eta、全步实际线性残差比和阻尼后接受步的实际线性化残差比。历史保护所用preveta保存接受步的上界eta_eff=(1-lambda)+lambda*请求eta；它可高于请求上限0.9但小于1，下一次请求仍裁到[1e-10,0.9]。EW1的范数差项使用实际接受步线性化残差，不以这个上界代替。

## 先验证，再冻结成本判断

冻结求解核心、运行器、本协议和实例表的SHA256后执行正式流程；此后不根据计时修改方法或参数。

制造解u=0.4*sin(pi*x)*sin(pi*y)，eps=0.05、gamma=2，解析连续右端。beta=(1,0.5)和(0,0)分别在n=15,31,63,127上以直接Newton求解，要求全部真残差合格，最后一对网格的相对L2误差收敛阶分别在[0.75,1.35]与[1.7,2.3]。这只验证指定平滑问题的一阶/二阶行为，不建立普遍误差定理。单元测试另检查Jacobian方向导数、边界和稀疏模板、线性特例、forcing公式、真实线性残差检查、快照恢复与失败记录。

每个32/64网格–参数组合另用直接Newton、rtol=1e-11、atol=1e-12生成离散参考解；该费用单列，不计作候选方法收益。候选最终解与高精度离散参考的相对L2误差须<=1e-6，同时满足真残差条件。制造解/离散参考/小网格预热在正式计时前完成。

## 基线完整成本

24个网格–参数组合×7策略×3重复=504次完整求解。每组每次重复用固定随机序种子打乱方法，BLAS单线程，不能并行其他求解/训练。每次独立组装PDE和Newton流程；完整时间从PDE组装前开始，到最终残差核验、返回求解结果为止，分解组装、Jacobian、ILU、GMRES/直接线性解、forcing、残差与线搜索。输出文件、离线参考比较不计入求解计时，另保留；未训练AI。

先在各实例对三次完整时间取中位，再对相对EW2的逐实例时间比取中位。从所有实例均准确的策略中，按该分数选择一个固定主基线（包含直接Newton），并在两种EW中按同规则选择一个固定续接控制器；并列按方法列表顺序。不能在每个实例分别挑最快经典方法称为可执行主基线。全部七种方法的直接比较均保留；任何方法失败必须报告。

## 有限分支诊断

在64网格的12个实例上，用选定EW另行运行来源轨迹（不参与基线时间）；固定截取Newton步0、1、2、3开始前的完整状态，最多48个。若轨迹提前收敛，缺失状态原样计数，不补挑后续状态。

每个状态独立施加一次倍率a in {0.25,0.5,1,2,4}，eta=clip(a*原生EW值,1e-10,0.9)，得到相同eta的动作按首次出现去重；重复组含倍率1时优先保留1作为原策略对照。随后全部使用同一选定EW至原始最终容差，保留原始初始残差分母及控制器历史。每动作重复三次并随机化运行顺序。来源轨迹、快照复制/存储、固定状态选择单独记录费用；不能把分支选择成本当作免费在线算法。

步0分支另独立重建PDE，报告包含组装的完整时间；后续状态报告已组装算子和已知状态下的剩余求解时间，不包含已发生前缀和静态组装。不能将不同状态的最优后续时间拼接成一个求解轨迹。

本阶段**继续门槛仅用步0**，以便与完整经典基线同口径：对每个实例取候选动作三次中位时间的最小值，与前述固定主基线在该实例的三次完整中位时间配对。该事后选择结果不是可部署策略或全动作空间的最优上界。12个实例全部有有效来源和步0动作；分支全部准确；配对时间比中位<=0.85，且至少9/12实例更快，才认定值得进一步检查。报告重复波动与动作重复情况，不把门槛当作统计显著性检验。

若未过线，停止当前PDE族、当前预条件设置和单步容差动作方案的训练投入，保留后续状态诊断，不通过增加动作/替换实例寻找有利结果；不泛化为所有非线性控制均无用。若过线，也只进入更完整经典对照与近邻核查，不直接启动训练：Botti2015公式与Oladokun2020全文尚未完整核验，性能与新颖性两关独立。单个后续状态即使有较大收益，也只能支持机制观察，不能覆盖步0门槛或自动扩大搜索。
