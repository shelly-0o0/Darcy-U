# 第六阶段结论：跳变当步的空间覆盖、使用接口与刷新成本

日期：2026-11-19。本文在第六阶段全部正式运行结束后撰写。对应 [运行前协议](stage6_protocol_zh.md)、[完整报告](../results/stage6_report/REPORT_zh.md) 和 [机器可读汇总](../results/stage6_report/summary.json)。

**本轮仍未获得超过强 AMG 的完整加速，但定位到了下一项可直接验证的因素：跳变当步只改善初值几乎不减少迭代，而同一空间通过固定平衡接口持续作用，在本批共同轨迹探针中能明显减少迭代。** 本阶段是经典数值实验，没有训练或调用 AI；在线事件步的平衡接口尚未验证，不能把离线迭代收益写成在线加速。

## 已完成的实验

82 项数值测试通过，其中11项验证新空间更新的正确性、预算、退化及数值分解失败处理；七种方法的完整20步小网格检查共140次求解通过。更新使用当前A/M及过去空间，不读取当前真解或未来状态；正常四维输入最多支付8次A、8次M向量作用，输出AU复用于投影，数值分解失败返回明确拒绝并保留已花预算。

正式开发使用三个新几何44001–44003，七种方法各两次完整序列，共840次求解。按预定规则选出 `event_reuse_frozen4`，即首步提取一次、以后直接复用，随后冻结六种确认对照。另五个新几何44011–44015用于128网格确认，256网格复用前两个，每项三次重复，共2,520次确认求解。独立确认几何仍是五个。

正式在线记录合计 **3,360 条**，全部最终显式相对真残差≤1e-8，最大 **9.980431e-9**。没有PCG失败、直接恢复、最终失败、整空间缓存拒绝或更新拒绝；所有更新满足8A/8M预算。所有失败字段、原始测量、几何排除与冻结哈希均保留。旧阶段记录未修改。

## 同方向、不同接口的离线诊断

在三个开发几何的全部七个非首事件，共21个系统上，固定共同基础历史、当前A/M和初值。比较上一事件空间、其一次预算更新、首步冻结空间和当前已完成轨迹的事后空间。后者只是至多24列增量得到的近似参考，不能提前用于在线求解。

下表均先对每个几何的七个事件取中位，再对三个几何取中位。“能量”指误差的 eᵀAe，不是相对压力L2误差；慢空间指标仅针对本次事后参考。

| 共同初值下的指标 | 上一事件空间 | 预算更新后的空间 |
|---|---:|---:|
| 投影后初始误差能量 / 原始误差能量 | 0.852456 | 0.553170 |
| 所测慢空间剩余误差能量比 | 0.969437 | 0.073480 |
| 与当前参考空间的A内积重合度 | 0.291863 | 0.624476 |
| 一次投影相对基础方法的迭代差中位数 | 0 | 0 |
| 固定平衡接口相对基础方法的迭代差中位数 | −8 | −10 |

预算更新改善了所测空间覆盖，但仅用于初值没有形成对应的迭代收益。直接复用和预算更新的平衡接口，相对各自一次投影在 **21/21** 个系统中减少迭代；balanced/warm配对迭代比的几何优先中位数分别为 **0.764706 / 0.687500**。预算更新的balanced相对旧空间balanced在20个事件改善、一个相同，配对中位只再少2次迭代。

不能把边际中位数之差当作配对差值，也不能说更新在所有指标、所有事件中都更好：慢空间剩余能量实际在18个事件下降、3个上升。方向经低端Ritz截断后不再包含全部旧空间，谱改善不保证右端相关误差改善。

首步冻结空间虽然更陈旧，其balanced相对基础方法仍在21/21个事件减少迭代，几何优先中位少6次；对应warm中位变化为零。因此，可以先用最廉价的首步空间验证事件步接口，无需先支付每次预算更新或训练模型。

这些探针没有独立计时重复，后续求解还复用了已经使用过的M；setup不含历史获取等成本。报告只将其用于方向/接口机制比较，不用其秒数声明公平在线加速。该结果只针对这批跳变事件，与第四阶段不同采样不能直接互相替代。没有逐迭代误差分量记录，因此尚不能声称直接观察到“误差重新进入慢空间”。

## 在线结果：低刷新成本较好，仍未超过基线

在线方案遵守运行前约定：**事件步均只做初值投影，后续PCG使用基础M；非事件步才使用固定平衡B。** 这样事件采集始终对应MA，不混用BA。它也意味着本轮在线结果不能否定事件步balanced的潜力。

每次先合计完整20步，再取同几何重复中位，最后汇总几何：

| 冻结确认方法 | 128网格中位秒数 | 256网格中位秒数 |
|---|---:|---:|
| 原SciPy基线 | 0.553227 | 2.705797 |
| 事件步自实现PCG，无回收 | 0.553051 | 2.719659 |
| 事件后刷新、事件前禁用旧空间 | 0.634425 | 3.144533 |
| 事件前直接复用、事件后刷新 | 0.646808 | 3.195202 |
| 事件前预算更新、事件后刷新 | 0.727809 | 3.555948 |
| 首步提取一次、以后直接复用（开发选中） | 0.586524 | 2.908668 |

选中方案 / SciPy的逐几何配对时间比中位数为 **1.055803 / 1.075054**，相对自实现基线为 **1.055407 / 1.069551**。不能用上表两列汇总秒数直接相除替代配对统计。128网格按总体中位时间选出的最快基线是自实现版本，256为SciPy；报告均在每组固定一种基线，没有逐几何挑选。

选中方案的迭代中位数由基线的532/669降至473/596.5，但每个确认几何的完整时间仍更慢，0/5、0/2达到节省20%的工程线。选中只意味着它是开发中的最快合格新候选，不代表已优于基线。

开发集可以分离不同费用来源：直接复用并刷新相对原滞后策略，配对总时间比为1.01559；预算更新并刷新相对直接复用并刷新为1.12250；持续运输更新相对首步冻结为1.08804。运输更新降低完整序列约34次迭代，但其非首事件增加约0.0819秒、非事件节省约0.0320秒，最后完整时间仍增加约0.0511秒。这些分类差值分别聚合，不能相加替代总时间的配对中位差。

预算更新并刷新的确认更新费用中位数约0.0874/0.4073秒，另有约0.1313/0.6820秒的事件末提取。对照表明，在本轮warm事件策略下，这些费用没有得到回报。所有方案沿各自数值历史推进，不能把整条序列的差异全部解释为同一空间的纯接口效应；纯接口证据来自前述共同历史探针。

## 下一项最小实验（尚未执行）

下一问题进一步收窄为：**只在首步提取一次四维空间，在后续跳变步也持续使用当前A下的固定平衡预条件器，能否让离线观察到的迭代节省覆盖在线应用成本？**

首先比较相同首步空间、相同刷新预算下的两种因果方案：本轮的“事件步warm、非事件balanced”，以及“首步之后所有步balanced”。每个系统开始前重建当前A正交基，PCG内部保持B固定；首步之后不采集新轨迹，因此没有将BA缓存当成MA的问题。全部构造、应用、真实残差与存储计入时间，使用新的开发/确认几何。

只有这一最便宜的接口改变显示可重复的完整收益，才进一步检查是否值得在少数事件更新空间，以及更新的计算成本能否由后续节省抵消。如果该接口也无法超过强基线，应重新评估当前PDE序列的加速空间，而不能靠继续加大网络掩盖成本问题。

学习模型仍需额外依据：在固定接口和可执行成本预算下，证明经典方法存在可观测且影响时间的方向失配，再检验预测更新是否比相同预算经典方法更好。当前结果支持下一项经典机制实验，不构成新的AI模型或国际一区论文的有效性证明。
