# 第九阶段结论：停止当前非线性容差动作方案的训练投入

日期：2026-11-19。已完成经典基线、数值验证和有限分支诊断；**没有训练AI，也没有发现足以继续训练的完整成本机会**。这一结论限定于本阶段PDE族、32/64内部节点网格、当前Jacobian的ILU和单次容差动作，不是关于全部非线性控制的否定结论。

## 已完成什么

新增二维单调对流–反应–扩散求解器：扩散中心差分、对流一阶迎风、零Dirichlet边界；反应项为u+gamma*u^3。实现解析Jacobian、统一Newton线搜索、ILU-GMRES、独立真残差核验、EW1/EW2以及可恢复的完整控制器状态。第一至第八阶段源码、协议和原始结果保持原样。

全部117项测试通过，其中新方向新增19项。制造解在15/31/63/127网格的最后一对收敛阶为 **0.983896（一阶迎风）**、**1.999989（纯扩散中心差分）**，符合运行前区间。这是指定平滑例子的数值验证，不是普遍误差定理。

正式运行12个参数实例、32/64两个网格、七种经典策略、每法三次重复，共 **504次完整非线性求解**。在64网格另取48个预定来源状态，经相同容差去重后得到184个动作、每动作三次，共 **552次分支求解**。552次包括首状态完整路径及后续状态的剩余路径，不应全部称为完整PDE求解。另有8次制造解、24次高精度离散参考、12次来源轨迹和7次预热，分别记录。

正式1,056次基线与分支全部满足共同精度，没有线性失败；最大相对非线性真残差 **9.023547e-9**，对高精度离散参考最大相对L2误差 **7.857035e-9**。参考解未用于求解初值或容差选择。源码、协议、实例、测量和48个快照的哈希核验通过；两个网格共享12个参数实例，不能当作24个独立样本。

## 经典基线已经解释了主要成本

按照运行前规则，在全部24个网格–实例组合上只选一个固定主基线，结果为 **直接Newton**；固定续接控制器为 **EW1**；四个固定容差中选出的全局最佳为 **eta=0.01**。没有逐实例选不同经典方法来制造更强的不可执行基线。

| 完整求解中位值 | 32网格 | 64网格 |
|---|---:|---:|
| 直接Newton时间/秒 | 0.008036 | 0.026275 |
| EW1时间/秒 | 0.010400 | 0.042506 |
| 固定eta=0.01时间/秒 | 0.010444 | 0.044341 |
| EW1 / 直接Newton，逐实例配对时间比中位数 | 1.283688 | 1.825870 |
| EW1 / 固定eta=0.01，逐实例配对时间比中位数 | 1.001120 | 1.004187 |
| EW1中ILU构造占比 | 67.1% | 75.1% |
| EW1中内层线性求解占比 | 11.6% | 18.1% |

先在实例内取三次完整时间中位，再计算逐实例配对比；不能把表中两个时间中位数相除代替。占比同样先按重复、再按实例汇总。直接Newton的分解计入线性解费用，并非免除预处理费用后比较。

**改变内层容差的直接目标并不是最大成本。** 64网格上EW1的Newton步数中位数为7，直接Newton为6；固定eta=0.5/0.9放宽内层精度后，Newton步数增至14.5/21，每步都要重新构造ILU。它们虽可能减少部分GMRES工作，却让完整成本更高。这支持“内外代价必须一起看”，不证明学习其他动作或复用预条件器必然获益。

## 有限分支没有通过继续门槛

每次仅改变一个状态的容差，随后全部用固定EW1至相同最终精度。倍率库为0.25/0.5/1/2/4，裁剪后去重。步0重新组装方程并测量完整路径；后续步骤只测量已有状态和已组装算子下的剩余路径。来源、存储与快照准备共0.597秒，另外保留，不作为免费在线决策。

事后在每个实例挑选最佳首动作，相对固定直接Newton的逐实例完整时间比中位数为 **1.821988**，范围 **1.214949–2.384110**，**0/12**实例更快。预定继续条件是中位比不超过0.85且至少9/12更快，因此明确停止。连这个排除选择费用的有限参考都未过门槛，不支持立即付出标签与模型训练成本。

这不是因为所有动作完全无效。相对同一分支计时批次的原生EW1动作，四个来源步的最佳剩余时间比分别为 **0.993317、0.987917、0.989595、0.998137**；部分步0实例有约10%的局部事后改善，但全部仍慢于直接Newton。相对另一批独立基线计时的EW1，最佳首动作比为0.979211；两个分母不同，不可混用来放大改善。

184个去重动作在48个状态内共有143种“记录数值轨迹及最终解字节”签名；10个状态所有动作签名相同。8个事后获选的非原生最快动作，其签名与倍率1相同，微小计时优势不能解释为求解路径改变。全部184个动作的三次重复数值签名一致。这个审计仅比较保存的残差、接受步长、实际线性残差、迭代计数和最终解哈希，不声称逐元素核验了所有中间向量。

## 为什么现在停止，而不是马上换更大的模型

当前策略未超过已实现的经典对照，局部动作收益也未形成足够的整体机会；不继续用增加网络宽度、标签数量、容差动作或多步强化学习来追逐未验证的潜力。也不把测试网格扩大到恰好有利的规模后沿用原门槛。若将来另有明确新证据，须重新制定独立协议。

这是一项资源决策，包含三项限制：只在较小网格筛查，直接法在更大问题上的优势未测；只改变一次容差并按EW续接，多步策略未测；只用一种ILU配置和每步重建方式，没有穷尽经典算法。这些限制阻止普遍否定，却不要求在单GPU、3–6个月论文预算下继续扩大同一方向。

新颖性也尚未成立。2020年的直接近邻已涉及学习线性容差，Botti2015给出另一类经典forcing策略；本次仍未完整取得这两项的算法正文，因此不能声称强基线覆盖完整或所提标签目标已有实质区别。已取得的原文、访问限制及EW公式见[核查文档](stage9_related_work_zh.md)。负结果足以停止当前投入；缺少更强对照不能把负结果变成正结果。

## 研究路线如何调整

归档本次内层容差学习候选，保留新的非线性求解器、Jacobian核验、制造解验证、快照恢复、完整成本记录和经典对照。当前没有需要继续训练的模型，也不将本阶段包装为已获得AI优势的论文。

下一候选转向第八阶段已列出的 **目标量驱动网格自适应的计算预算问题**：对二维对流–扩散方程及移动局部平均目标量，先测量经典DWR中富集伴随与误差估计的成本，并比较廉价恢复。只有这个环节确实昂贵、且存在保留目标量精度的节省空间，才研究小模型决定“何时/何处值得做昂贵富集”。[E2N](https://arxiv.org/abs/2207.11233)与神经伴随已有相关研究，不能以“学习误差指标”作为创新主张；具体差异仍须另行核查。[既有候选对照与停止建议](stage8_pivot_literature_zh.md)

这是下一项待执行的成本可行性筛查，尚未实现或测量。先以十余个源项–目标量实例建立强经典对照和明确停止线，不并行启动多个大训练项目。当前阶段已经完成，不自动延长为无期限容差调参。
