# 第七阶段运行前协议：首步空间的全步固定平衡接口

制定于2026-11-19，正式开发与确认之前。保持阶段1–6全部源码、协议、权重和原始结果不变。本阶段不训练或调用AI，主问题固定为：只在首步提取四维空间，让它在后续所有系统中持续参与PCG，能否把第六阶段离线探针的迭代收益转化为完整在线收益？

## 固定五项对照

1. `baseline_scipy`：当前Galerkin AMG层次刷新+历史四解初值，全部步SciPy PCG。
2. `baseline_event_custom`：同基础方法，首步/大变化步用自实现PCG，关闭采集；非事件SciPy。
3. `frozen_event_warm4`：首步基础M求解时采集最多24列D/AD/MAD，提取最多四个低端Ritz方向，此后源空间保持不变。当前A正交化后先做初值投影；后续事件步使用基础M，非事件步使用固定平衡B。这是第六阶段选中策略的本阶段重新测量。
4. `frozen_all_balanced4`：与第3项相同，但首步之后所有系统均使用当前A下的固定平衡B。这是唯一预先指定的主候选。
5. `frozen_all_warm4`：相同首步空间构造，但首步后所有系统都只做初值投影，PCG使用基础M，作为预定次要对照。

主机制对照固定为第4/3项；第3/5项分离非事件接口，第4/5项比较全步持续作用。完整收益同时与两种基础方法比较。不依据开发或确认时间改变主候选，即使次要方法更快也不将其改写为预定主方法。

三个回收方案各自支付完整首步求解、采集、复制和提取，不共享预先生成的空间。首步之后绝不采集、提取或预算更新；每个当前系统重建A正交基U/AU并投影，保持源空间不变。B=UUᵀ+(I−UUᵀA)M(I−AUUᵀ)，每次普通PCG内部B固定。

首步/大变化步仍用自实现PCG，后续调用必须传入实际选中的M或B且max_vectors=0；非事件使用SciPy和实际选中算子。逐行保存solver_operator与capture_requested。唯一采集发生在首步基础M下，不把BA缓存当成MA。

## 数据与精度

沿用二维Darcy/P1、mixed序列、20步、对比度1e4、恒定右端与齐次Dirichlet。事件仍为首步或max|log(k_new/k_old)|≥log(10)。最终显式相对真残差1e-8，总PCG迭代预算500、最多三次真残差刷新。所有失败、恢复、空间拒绝保留；不准确时直接恢复计入完整时间。

开发几何从45001起取3个，确认从45011起取5个。完整32网格占据序列哈希排除第六阶段全部历史排除/使用几何和功能检查75003，再排除当前重复；只因几何重复顺延，不因性能或失败换样本。开发n128、五方法各两次完整20步，共600次求解。确认n128另五几何、n256前两个，每方法三次重复，共2100次；全部在线预期2700条，独立确认几何仍为五个。

每条方法/重复独立清空解历史、AMG模板和空间，方法顺序由固定种子随机排列。开发结束后，只有全部五法记录完整、最终准确、零PCG失败且首步提取无整空间拒绝时才进入确认；时间不参与这一资格门槛。未通过则保留负结果并停止，不放宽门槛或替换方法。通过后冻结所有求解源码、协议、划分、开发测量、固定主假设和全部五个确认配置。

## 审计与全成本

保存不变首步源空间；在每条序列计时全部结束后计算其字节哈希，写入initial_space_sha256，仅用于同网格/几何/重复下三种回收法的来源审计，不传入在线决策。哈希相同是比子空间等价更强的检查，不同不自动表示数学空间不同；若不同，应保留记录并检查符号/旋转等价，不换样本。相同首步空间不保证后续数值历史逐位相同。

计时从组装前到空间释放/历史保存后，包含组装、历史四解初值、AMG刷新、当前A正交化、初值投影、B构造及每次应用、PCG采集/复制、真残差检查、失败恢复、首步提取和维护。extraction_seconds属于maintenance_seconds子项，不重复计入。直接参考解、能量误差核验与首步空间哈希审计在计时外，不能影响初值/空间/方法。

CPU运行，BLAS/OMP/MKL单线程，不与其他训练或求解计时并行。每次完整20步求和→同几何重复中位→跨几何汇总；配对比在几何内计算后再汇总。首步、后续事件、非事件分开汇总，用于解释节省与费用，不能挑有利步骤替代完整时间。阶段之间不直接相减归因，必须使用本轮匹配对照。

两种基线均报告；每组按整体几何中位时间选出同一种最快有效基线作为主完整收益比较，不逐几何选不同基线。仍以节省20%作为工程投入筛选线，不视为统计显著性或论文录用标准。经典收益不归因于AI；若固定首步四维空间仍无完整收益，应重新评估当前序列上的时间预算，而不能直接扩大网络训练或否定所有学习空间。
