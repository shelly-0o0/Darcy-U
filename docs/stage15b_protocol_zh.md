# 第十五阶段B：单目标经典完整循环与成本筛查协议

日期：2026-11-20。正式运行前制定；运行保存本协议、配置与计算源码哈希。父方案为[第十五阶段设计](stage15_design_zh.md)，前置[15A数值核验](stage15_findings_zh.md)已通过。本轮不是学习对比或总体统计确认。

## 1. 范围、问题与固定参数

单位正方形，零Dirichlet，−div(k∇u)=f。固定单位积分紧支撑源，中心(.25,.5)、半径.18；固定单位积分区域观测，中心(.75,.5)、半径.18。使用15A的四次紧支撑一维权重张量积，f与观测对全部材料保持相同，不从精确解反推。只做一个目标，避免把尚未完成的循环多目标算法当成已覆盖。

六个确定性材料：k=1；交替四层k=1/.1；交替四层k=1/.001；x∈(.5,.625)的低渗屏障k=.001、其余1；y∈(.375,.625)的导通道k=1、其余.001；矩形(.5,.75)×(.25,.75)低渗包含体k=.001、其余1。初始n=8三角形网格解析全部界面，材料定义不随细化变化。六案例不能当作六个独立随机样本；同一几何的容限/重复也不是独立样本。

预定绝对无量纲目标容限τ∈{1e−3,3e−4}，不根据真目标幅值调整，不沿用制造解的1/k_min归一化。所有方案使用同一f、k、w与τ。

## 2. 参考准入，先于速度结论

每例固定P2 n=32/64/128/256，10阶求积；n=256另用18阶；P1 n=512、10阶作独立阶次交叉核验。每次只求主问题，不将伴随伪计为必需；参考成本单列在离线账本。采用P2 n=256、18阶的目标值作为指定参考。

τ_min=3e−4。准入须同时满足：全部原矩阵相对残差≤1e−9、分量后向误差≤1e−12且状态成功；网格面积/界面对齐正确；P2最细两级目标差≤0.05τ_min；18与10阶目标差≤0.01τ_min；P1交叉目标差≤0.1τ_min；三段P2差的绝对值不增长超过10%加舍入余量，显著差不发生符号翻转。舍入余量为100 eps max(1,max|J|)。保存带符号差和末两段比值。

这些条件是保守的经验稳定性筛查，不是连续误差严格上界；符号/增长失败也不证明参考一定不准。任何失败均保留，不临时加密或放宽阈值。本轮仍执行该案例的在线路径，以保留诊断，但不以其q或耗时批准同等精度优势。

## 3. 八个可部署路径定义

| 方法 | 在线行动 | 停止方式 |
|---|---|---|
| uniform_direct / uniform_amg | 每次统一细化，直接法或缩放AMG | 下述付费DWR核验 |
| coefficient | h_T²[1+邻边log k跳跃绝对值之和]，含域内底分数 | 同上 |
| primal_residual | 主问题体残差及面通量跳跃，Dörfler标记 | 同上 |
| joint_residual | 主/对偶平方残差各除全局总量后相加；同一次P1分解求两个右端 | 同上 |
| dwr | P2富集伴随的强式体/面局部贡献绝对值用于标记 | 每层付费核验，全局估计含代数项 |
| fixed_direct / fixed_amg | 事先固定P1 n=256，单次主解和目标积分 | 固定分辨率结束；离线按同一τ验收 |

固定网格的n不从参考/测试结果选择；不要求它为已固定的结束规则额外求伴随。若精度不足则记失败，不能事后换细网格仍沿用较短耗时。这两个基线用于防止把“自适应”本身当作速度保证。

主问题残差定义：单元项h_T²∫_T r²/k；内边项h_e∫_e jump²/max(k_+,k_−)，两侧各分摊一半。对偶用w替换f。没有平衡通量与数据振荡上界，故不能宣称高对比可靠性证书。联合标记使用归一化的主/对偶残差组合，不冒称原生NGO-AFEM。经典主/对偶框架参照[FPZ作者原文§2、§4](https://arxiv.org/html/1505.04536v1)，本文材料跳跃设定不直接继承该文模型的全部假设。

除统一细化外，采用θ=.5的Dörfler前缀，分数降序、原单元编号打破并列。成熟网格细化接口参照[scikit-fem官方API](https://scikit-fem.readthedocs.io/en/stable/api.html)。只有已通过15A及独立15B测试的积分/局部化内核用于正式路径。

## 4. 真实停止、资源与失败

DWR标记每层求P2伴随。其余自适应方法只在第0层、层号为3的倍数、或相邻层目标变化≤.5τ时触发付费P2伴随核验。小的目标变化只触发核验，本身不能导致成功。核验保留R(I_Hz_2)代数项，只有所有线性验收通过且|R(z_2)|≤.5τ才允许估计停止；不使用参考真值决定是否细化或停止。

最多13个网格状态（编号0–12）；P1主问题最多70000自由度，P2可更大并记录峰值；每路径60秒软时间上限，在装配/求解/细化完成后检查，可能超过一个不可中断操作的时间，实际超限时间不截短。未达标、零指标、求解失败、异常、自由度或时间超限均保留，不能把其较短耗时当作成功加速。

退出后独立检查q=|J_ref−J_h|/τ。只有参考准入、在线路径正常完成、q≤1及网格/线性验收同时满足，才记“相对已核查参考成功”。估计停止但q>1记accuracy_failed，不能继续求解后替换该记录。无论是否成功都保留带符号/绝对目标数据与路径。

## 5. 成本、重复与交付

6材料×2容限×8方法×3重复，共288路径。按(case编号+容限编号+重复编号)确定轮换方法顺序。单线程BLAS；每种方法先固定小规模预热，预热记录和成本单列。CPU算法计时包含初始网格、全部装配、必要主/伴随求解、指标、标记、网格细化及线性和停止核验，也包含当前实现的记录准备/哈希开销；文件写出、离线参考与事后比较单列，不偷偷从必需核验成本中扣除。

分解/AMG层级在同一矩阵的多个右端之间复用。跨网格矩阵变化；本轮没有固定矩阵重复查询摊销主张。P2只求伴随，不把离线P2主解夹入在线DWR。

每case/τ/方法报告3次时间中位数、范围、最终q、DOF、失败原因、分项成本；重复次数不增加几何样本数，不给总体置信区间或显著加速结论。只在同case/τ全部重复成功的共同子集上列辅助配对比，必须同时展示全部失败，不能以共同成功子集替代全局门槛。

保存参考、288条压缩路径、最终网格/解数组、索引、哈希清单、独立测试与聚合报告。网格可从固定初始网格与逐层保存的标记重建。任何求解失败保留，不读结果后调参改门槛。
