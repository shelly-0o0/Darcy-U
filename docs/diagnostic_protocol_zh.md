# 第二轮诊断协议：先验证收益空间，再决定是否继续训练

协议制定日期：2026-11-19。本文件在第二轮正式计时前确定研究问题、验证数据、比较方法和判断规则。它不预先承诺正结果，不把诊断消融作为可部署算法。第一轮代码、权重和 `results/pilot_cpu/` 保留；第二轮使用独立的诊断程序和输出目录。

## 1. 本轮只回答三个问题

1. 第一轮 Schwarz 方法的主要成本，是否来自可修正的局部矩阵组装、稠密局部求解和缓存实现？在数学粗空间不变的条件下，稀疏实现能改善多少端到端时间？
2. 在真实旧空间失效事件中，至多四个新增方向是否足够？现有网络失败主要表现为方向数不足，还是给出的方向未满足完整矩阵检查？
3. 即使候选方向生成成本理想化为零，是否仍有值得继续研究的总时间收益空间？真实在线算法和假设零成本的诊断必须分开呈现。

本轮不训练新模型，不根据诊断结果重选已有检查点，不用原测试种子 90001–90003 调参。完整序列计时使用现有种子 7 冻结检查点；它是训练阶段按验证损失选出的检查点，不是在第二轮几何上挑选的模型。离线事件审计另检查同样冻结的种子 17、27，以描述模型初始化差异，不据此重新选择计时模型；多个模型不是新增的独立 PDE 事件。

## 2. 固定问题与两部分验证数据

| 项目 | 预先固定的设置 |
|---|---|
| 方程及离散 | 单位正方形二维 Darcy，零 Dirichlet 边界，原 P1 有限元 |
| 网格 | 128×128 个单元；16,129 个内部自由度 |
| 序列 | 原 `mixed` 生成器，每条 20 步，右端 `one` |
| 系数对比度 | 1e4 |
| 子域 | 核心宽度 16、重叠 2，共 64 个局部块 |
| 数值谱检查 | 完整矩阵检查，gamma=0.03；原对角合同缩放和 5e-10 容差 |
| 参考谱构造 | 包含所有广义特征值不大于 0.06 的模式 |
| 线性求解 | PCG；显式相对真残差不超过 1e-8；沿用原预算与失败记录规则 |
| 设备 | CPU；BLAS 1 线程，PyTorch 2 线程 |
| 完整序列计时 | 新验证种子 70001、70002、70003；每种配置计时 3 次 |
| 事件审计 | 新验证种子 70001–70020；每条经典谱复用轨迹只运行一次 |

这 20 条序列均为本轮诊断验证集，不是用于声称最终泛化性能的独立测试集。前三条同时用于计时和事件审计，不能被重复计为额外几何。计时重复不是独立 PDE 样本。同一序列中的多个局部事件也并非统计独立；报告应同时给出几何数、唯一事件数和逐几何结果。

保存生成配置、完整序列哈希和种子。检查它们与旧训练、验证、测试清单不存在相同序列。若以后据本轮诊断修改方法，正式测试必须另取从未参与方法选择的几何。

## 3. 六种计时配置

| 配置 | 本轮作用 |
|---|---|
| `dense_spectral_reuse` | 原稠密局部实现和原经典谱复用，提供保持原逻辑的对照 |
| `sparse_spectral_reuse` | 相同谱空间、复用判据和检查规则，采用局部缓存及稀疏局部因子 |
| `sparse_spectral_increment4` | 使用精确局部谱信息构造最多四个补充方向；完整计入参考谱构造、正交化和检查成本 |
| `sparse_spectral_increment_all` | 用精确局部参考谱空间的全部缺失方向补充；完整计入所有构造与检查成本 |
| `sparse_unet`，`model_seed=7` | 冻结的 U-Net 种子 7；最多四个方向；共享稀疏实现、复用、检查和失败处理 |
| AMG | 原 PyAMG 配置，作为当前实测最强的经典参照，保留完整在线成本 |

稀疏方法共享同一局部求解、缓存、粗矩阵和检查实现。不能只优化 AI 分支而保留未优化的传统对照。精确参考方向仍然需要计算谱信息，因此完整计时的两个参考增量方法本身属于传统候选算法；不应把它们当作免费获得的输入。

参考方向规则在计时前固定：求当前局部广义特征对 `A_N v=lambda B v`，取 `lambda<=0.06` 的模式，按特征值升序处理，包含 Neumann 零模。旧基先作 B 正交归一化；各参考模式对旧空间和已经选出的方向进行两轮 B 正交投影，仅在残余 B 范数平方大于 `1e-10` 时保留。四方向版本最多保留四个独立残余，全部方向版本保留全部独立残余。将该规则及阈值记录在清单中。

这个规则没有求解完整矩阵接纳条件下的全局最优四维补空间。因此四方向参考失败不能单独证明所有四方向方法都失败。全部方向参考用于检验是否能覆盖参考空间；它可以比四方向方法更宽，不能仅凭其结果认定现有四输出网络有同样性能上限。重复或极接近特征值对应的数值基可能影响截断四方向的选择，应保留源代码和运行环境以便复现。

## 4. 公平性、正确性与计时

- 各方法接收相同系数序列、网格、右端和残差要求；均只用本方法上一步的已求解状态热启动。直接参考解不得用于热启动或作为网络输入。
- 相同初始状态下，稠密和稀疏谱复用应给出相同的粗空间投影与复用/修复决定，允许浮点分解引起的微小误差。先核对这一点，再将时间差解释为实现改进。若产生不同接纳分支，必须记录并解释，不能默认只是等价加速。
- 缓存必须覆盖局部矩阵的完整系数支撑。局部 `A_D` 的边界对角元依赖子域外相邻单元，不能仅凭子域内部系数未变就重用因子。
- 稀疏因子须对应原对称正定局部问题，且 PCG 一次运行中预条件器保持不变。核对作用结果、对称性和正性；不能靠更宽松的真残差或未记录的求解失败换取速度。
- 每条序列的第一步初始化计入总时间；每次完整重复都从空缓存开始。不得将前一方法或前一计时重复的缓存交给后一方法。
- 六种配置的运行次序使用固定随机种子打乱，并保存实际次序。模型可在计时前做一次不接触验证几何的通用预热；所有计时运行不得与训练、其他基准或重型后台计算并行。
- 记录组装、局部构造、复用、参考谱计算、候选生成、正交化、检查、局部与粗问题设置、PCG、失败恢复及未分类开销。子项不得与已经包含它的上层时间重复相加。
- 保留原显式真残差刷新和直接恢复规则。全部尝试及恢复成本计入总时间，分别报告 PCG 失败和最终解是否达到容差。出现非有限数、未经解释的等价性失败或真实残差超限时，先修正正确性，再讨论速度。

正式计时前保存 `diagnose.py`、所导入数值/学习/数据模块、依赖版本、协议文件和冻结模型权重的 SHA-256。清单还应记录硬件、线程数和启动参数。计时后若修改影响算法或计时的源码，保留修改原因和新哈希，并重跑所有受影响的配对配置；不得把不同实现的行拼成一次未说明的比较。

## 5. 20 条经典轨迹的事件与容量审计

事件轨迹只由经典谱复用规则推进。满足廉价系数界时直接复用；廉价界未通过时检查旧空间；仅当旧空间的完整矩阵检查也失败，才记为需要补充的候选事件。不得通过关闭廉价复用、强制每步调用网络来人为增加实际算法的事件数。

唯一事件键为“序列种子、时刻、局部块”。在同一事件上独立比较旧空间、冻结网络、四方向参考、全部方向参考，最后仍按经典谱修复推进审计轨迹。这可保证各候选看到相同旧空间；它不等同于每个方法自由运行后的自身轨迹。三个完整计时几何则各自运行真实在线轨迹，二者分别报告。

每个事件至少记录：旧维数、参考维数、各候选有效新增列数、完整检查的最小特征值及容差、是否通过、旧检查矩阵负特征值计数、触发类型、候选计算成本。报告每个几何的触发次数；零触发时接纳率记为不适用，不能记作 100%。

容量解释以完整矩阵

`L_old = A_N - gamma [B - BZ(Z^T B Z)^(-1)Z^T B]`

为依据。精确算术下，加入 r 个独立方向只能对该矩阵产生秩至多 r 的半正定修正；若 `L_old` 有超过 r 个负特征值，r 个方向不足以使其半正定。因此超过四个可靠负模式是四方向容量不足的证据。实际计数固定使用 `D=diag(A_N+B)`，对 `D^(-1/2) L_old D^(-1/2)` 求全部特征值，计数小于 `-5e-10` 的模式，并保留特征值以观察接近阈值的情况。它仍然是浮点数值诊断，不能写成经过舍入误差认证的数学结论。

反向推断不成立：负模式数不超过四个，或某种四方向参考检查失败，都不自动证明四个方向一定足够或一定不够。若全部参考方向也未通过，应先检查数值秩截断、参考谱求解、零模和接纳实现，不能立即归因于模型。

## 6. 完整成本与假设免费成本必须分表

主表只使用实际测量的完整在线总时间。另可呈现两类明确标注为“诊断，不能部署”的时间重算：

1. `hypothetical_free_candidate_seconds = total_seconds - candidate_seconds`：假设候选的完整构造与正交化免费，其余实测路径和成本保持不变。
2. `hypothetical_free_all_space_work_seconds = total_seconds - spectral_seconds - candidate_seconds - check_seconds - fallback_seconds`：更乐观地假设首步谱空间构造、候选构造、全部旧空间与候选数值检查、失败后的谱修复都免费，其余实测路径和成本保持不变。局部矩阵组装、复用逻辑、局部与粗矩阵设置、PCG 和直接求解恢复成本仍然保留。

每种时间重算必须列明被扣除的字段、扣除总额及剩余成本，避免重复扣除。第二种情景明确同时扣除旧空间和候选检查，不能只称“候选验证免费”。任何数值结果都要和原始完整成本一同呈现。

这些是特定实测空间与迭代路径下的成本情景，不是所有可能 AI 方法的普适下界。离线精确参考提供的信息不能在可部署计时中隐去。尤其不能把参考构造免费后的时间当成网络时间，或把全部参考方向的 PCG 表现直接套到四输出网络上。

## 7. 聚合与预先约定的决策门槛

主指标是整条 20 步序列的在线总时间。先逐完整运行求和，再在同一几何同一方法的三次重复间取中位数。保留每个几何的时间、配对比值和三次计时范围，最后才汇总三个几何；不得以逐步中位数求和替代主指标。

每个几何的最强实测传统基线取 AMG、稠密谱复用、稀疏谱复用、完整成本四方向参考和完整成本全部方向参考中的最快者。设候选与该基线的整序列中位时间为 `T_candidate` 和 `T_classical`。预先采用 `T_candidate / T_classical <= 0.80` 作为约 20% 端到端改进的工程筛选线；同时要求所有结果满足共同真残差标准，不隐去失败与回退。

20% 是本项目用于决定是否值得扩大投入的工程门槛，不是一区期刊录用标准，也不构成三个几何上的统计显著性结论。各几何结果必须全部公开，不能仅挑最好的一条过线。

- 若连明确标注的理想化成本情景都没有这种量级的收益空间，应暂停当前“仅学习局部增量构造”的扩展训练，优先重新选择计算瓶颈或研究问题。
- 若只有理想化情景过线，只能说存在潜在空间；应继续小规模可部署算法研究，不能宣称真实 AI 方法已达到门槛。
- 只有计入推理、正交化、检查、修复和求解的实际方法取得可重复的端到端优势后，才考虑大规模训练及新的独立正式测试。若只有稀疏传统实现变快，应把收益归因于实现改进。
- 若触发事件少，或计时变化与方法差异相近，结论是证据不足，而不是自动增加训练轮数。可以据此预先设计下一轮更广泛但有实际意义的问题分布，并清楚标注研究范围变化。

本轮报告必须保留负结果。它只决定下一阶段资源投入，不承担最终论文创新性、泛化性能或发表等级的证明。
