## 1. 本轮实际计算了什么

求解单位正方形上的 `−div(k∇u)=f`，齐次Dirichlet边界。固定归一化局部源中心为(0.25,0.5)，固定区域压力观测中心为(0.75,0.5)，半径均为0.18；源和观测不随材料改变，也不由制造解反推。材料为常系数、两种对比度的分层、屏障、通道和矩形包含体，共六个确定性案例。所有界面均与初始网格对齐。

两个绝对无量纲容限为 `τ=10⁻³`、`3×10⁻⁴`。六材料×两容限×八方法×三次计时，得到288条完整路径。八方法包括均匀细化配直接/AMG求解、系数指标、主残差、主/对偶联合残差、富集DWR，以及预先固定P1细网格的直接/AMG求解。联合残差不是多目标循环NGO-AFEM。

自适应方法从相同网格开始，在线停止不读取参考解。DWR每层支付P2伴随和全局估计；廉价方法仅按预定间隔或目标变化触发P2核验。所有自适应停止均检查实际线性残差、分量后向误差和含代数项的全局DWR估计，安全系数为0.5。固定细网格方法的分辨率事先固定，不做在线目标误差估计；退出后与其他方法接受同一参考精度验收。

完整在线时间包括初始网格、主问题装配/求解、实际线性验收、伴随、估计、标记、细化和算法记录准备，输出写盘与离线参考另计。正式运行共1059次在线求解器调用、1176个右端解；另有36次离线参考求解。正式运行总墙钟约227.08秒，其中离线参考约154.34秒，在线路径耗时合计63.65秒，其余为预热和文件等开销。不能用总墙钟直接比较某个求解方法。

## 3. 正式比较中的正向信息及其边界

每个材料—容限设置先取三次耗时中位。DWR在4/12设置最快，主残差在5/12最快，联合残差在3/12最快。DWR领先的四个设置如下，时间来自原始正式批次，尚未加入后续实现优化。

| 材料 | τ | DWR中位毫秒 | 其他方法中最快者 | 该方法中位毫秒 | DWR/该方法 |
|---|---:|---:|---|---:|---:|
| layers_10 | 3×10⁻⁴ | 24.902 | 联合残差 | 30.504 | 0.8163 |
| layers_1000 | 3×10⁻⁴ | 13.041 | 均匀细化＋直接解 | 34.785 | 0.3749 |
| inclusion_1000 | 10⁻³ | 13.138 | 系数指标 | 18.241 | 0.7202 |
| inclusion_1000 | 3×10⁻⁴ | 12.926 | 系数指标 | 31.359 | 0.4122 |

表中“其他方法中最快者”是逐设置的事后比较参照，不能伪装成部署时已知的最优方法选择器，也不能根据这四项结果事后定义论文确认集。

这说明：在当前分层/包含体的部分容限下，支付正确的目标信息可以减少总求解成本。它修正了早期受限网格动作实验无法体现完整自适应的不足，但不是AI贡献，也不构成所有高对比材料上的结论。

反面证据同样清楚：216条自适应路径中90条在初始网格已通过停止规则，对应每种自适应方法的5/12设置。这里没有中间细化层可供模型替代；廉价方法之间微小的耗时排序也不足以说明标记策略更优。所有DWR路径仅需1–3个状态，最大P1自由度为235，尚不足以代表大规模PDE场景。

固定细网格有65025个P1自由度，在本轮通常明显过度求解。它的较长时间不能用来制造AI或自适应方法的夸大加速比；应优先比较能按容限退出的强经典方法。完整逐设置数据见[正式报告](../results/stage15b_report/REPORT_zh.md)。

## 4. 先消除普通实现开销，再讨论学习

正式实验后发现：原DWR在已经满足停止条件的最后一层，仍计算供下一次标记使用的局部指标。新实现先做全局核验，只有继续细化时才计算体/面局部化，并缓存已计算的富集伴随缺陷。这不改变方程、网格规则、估计公式或停止标准。

追加72条新路径：原版和优化版在同一新批次交替运行，每种材料—容限各三对。36/36对通过原参考精度验收，状态、目标值、标记、网格及最终解完全一致；继续细化层的带符号局部项与标记分数也一致。两版各66个状态，局部化调用由66次减少为30次，省去36个停止层的无用工作。

12个设置内分别计算三次新/旧配对时间比中位，再跨设置取中位，得到 **0.810997，即约18.9%的耗时下降**。这不是两个跨设置耗时中位数之比。36/36对均更快，绝对分组中位节省约1.70–3.96毫秒；优化后的完整时间中位范围为3.64–24.13毫秒。

这是同一固定案例上的事后工程验证，不是新几何确认或总体统计显著性结论。原288条正式路径保持不变；不把本次优化时间与上一批其他方法的时间拼接重新排名。后续同批比较必须采用优化后的DWR。见[追加报告](../results/stage15b_deferred_probe/REPORT_zh.md)和[逐对记录](../results/stage15b_deferred_probe/summary.json)。

## 5. 真正可能替代的成本有多少

原DWR的“P2装配＋伴随＋估计”占比中位约70.5%，但其中包含最终核验和刚被消除的实现开销，不能全部当成AI可省成本。

在优化后轨迹上，保留最终P2核验，只汇总**仍需细化的中间层**的P2装配、伴随、全局估计和局部化时间，得到下表。每个单元格是对应设置三次记录的中位。该账本是事后分析。

| 材料 | τ=10⁻³：中间估计占比 / 毫秒 | τ=3×10⁻⁴：中间估计占比 / 毫秒 |
|---|---:|---:|
| constant | 0% / 0 | 44.84% / 10.81 |
| layers_10 | 43.90% / 9.33 | 43.47% / 9.24 |
| layers_1000 | 38.71% / 3.99 | 38.45% / 4.06 |
| barrier_1000 | 0% / 0 | 0% / 0 |
| channel_1000 | 0% / 0 | 0% / 0 |
| inclusion_1000 | 38.04% / 3.96 | 38.20% / 3.93 |

7/12设置的中间估计占比超过设计建议的30%，另外5个为零。不过，在这7个设置里，只有4个是原正式实验中DWR最快的设置，其余仍有更快的廉价经典方法。仅比DWR快不足以证明研究价值。

即使假设不改变网格轨迹、将这些中间费用全部降到零，这也只是固定轨迹的算术成本情景。哪些层属于中间层是从已观测轨迹得知的；实际算法不能免费预知最终层，必须自行决定何时付费核验。真正模型还需支付特征、推理、停止触发、核验和回退，并可能走出不同网格。该表不提供实测学习加速或可达到的收益保证，也不批准G1。毫秒级绝对空间尤其要求先测CPU小模型、数据转换和核验开销，而不能默认GPU推理便宜。见[成本账本](../results/stage15b_cost_space.json)和[分析程序](../analyze_stage15b_cost_space.py)。

## 6. 对研究问题和模型设计的具体调整

下一候选问题收窄为：**对需要多轮细化的单目标Darcy问题，能否用已支付的粗层信息近似中间层目标相关标记，并保留最终数值核验，从而比优化DWR和廉价残差方法更快达到同一容限？** 这是一项待否证的研究问题，不是已经成立的新颖性声明。

如果下一阶段通过资格门槛，最小学习试验采用现有设计中的两层、每层64宽MLP，预测廉价局部指标的修正，离线监督来自富集DWR。输入限于已支付的材料、单元几何、主残差/通量、目标位置和必要的粗伴随量；若使用粗伴随，其装配与求解必须全额计时。模型不读取在线P2伴随或参考解，否则将重新付出本想节省的成本。先考察局部排序/标记质量及真实求解路径，再决定是否需要邻域图结构。

部署流程应为“粗主解→廉价特征和中间标记→真实细化→触发经典核验→通过则停止、未通过则继续或回退”。停止触发方式是需要单独验证的设计变量；尚未实现或测得有效触发策略，不能仅凭最终核验存在就声称整体可靠或高效。当前DWR核验仍是经验规则，高对比严格认证另需平衡通量、数据振荡与适用假设。

这种学习误差指标的基本框架已有文献近邻，应以[学习近邻矩阵](research_review_learning_zh.md)中的E2N风格MLP、学习标记参数等为直接对照。不能以“目标条件”“神经伴随”或“带回退”作为充分创新点。当前没有证据需要更大的GNN、神经算子或强化学习。

## 7. 下一阶段的有限投入与停止条件

以下是下一轮的工作建议，**尚未冻结、尚未执行，不属于本轮实验结果**。沿用[第十五阶段总设计](stage15_design_zh.md)的两周资格检查上限，不因本轮局部正向信息重置期限。

1. 在明确应用与源/观测规则后，预先生成新的材料几何，先保持界面合规，覆盖分层、屏障/通道和包含体；将几何、容限、参考层级、预算和终点写入新协议。目标/容限变体仍按同一几何统计，不作为新增独立样本。避免只保留本轮DWR领先的四个设置。
2. 在同一新批次比较优化DWR、主/联合残差、系数、均匀细化和便宜的伴随恢复；保留固定细解作成本参照。先检查精度、是否实际需要多层细化、完整时间及中间估计的绝对成本。一般未对齐材料、多目标循环和高对比认证各有缺失基线，不能从当前单目标对齐范围外推。
3. 只在优化后的强经典对照仍存在可重复成本空间、廉价恢复不能消除差距时，批准有限MLP试验。训练/验证/确认按几何分离，计入标签、推理、核验、回退及摊销成本。各材料族单独报告，不用事后逐例最优参照充当部署策略。
4. 若新几何上DWR优势不再出现，或可省中间费用不足以支付推理/核验，就停止该估计器替代分支，形成机制与失败报告。随后围绕具体重复正问题或反问题重新调研，不再通过无限缩小容限、扩大网格或网络来寻找有利数字。

本轮对“是否继续”给出的答案是：**允许再做一轮有上限的经典确认，尚不足以进入大规模AI训练或论文主结果阶段。**
