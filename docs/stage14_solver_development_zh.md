# 第十四阶段求解器开发：统一验收，并保留第十三阶段失败

本文件仅记录开发，不是正式确认结果。使用八个独立几何：常规组 `55000–55003`、高对比组 `55100–55103`，均为 `nc=64`。每个矩阵检查四个载荷，因此有 32 个右端项，独立几何数仍为八。八个系数哈希互异，与核查的第十至十三阶段数据无重合。没有读取第十四阶段正式确认几何 `55200–55215 / 55300–55315`，没有训练模型。第十三阶段的两个失败上下文、六次失败重复和总门槛未通过结论保持原样。

## 1. 统一规则与实现

公共接口位于 [stage14_solver.py](../stage14_solver.py)：

```python
u, metrics = solve_system(A, b, method)  # method = "direct" 或 "amg"
```

`b` 为向量 `(n,)` 或按列排列的多右端项 `(n,n_rhs)`；输出保留形状。一次调用只共享自己的分解或 AMG 层级，不跨方法或重复缓存。两种方法都对**原始 double 矩阵和原始载荷**验收，每一列同时满足：

- 相对二范数实际残差 `||b-Au||₂ / ||b||₂ ≤ 1e-9`；
- 分量后向误差 `max_i |r_i| / (|A||u|+|b|)_i ≤ 1e-12`；
- 所有内层调用状态正常，解及指标有限。

残差与后向误差使用本机 `longdouble` 的 64 位有效二进制尾数计算，另行保存 float64 实际残差。矩阵、载荷、迭代、分解和最终解仍为 float64；扩展精度点积**没有把矩阵装配或 PDE 离散误差变成高精度**。分量后向误差约束会识别整体二范数被大分量掩盖的局部相对不平衡。零载荷给出零解和零误差，不借助除零掩盖非零残差。

`direct` 使用普通稀疏 LU。`amg` 使用 `D A D y = D b, u = D y`，`D=diag(A)^(-1/2)`，在缩放系统建立固定的对称 AMG V-cycle（种子 51700）。首轮 PCG 相对停止参数为 `1e-10`，随后检查原系统规则。未通过的列最多做两次修正：用扩展精度计算的原系统残差转回 double 作新右端项，复用本次分解或层级求修正；修正 PCG 参数为 `1e-3`。每个右端项的初次与修正迭代合计最多 1000 次。状态失败不会仅因最后残差小而被改记为成功。源码默认启用上述条件修正；`max_refinements=0` 只用于开发消融。

`metrics` 包括逐列指标及其最大值、`converged`、内层状态、每列迭代和修正次数、初次及逐次残差、固定规则和分项时间。总时间包含输入校验和复制、double/longdouble 转换、缩放、分解/层级、全部求解、实际残差与后向误差检查及必要修正。PDE 系数采样、装配和目标评价由外层完整流程计时。这里不使用参考解决定停止。

细求解器还需要外层共同检查三个目标相对细直接参考的差异 `E ≤ 1e-5`，并验证粗目标误差分母非退化。开发只用主载荷的三个目标执行该检查；其余三个载荷独立接受残差压力检查。参考一致性不是连续 PDE 精度证明。

## 2. 开发结果

各组有四个几何；下表取组内四个几何、每个四列的最坏值。“通过”要求该几何全部四列满足共同残差和分量后向误差。旧 AMG 的本来停止规则另行保留，没有替换。

| 组 | 实现 | 四列共同规则通过 | 最大扩展精度相对残差 | 最大分量后向误差 |
|---|---|---:|---:|---:|
| 常规 | 普通 LU | 4/4 | 4.33e-12 | 8.70e-16 |
| 常规 | 旧 AMG-PCG | 0/4 | 9.89e-11 | 1.14e-10 |
| 常规 | 对称缩放 AMG，禁用修正 | 0/4 | 1.85e-10 | 2.61e-11 |
| 常规 | 统一接口 direct | 4/4 | 4.16e-12 | 7.76e-16 |
| 常规 | 统一接口 amg | 4/4 | 9.34e-13 | 1.98e-14 |
| 高对比 | 普通 LU | 4/4 | 2.18e-10 | 8.34e-16 |
| 高对比 | 旧 AMG-PCG | 3/4 | 1.83e-10 | 4.99e-12 |
| 高对比 | 对称缩放 AMG，禁用修正 | 0/4 | 1.33e-9 | 2.54e-11 |
| 高对比 | 统一接口 direct | 4/4 | 2.14e-10 | 7.20e-16 |
| 高对比 | 统一接口 amg | 4/4 | 6.70e-11 | 1.33e-14 |

统一接口的 direct 无需修正；amg 的 32 列均进行一次修正，全部正常返回。两者的最坏目标差异 E 分别为 `5.28e-14`、`5.49e-10`，都远低于预定的 `1e-5`。对称缩放单独并没有解决问题；本开发支持“缩放加实际残差修正”的完整实现，不能把效果单独归功于缩放。

所有方法实际计算了扩展精度残差。以高对比组为例，普通 LU 的最大 double 残差为 `2.26e-10`，扩展精度为 `2.18e-10`；旧 AMG 分别为 `1.97e-10 / 1.83e-10`。提高残差点积精度改变了数值，但没有自动消除较大的相对残差。与此同时，普通 LU 的 normwise 后向误差最坏仅 `4.94e-16`。这些观测符合高对比矩阵中舍入和相对残差归一化影响严格停止的解释，但不足以证明唯一原因，未测量完整条件数，也未计算高精度重新装配的独立解。

旧 AMG 在新几何 `55100`、`55103` 的全部四列上再次出现库状态 `info=0`、三次实际残差重启后仍高于旧 `1e-10` 的情况，共八个 RHS 失败。这不是仅靠删除第十三阶段特殊样本可以处理的问题。另一方面，旧 AMG 的部分常规样本虽满足原来的整体残差要求，却未满足新加的分量后向误差要求，说明新协议不仅仅放宽一个阈值。

开发中每个方法只运行一次、复用同一已装配矩阵，且求四个右端项。求解器时间中位数（常规/高对比）为：普通 LU `46.12/44.27 ms`，旧 AMG `86.76/121.77 ms`，缩放无修正 `83.68/106.99 ms`，统一 direct `49.67/49.02 ms`，统一 amg `109.44/159.56 ms`。这些是包含全部诊断的四 RHS 开发时间，**不能替代正式的三次新建完整主问题路径计时，也不能与第十三阶段单主解时间直接比较**。新规则与修正确实要付成本，不应隐藏这一点。
