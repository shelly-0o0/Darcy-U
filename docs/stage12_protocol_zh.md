# 第十二阶段运行前协议：局部补丁动作与相互作用的非学习可行性检验

本阶段检验一个有限问题：**在相同新增自由度下，直接评价小型局部细化动作的有符号目标变化，能否找到明显优于既有误差指标排序的网格？** 第十一阶段已停止扩展“预测伴随缺陷后排序”的 AI 分支。本阶段不训练模型、不修改九个既有权重、不将精确参考信息包装为可部署输入。精确动作公式属于经典块消元；本阶段的目标是决定是否存在值得进一步学习的动作信息，而非证明新颖性或论文可发表。

本文件与源代码必须在正式结果产生前冻结并写入哈希清单。仅可使用不属于正式样本的几何进行程序正确性和运行开销检查，不得根据正式结果改变选择规则、目标尺度、预算、样本或继续门槛。发生程序错误时保留原目录与错误，修正后另建目录重新运行，不覆盖冻结结果。

## 问题、独立样本与真实预算

沿用第十、十一阶段的二维零 Dirichlet Darcy 问题、SW→NE P1 三角形、系数生成函数、载荷及积分。粗网格 16×16、指定细参考 32×32，内部自由度分别为 225 和 961。`Ac=P.T Af P`，所有局部细化算子都由同一细离散算子限制而来；不重新采样系数，不改变积分。所有误差相对于指定细离散解，不是连续 PDE 误差或误差界。

正式样本为全新的 32 个独立几何：ID 种子 53000–53015，高对比种子 53100–53115；ID 对比度从 5/20 取值，高对比从 100/1000 取值。检查与训练、验证及历史测试几何哈希无非预期重复，发现冲突则停止，不换样本后继续。每个几何的四个载荷仍固定第 0 个为源项，第 1、2、3 个为目标。三个目标共用一个网格和一次适应主问题求解，不当作三个独立样本。

每种局部细化方法增加恰好 64 个独立自由度，适应空间维数必须为 289。选中粗方格的中心各增加一个自由度；每一对选中相邻方格的公共内部边中点再增加一个。边界中点为零边界值；非一致接口的中点保持悬挂约束。使用第十一阶段的真实细化嵌入 T 与 `T.T Af T` 求解验证最终结果。预算不是选中方格数，不允许不同方法停在不同维数。

## 目标函数与经典精确动作公式

三个在线目标尺度沿用 `s_j=max(abs(g_j.T P u_c), 1e-12 max_l abs(g_l.T P u_c), 1e-30)`。尺度只使用粗解；所有方法固定相同尺度，不根据细参考误差调整权重。

令选中方格集合为 C，`I(C)` 为新增自由节点索引，V 为相应细空间标准基列。其空间满足 `range(T)=range([P,V])`。令 `r_f=f−Af P Ac^{-1}P.T f`，各目标同理得到 `r_gj`。消去粗变量后得到

`B=P.T Af V`，`K=V.T Af V−B.T Ac^{-1}B`，

`Δ_j(C)=(V.T r_gj).T K^{-1}(V.T r_f)`。

该 Δ 是从粗空间到联合富集空间的精确目标变化。K 包含新增方向之间通过原算子和粗变量消元产生的相互作用。完整细空间上预计算 Schur 矩阵后，任意可行集合取其主子块得到同一 K；这种设置及其全部求解、存储和时间必须收费。无需逐目标精确细伴随求解。

精确粗目标误差为 `e_c=J(u_f)−J(Pu_c)`。主离线 oracle 使用一次精确细主问题求解获得它。对选中集合定义 `F(C)=||(e_c−Δ(C))/s||_2²`。F 的改善必须使用有符号目标变化；不能把正的能量下降或目标变化绝对值直接当成三个目标误差下降。

## 冻结的候选动作与贪心选择

每步候选为所有单个粗方格、所有水平／竖直相邻方格对、所有 2×2 方格块。候选编号顺序为单格行优先、水平相邻对行优先、竖直相邻对行优先、2×2 块行优先。它们与当前已选集合取并集；若没有新增自由度则跳过。候选新增代价为联合空间维数增加量，包括新出现的共享边，不只计算原始补丁中心。只评价代价不超过剩余预算的候选。得到同一新增方格元组（也即同一联合方格集合）的候选只保留编号最小的一个，不增加其选择机会。nc=16 的原始动作目录固定有 961 项：256 个单格、240 个水平对、240 个竖直对、225 个 2×2 块。

主方法 `oracle_coupled` 对每个联合候选 C' 计算其完整 K 子块下的精确 Δ(C')，选择 `(F(C)−F(C'))/(dof(C')−dof(C))` 最大者。实现通过对当前新增方向继续作 Schur 消元，批量评价条件化后的新方向；这是联合公式的代数等价加速，最终必须与从头计算的联合 K 子块结果交叉核验。浮点得分严格相同才按较小候选编号破同分，不以事后调节的容差把近似同分合并。即使最大增益为负，也继续至精确预算或触发预定完成回退；保留全部负增益步骤，不能删除目标误差恶化的样本。它是有限候选族上的贪心路径，不是全局最优网格或可达误差的严格上界。

交互消融 `oracle_uncoupled` 使用相同的动作族、预算、目标误差标签和选择规则，忽略不同选择步骤之间的 Schur 交叉耦合。对候选的新增方向 `D=I(C')\I(C)`，按独立空集公式计算 `δ_j(D)=r_gj[D].T K[D,D]^{-1}r_f[D]`，与之前已选增量的独立 δ 累加后评价预测 F。每个新增方向仅计一次；共享边在其成为独立自由度的那一步计入 D。不能直接累加允许重叠的原始补丁空集收益，那会额外引入重复计算和遗漏跨补丁共享边的问题。该消融的最终结果仍由真实联合适应求解给出，绝不以累加预测代替实际误差。

若贪心路径没有恰好花完 64 且不存在可行候选，保留回退前的全部选择、剩余预算和目标预测，再从两个棋盘奇偶子集中分别按该方法冻结的初始单格分数选 64 个方格，得到两个必定恰好 64 自由度的集合，按该方法自己的预测 F 选择。耦合方法对两个集合计算完整联合 Schur 预测，uncoupled 对每个集合相加初始单格独立变化；棋盘内没有释放的共享边。完全同分时优先偶数奇偶类。记录回退标记、回退前与最终结果，不把预算改小、不丢弃失败样本。正式实现若采用另一种确定性完成机制，必须在首次正式冻结前同步修订本段并进行预算测试。

耦合与相加方法可能沿不同路径产生不同候选增量，因而比较是完整选择策略的比较，不能仅凭末端误差差异认定纯粹的单一因果机制。除主结果外，应报告相加方法所预测的目标变化与最终真实目标变化之差，并报告相同终端集合下精确联合变化与相加预测的差，帮助定位交互忽略的影响。

## 对照与参考信息边界

以下经典指标方法保持第十一阶段实现与名称：一次 `amg_v1`、八步阻尼 `jacobi8`、二次插值 `recovery`，均用相同粗伴随残差、Q 投影、三目标归一化聚合以及精确预算排序器。主要经典对照预先指定为 AMG，廉价对照为 Jacobi8，不逐几何选择最有利对照。`oracle_indicator` 用精确伴随指标及同一指标排序器，直接比较“准确指标加排序”和“准确动作收益加选择”；其细伴随成本不可隐藏。

可部署诊断 `amg_coupled` 使用与主方法相同的耦合动作评价，但把未知 `e_c` 换为一次 AMG V-cycle 对主问题粗残差的修正与三个目标残差配对得到的预测。其尺度仍来自粗解。该方法的输入函数不能接受精确参考解或真实粗误差；参考仅在方法完成后用于评价。它是单独的探索性经典诊断，不替代主 oracle，也不根据测试结果更换 e_c 预测器。

`fine_direct` 直接求解一次细主问题并评价三个目标，没有额外粗层或三次伴随成本。它不匹配 64 自由度预算，单列为准确性和完整成本边界对照。离线 oracle 已经求得细主解，因此即使找到更好的小网格，也不能称它在当前实例上节省了求解工作；其价值只在于诊断是否存在可学习的动作空间。

## 主指标、汇总与继续门槛

最终指标取真实适应主问题求解后的 `E=||(J(u_f)−J(Tu_ad))/s||_2 / ||e_c/s||_2`。保存细、粗、适应三目标值，签名误差、绝对缩放误差范数、每步选择、实际新自由度、负增益步骤、回退、空间哈希及能量误差。多目标以向量范数聚合，不能让不同目标正负抵消。每组 16 个独立几何分别报告中位数、范围和改善数；重复计时不是独立样本。

所有配对比值先在同一几何计算，再跨几何取中位数；不以两个跨几何中位数相除代替。若粗误差缩放范数或经典对照最终缩放误差范数低于 `1e-12`，保留原始数据、将对应比值标为 null，整个正式通过门槛判为不通过，不删除或替换该几何。细直接解的零离散误差不作配对分母。

继续研究动作信息的可达性门槛固定为主候选 `oracle_coupled` 同时满足：

1. ID 与高对比两组，相对 AMG 的逐几何 E 比值中位数均 ≤0.90，每组至少 12/16 个几何严格改善。
2. 两组相对 Jacobi8 的逐几何 E 比值中位数均 ≤1.00。
3. 数值核验全部通过，没有分母退化或预算不一致；主候选所有正式几何均没有触发预算完成回退。回退样本仍完整保留、计算最终误差，但不能用重启棋盘选择的结果通过动作搜索门槛。

10% 与 12/16 是开发决策阈值，不是显著性或发表标准。oracle 的完整成本不进入这个准确性可达性门槛，但必须报告，不得据此声称效率过线。相加消融、精确指标对照和可部署诊断均不替换主候选，不根据其表现改写正式结论。

若门槛不通过，停止在当前动作族、预算及网格下训练 AI 去模仿该 oracle；这不是证明所有网格或动作无效。若通过，仅说明当前动作选择留下准确性空间；下一步需检验参考误差信息的可预测性、动作评估成本、跨实例泛化及相关工作，再决定是否训练学习器。若 `amg_coupled` 已取得同样收益，优先承认经典方案已经利用了这些信息，不能把 oracle 正信号等同于 AI 必要性。

## 数值审计与完整成本

对所有方法核验零边界、悬挂约束、粗空间嵌入、精确 64 自由度、适应线性求解相对残差 ≤`1e-8`、能量误差平方比 ≤`1+1e-8`。作用 Q 的指标方法继续核验粗正交残差 ≤`1e-8`。新增动作公式应在单格、相邻、重叠动作和预算终端集合上，与独立 T 适应求解的目标变化交叉核验，按目标尺度归一化后，目标变化差的二范数除以 `max(norm(实际目标变化/s),1e-12)`，所得相对差 ≤`1e-8`；对称 Schur 子块需正定，Cholesky 失败不得靠无说明正则化掩盖。

CPU 和 BLAS 固定一个线程。每方法每几何从新对象开始进行三次暖运行，每几何建立种子 `53991+geometry` 的随机流，依次生成三次完整方法排列；预热固定几何为 53950，全部八种方法各执行一次，其成本单列。仅供代码检查的烟雾运行使用 ID 53970、高对比 53980，粗网格 8×8、预算 16、每方法一次，不参与正式结论。记录全部重复与中位数，要求重复选择完全一致，目标值满足 `rtol=1e-12, atol=1e-15`。三次重复只用于检查确定性及描述开销，不将微小毫秒差异解释为已证实的速度优势。

每个方法完整收费包括几何和算子／载荷装配、必要粗求解、Schur 矩阵和候选结构构建、所有候选收益评价与搜索、回退、真实约束网格构建、适应装配和主问题重求解、三个目标评价。参考信息由 oracle 自己实际生成并计费；不能免费复用独立评价的细分解。共同设置可在一个方法内共享，不能由先运行的其他方法免费提供。可部署经典方法的评价参考在完整在线计时之外。全局 Schur 设置是本次小网格诊断工具，不声称它能直接扩展至大规模网格。

记录总墙钟时间、完整每几何成本、分阶段成本和候选次数；离线评价、报告与序列化分开。保存源码、协议、配置、环境和全部输入／输出哈希。冻结结果及失败记录不可覆盖；复现命令必须创建新的输出目录。
