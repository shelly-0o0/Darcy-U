# 第六阶段运行前协议：跳变当步复用、预算更新与刷新时机

制定于 2026-11-19，正式诊断和计时之前。本阶段不训练或调用 AI，保持阶段1–5代码、协议、权重和原始结果不变。检验当前系数变化发生后、求解开始前，历史慢方向是否仍有用，以及有限经典更新和刷新时机能否带来完整时间收益。

## 固定算法与预算

沿用二维 Darcy/P1、mixed 系数序列、20步、对比度1e4、恒定右端和齐次 Dirichlet。基础方法为当前 Galerkin AMG 层次刷新、历史四解初值。最终显式相对真残差1e-8，总PCG迭代预算500，最多三次真残差刷新。CPU、BLAS/OMP/MKL单线程，不并行其他训练或求解计时。

事件定义与第五阶段相同：首步或 max|log(k_new/k_old)|≥log(10)。首步无旧空间，必须独立统计，不能算作历史方向的可改善范围。所有回收方法固定输出秩4，事件轨迹最多采集24列已支付 D/AD/MAD。事件PCG均使用固定基础 M；非事件有空间时先做当前A投影，再使用固定平衡B，无空间时退回基础M。普通PCG每次求解内预条件器保持固定，不把BA缓存解释为MA。

预算更新先将旧四列在当前A上正交化为 U/AU，计算 V=M AU，再计算 AV和MAV；候选为 W=[U,V]，缓存为 AW=[AU,AV]、MAW=[V,MAV]。用缓存Ritz提取低端四方向，复用返回AU进行投影，不重复正交化。输入不超过四列时，空间更新至多8次A和8次M向量作用，按列计数；这是空间更新预算，历史初值、初值投影、残差检查及PCG中的额外作用另计于完整时间。更新/提取拒绝全部记录，不调整门槛；更新拒绝时当前事件使用基础初值和M，持久更新方案保留原旧空间供后续步处理。

候选八维空间包含旧空间，但截取四个低端Ritz向量后未必包含旧空间，不能预设右端相关误差或迭代改善。保持真实秩、拒绝、投影保护和失败记录。

## 七组开发对照

1. `baseline_scipy`：所有步原SciPy PCG，无采集/回收。
2. `baseline_event_custom`：事件步新PCG但无采集，其他步原SciPy，无回收。
3. `lagged_balanced4`：第五阶段时机；事件前禁用旧空间，事件结束提取替换，非事件平衡。
4. `event_reuse_refresh4`：非首事件先用旧空间当前A投影，后续PCG仍M；事件结束由新轨迹替换空间。
5. `event_update_refresh4`：非首事件先做一次预算更新，再投影；事件结束由新轨迹替换空间。预算更新仅用于本事件初值。
6. `event_reuse_frozen4`：只在首步采集提取，以后每步重建当前A正交基并投影；非首事件仍新PCG，但关闭采集。非事件仍平衡。
7. `event_update_transport4`：只在首步采集提取；非首事件在当前A/M下预算更新并保留新空间供后续步使用，无事件末轨迹提取。非首事件新PCG关闭采集；非事件平衡。

每条序列独立清空历史、空间和AMG模板。方法顺序按预定种子随机排列。各方法沿自己的数值历史推进，不能声称在线方向或轨迹完全相同。lagged/reuse对照考查使用时机；reuse/update考查有限更新；refresh/frozen/transport考查维护成本与方向陈旧，不把复合变化全部归因于某一组件。

## 几何划分、诊断与冻结

开发从44001起取3个，确认从44011起取5个。完整32网格占据序列哈希排除第五阶段的全部历史排除与使用几何，以及功能检查种子75001/75002，再排除本阶段重复；仅因重复顺延。开发n128，每法两次完整序列，预期840次在线求解。

正式筛选前，在三个开发几何的共同基础轨迹上诊断全部非首事件（本序列预期每几何7个，共21个）。基准历史只来自基础求解，不用参考解驱动。比较上一已完成事件空间、该空间的一次预算更新、首步冻结空间，以及当前已完成轨迹的事后Ritz参考。每个方向均在共同当前A和相同初值下比较一次投影与平衡接口，记录真实残差、迭代、初始误差能量、对当前参考空间的覆盖、实际秩及更新预算。直接参考解只用于计时外诊断。探针中setup、当前轨迹提取、投影、接口构造及求解时间仅为分项记录，历史获取成本未含在setup中，不能作为完整在线成本比较。首步冻结探针不等于在线多次持久更新；当前轨迹探针只是有限24列的事后参考，不是精确慢空间或可实现速度保证。诊断不改善不调整已定算法。

筛选后从第4–7项中，按全开发精度合格、零PCG失败、零整空间缓存/更新拒绝、预算满足且完整序列几何中位时间最小选择一个；即使所有候选慢于基线，仍选择并明确报告。无合格候选则保留负结果并停止确认，不放宽门槛。

确认前冻结全部求解源码、协议、分组、诊断、开发测量及选择哈希。确认固定保留第1–5项，加开发选出的候选并按名称去重，因此每组5或6项。n128另五个几何、n256前两个，各三次完整序列，共2100或2520次确认求解。独立确认几何仍是五个。不得见确认结果再改法或重新选最优。

## 全成本与判断

计时从组装前到空间/历史维护后，包含组装、历史四解初值、AMG刷新、当前空间处理、预算更新、投影、PCG采集及复制、真残差、失败恢复、提取、释放缓存与存储。`update_seconds`为独立组件；`extraction_seconds`是维护子项，不能重复计入总和。直接参考解和能量误差核验只在计时外。全部失败和恢复保留。

每次20步求和→同几何重复中位→跨几何汇总；配对比在几何内算后再汇总。另分首步、非首事件、非事件分别合计，用于解释作用时机，不挑选有利步代替完整时间。两种基线同时报告，以每组总体中位时间选出的同一种最快有效基线作为主比较，不逐几何选不同基线。节省20%仍为工程筛选线，不是显著性或论文录用标准。

若经典复用或更新有效，首先归于经典机制；若仍无完整收益，保留负结果，结合方向失配和更新成本判断是否需要重新定义研究问题。不得从这轮经典实验直接声称AI创新或启动无依据的大规模训练。
