# 第八阶段运行前协议：当前轨迹参考空间的预算筛查与停止规则

制定于2026-11-19，正式生成开发数据和计时之前。本阶段是当前Darcy低秩增强路线的最后一次预算筛查，不训练AI，不改动阶段1–7源码、协议和原始结果。目的不是把事后信息包装为可执行加速，而是判断一类当前系统参考方向在真实应用费用下，是否还值得投入方向预测研究。

## 固定问题与五种方法

保留二维Darcy/P1、mixed序列20步、对比度1e4、固定右端、齐次Dirichlet、当前Galerkin AMG刷新和历史四解初值。CPU、BLAS/OMP/MKL单线程，正式计时不并行其他训练或求解；精度要求为显式相对真残差不超过1e-8，总PCG预算500及最多三次真残差刷新。

固定比较：`baseline_scipy`、`baseline_event_custom`、`frozen_all_balanced4`、`current_reference4`、`current_reference8`。前三种沿用第七阶段实现。后两种每个当前系统读取已预存的q=4或q=8参考空间，重新做当前A正交化、初值投影，再以固定平衡B求解。事件步自实现PCG接收实际B且采集容量为零，非事件使用SciPy PCG；每条方法/重复独立清空历史、AMG与空间，不共享在线求解成果。

只有参考方向的获取费用被单列。参考法的组装、历史初值、AMG刷新、当前正交化、投影、B构造/复制和全部应用、PCG、真残差、失败恢复与维护均计入部署路径时间。计时不得只保留PCG部分。冻结空间对照仍自行支付首步采集与提取，不从参考数据免费获得空间。

## 离线参考生成与质量

每组正式计时之前，先独立整批生成并保存该组全部参考方向，再启动各方法交错计时，不能在某个参考法计时之前紧接着同系统参考求解而只为其预热。方向统一加载到内存后计时，采用数据已驻留口径；文件I/O和离线获取成本单列，不解释为完整在线加速。

参考序列使用基础M和该序列自身过去已求解的四个解。当前系统基础PCG已完成轨迹最多采集64列D/AD/MAD，分别提取四/八个低端Ritz方向。方向使用当前已完成求解的信息，因此整个参考方法不是因果在线算法，不是学习模型，不是最优空间上界。参考方向来自当前右端激发的有限轨迹，不保证覆盖完整系统最慢q维。不得在看到开发结果后增加采集长度、改q或更换来源。

逐系统记录获取费用、采集列数/分段、实际秩、Ritz值和残差；用实际A/M独立核验当前A正交性与MAU−UΛ的A范数相对特征残差，不能只检验小矩阵特征方程。在每条序列固定第0/10步核验缓存AD/MAD与实际算子作用的一致性，Frobenius相对差阈值为1e-7。共同基础历史下，用计时外直接参考解测量当前q4/q8和首步冻结q4的投影后误差能量比例；首步冻结对照由初始缓存前24列提取。直接解不得输入方向构造、初值或在线选择。参考获取费用按同一准备流程汇总，包含两种q和首步冻结参考的提取，不能冒充某一种q的独立可执行获取成本。

质量指标完整保留。实际秩不足q、非有限量、非正Ritz值、正交误差超过1e-7或参考基础PCG失败均不能被降秩、换样本或恢复后隐藏。有限轨迹Ritz特征残差只作描述，不根据结果事后设置阈值；若参考质量有限，失败结论仅适用于本参考，不能证明所有方向没有预算。方向数组可由程序重建，保存文件和逐方向哈希供来源审计，不上传大数组。

## 新几何、预先冻结与门槛

开发从46001起取3个新几何，确认从46011起预留5个新几何。继承第七阶段全部排除/使用种子，另排除功能检查75004；在32网格完整占据序列上检查几何哈希，只因重复顺延，不因性能或失败换样本。

开发使用128网格三个几何、256网格前两个，每方法三次完整重复，共1500条部署路径求解记录，其中当前参考路径600条，另外900条为因果在线对照。参考生成和直接求解另行计数，不混入这1500条。方法顺序由固定种子随机排列。开发开始前保存源码、协议、划分和固定配置哈希；拒绝覆盖已有结果。

先按完整20步求和，再取同几何三重复中位数，最后做几何内配对。两种基础实现都报告，继续门槛固定对SciPy基线，不逐几何挑选基线或参考秩。只有全部方法数值有效、参考质量满足上述结构检查，且**同一个q在两个网格的全部开发几何上，部署路径时间均不超过SciPy的0.8倍**，才进入独立确认；若q4和q8都通过，预定选择q4。小于等于0.8只允许确认，不代表已有可用模型构造预算或统计显著性。

每个几何另报告构造预算 `0.8*T_baseline − T_reference_path`，以及单位系统平均预算。该预算没有包含真实特征构造、模型推理、传输和保护费用；非正值不能支持训练投入，正值也仅是本参考路径的候选预算，须由实际可执行方法验证。

若开发未过门槛：保存完整数据、结构质量和失败原因，写停止决定，不追加q、不换种子、不放松目标、不运行本路线确认或扩大训练；总结七轮及本轮结果，转向新的研究问题。此为资源配置决定，不是无加速可能性的数学证明。

若开发过门槛：冻结开发测量与选择，使用预留确认几何，128五个、256前两个，各五法三重复，共2100条路径记录。同一预选q须再次满足全部几何门槛才允许讨论进一步预算；其他q仅作固定次要对照，不在确认后改选。未通过则停止该路线。即便确认通过，也不将事后参考的时间写成AI或因果在线加速。

## 转向原则

转向调研可与CPU实验独立进行，优先选择AI能够影响主要成本、强经典基线明确、两周可做可证伪筛查的新研究问题。必须核对近期原始论文与作者代码，明确直接近邻；不能把已有网络、网格自适应或求解器选择简单拼接称为新颖框架。新方向的研究提案、未执行试验与已有实验结果明确分开。
