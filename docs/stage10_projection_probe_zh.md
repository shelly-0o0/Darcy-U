# 第十阶段事后诊断：去除预测缺陷中的粗空间分量

本方案在第十阶段正式训练和测试结束、已观察到全局误差矩阵精度与局部标记质量不一致之后制定；以下内容在本诊断运行前写定。它是**事后、零训练、同一测试集上的机制诊断**，不是事前确认实验，不替换正式结构贡献判据，也不把结果当作新的独立验证。

## 问题与固定操作

沿用正式实验的全部 64 个测试 context（四组各 16 个；合计 32 个独立系数几何）、9 个冻结模型及 Jacobi1、Jacobi8、AMG V-cycle 三个经典对照。每个 context 有四个右端，同时充当源项及目标，比较 768 条匹配记录。不得只给学习模型施加处理，不按结果筛选实例、模型、种子或目标。

令细层矩阵为 \(A\)，粗层延拓为 \(P\)，\(A_c=P^TAP\)。对每个当前缺陷预测 \(\widehat\delta\)，只施加固定的 \(A\)-正交补投影

\[
Q=I-PA_c^{-1}P^TA,\qquad
c=(I-Q)\widehat\delta,\qquad
\widehat\delta_Q=Q\widehat\delta.
\]

不修改模型参数、系数特征、粗解、参考标签或目标。真实两层缺陷 \(\delta\) 满足 \(P^TA\delta=0\)，残差 \(r=A\delta\) 满足 \(P^Tr=0\)。因此在精确算术下

\[
r_i^T\widehat\delta_{Q,j}=r_i^T\widehat\delta_j,
\quad
\|\widehat\delta-\delta\|_A^2
-\|\widehat\delta_Q-\delta\|_A^2=\|c\|_A^2.
\]

第一式来自 \(r_i^TP=0\)；第二式来自 \(Q\) 的 \(A\)-正交性及 \(Q\delta=\delta\)。所以该操作按数学构造不改善全局误差矩阵，却可能改变固定单元分解及局部标记。局部标记改善并不由上述恒等式保证。它也不能修复预测在细空间正交补内的剩余误差。

## 固定记录与数值核验

1. 从正式 freeze、complete、训练记录及 checkpoint 加载并核验所有源码、协议、权重和结果哈希；开始前保存本诊断源码、本文档及正式结果引用的哈希，结束时再次核验。重新生成每个 context 一次，检查系数哈希及参考矩阵与正式记录一致。
2. 在 CPU 上重新推理相同权重；保留正式指标与本次投影前指标。CPU/GPU float32 实现允许微小差异，误差矩阵差按参考矩阵范数归一后须不超过 \(10^{-5}\)；本诊断不改写正式记录。诊断比较采用本次同一 CPU 预测的投影前后配对。
3. 逐右端记录投影前误差能量、投影后误差能量、移除粗分量的能量及其占原误差能量的比例；这里的能量均为 \(v^TAv\)，不是其平方根。恒等式差按相关三项的最大值归一，容差 \(10^{-8}\)。同时核验投影后粗正交残差。
4. 比较全局误差矩阵及其主指标、相对能量误差平方、固定源项 0 对四目标的 `marker_mass_ratio` 和局部指标相对 L1 误差。全局矩阵变化相对真矩阵及投影前矩阵均须不超过 \(10^{-8}\)；不以局部改善作为运行完整性门槛。
5. 每个几何内先对三个训练种子取中位，再跨几何取中位。投影前后比值和模型/AMG 比值均先按几何配对后汇总，保留逐几何数据；经典方法没有人为复制成三个独立种子。

## 成本、复现与解释边界

每个 context 仅生成一次，其已有粗矩阵 LU 分解对所有方法和右端复用。每次投影时间包括 \(A\) 乘法、\(P^T\) 限制、已有 LU 的粗求解、\(P\) 延拓及减法；参考数据生成和其中的因子分解另列，模型加载与推理另列。四个右端批处理。这些时间只描述诊断工作量，不能支持在线加速结论：它们没有进行竞争算法端到端成本设计或受控基准计时，且本次参考标签生成会准备缓存。

复现：在安装现有依赖的环境中设置 `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1`，运行 `python stage10_projection_probe.py --self-test`，再运行 `python stage10_projection_probe.py`。默认输出到新目录 `results/stage10_projection_probe`；已有 manifest 时拒绝覆盖。正式训练目录只读。

若粗分量占据较多能量且投影改善局部分布，可将“预测应显式属于细空间正交补”作为下一轮待独立验证的表示假设。若仍明显不及经典 AMG，则剩余的细空间误差、训练目标与局部任务不匹配仍需解释，不直接扩大训练规模。若投影几乎无效，也不推断所有结构方法无效。任何后续训练或 AMR 闭环均须重新冻结方案并使用独立测试数据；本诊断不声称创新、严格连续误差界或期刊可发表性。
