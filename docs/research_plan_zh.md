# 研究计划：高对比扩散方程序列的增量粗空间学习

更新时间：2026-11-19。

本文是实验仓库的研究设计说明。方案、目标和待证明命题不代表已获得的结果。实际运行参数、耗时、误差及失败情况应以本仓库生成的原始结果和运行报告为准；首次小规模试验只能判断可行性，不能证明期刊级创新或统计优势。

## 1. 明确的研究问题

研究单位正方形上的扩散方程：

\[
-\nabla\cdot(k^{(n)}(x)\nabla p^{(n)}(x))=f(x),\qquad
p^{(n)}|_{\partial\Omega}=0,\qquad\Omega=(0,1)^2.
\]

渗透率严格为正，最大值与最小值之比为 \(10^2\) 至 \(10^6\)。序列相邻时刻只有少数区域变化，包含通道连接、堵塞、局部夹杂物移动和系数漂移。

**主问题：能否根据新旧局部系数与已有粗空间，学习缺失的少量低能量方向，在相同离散解精度下，降低整条问题序列的总求解成本？**

网络输出用于更新迭代求解器，不直接替代最终压力解。最终压力由收敛的线性迭代产生。

## 2. 候选算法与创新边界

拟使用小型 U-Net 预测每个局部区域的 2–4 个候选向量。输入为当前对数渗透率、相对上次更新的系数变化、局部坐标、有效节点掩码及旧空间的基变换不变特征。旧空间特征可以首先采用加权投影矩阵的对角信息；该表示会丢失部分空间信息，若效果不足，应研究更完整的表示。

网络输出 \(Y_i\) 后，以确定性投影与正交化去除旧空间已经包含的分量：

\[
\Delta Z_i=\operatorname{orth}_{B_i}[(I-\Pi_{Z_i}^{B_i})Y_i],
\quad
\Pi_{Z_i}^{B_i}=Z_i(Z_i^TB_iZ_i)^{-1}Z_i^TB_i.
\]

已知零模直接提供，数值秩不足的候选向量删除；过大的粗空间需要压缩并重新检查。完整流程是“复用判断 → 候选生成 → 检查 → 必要时传统修复 → 更新粗矩阵 → PCG”。每次 PCG 内预条件器保持固定、对称正定。

候选创新是**旧空间条件下的增量学习与独立接纳检查的组合，以及其在相关 PDE 序列中的端到端收益**。学习粗空间、子空间损失、自适应复用和学习失败后的特征问题回退均已有相关工作，不能单独声明首次；见 [相关工作](related_work_zh.md)。

## 3. 理论研究目标及其限制

对于局部半正定矩阵 \(A_i\)、正定权矩阵 \(B_i\)，希望接纳的空间满足：

\[
\min_{z\in\operatorname{range}(Z_i)}\|v-z\|_{B_i}^2
\leq\gamma_i^{-1}v^TA_iv,\qquad\forall v.
\]

当 \(Z_i\) 满列秩时，它等价于：

\[
A_i-\gamma_i\left[B_i-B_iZ_i(Z_i^TB_iZ_i)^{-1}Z_i^TB_i\right]\succeq0.
\]

局部零空间必须被空间包含或显式消去。普通浮点分解加容差是数值接纳检查，不是经过舍入误差验证的严格认证。随机探针、有限个参考向量上的覆盖误差、有限步平滑误差测试，也不能冒充上述“对所有向量成立”的条件。

若上次通过检查的矩阵满足
\(A_i^{(n)}\succeq\alpha_i A_i^{(s)}\)、
\(B_i^{(n)}\preceq\beta_i B_i^{(s)}\)，
则旧空间的阈值可保守延续为 \(\gamma_i^{(n)}\geq(\alpha_i/\beta_i)\gamma_i^{(s)}\)。应对最近一次直接检查时刻计算比例，避免不断累乘保守界。

从局部性质推导全局 Schwarz 条件数界，还需要 \(B_i\) 与分区拼接能量相匹配、稳定分解、有限重叠等条件。现阶段这是待完成的分析，不能对任意实验中的局部矩阵直接套用。即使迭代次数对对比度稳健，粗空间维数与总时间也未必对对比度无关。

## 4. 数据协议

`fields.py` 的 `coefficient_sequence(N, steps, seed, contrast, family)` 返回系数数组和逐步事件信息。约定 `k[iy, ix]` 为单元渗透率。几何固定生成在 32×32 设计网格上，然后整倍数复制到细网格；因此同一随机种子的 N=64/128/256 表示同一物理几何。

| family | 变化 |
|---|---|
| topology | 中点接通两片通道，四分之三处重新堵断桥 |
| moving | 小夹杂物每三步平移一个设计网格单元，沿短轨道往返 |
| drift | 一小段通道渗透率缓慢变化 |
| mixed | 组合上述变化 |

背景渗透率为 1，高通道为指定对比度；漂移区域可取其间值。几何连接/堵断只指高渗透区域连通性，整个椭圆算子的系数始终严格为正。初始时刻视作全域初始化，之后局部改变通常低于单元总数的 5%。

按完整几何种子划分训练、验证、测试集合，再提取局部块。相邻时刻、同几何的不同分辨率和增强版本不得跨集合。试验配置应保存实际种子列表。

第一阶段用少量序列调通流程；论文阶段建议训练 100 条、验证 20 条、测试至少 30 条，每条约 20 步，根据学习曲线增加训练规模。训练使用 \(10^2\! -\!10^4\)，外推测试 \(10^5、10^6\)。这些是计划规模，不是已完成数量。

## 5. 训练协议

局部参考空间由与求解器一致的广义特征问题产生。训练样本包括当前系数、旧系数、旧空间和当前参考空间。旧空间的来源需包括不同年龄和已有修复轨迹；只用上一步的精确空间训练可能造成部署分布偏差。

优先使用加权子空间覆盖损失，不逐点回归某一特征向量。若输出经过投影后接近零或出现秩退化，应采用稳定的正交化与数值秩处理，并记录丢弃比例。初步网络可用三尺度 U-Net、通道 32/64/128、4 个输出、AdamW；具体参数由验证集选择，不能根据测试集调整。

论文阶段至少三个训练随机种子。报告训练硬件、总训练时间、标签生成时间和验证模型选择规则。首先完成纯监督学习，再依据必要性增加端到端迭代损失。

## 6. 公平对照

| 方法 | 目的 |
|---|---|
| 调优后的 AMG-PCG | 对成熟数值工具的实际价值 |
| 每步完整重建谱空间 | 衡量重建成本 |
| 传统自适应复用与局部特征修复 | 隔离复用策略收益 |
| 平滑误差候选 + 同一检查与回退 | 隔离网络候选方向的收益 |
| U-Net 候选 + 同一检查与回退 | 完整学习方法 |
| 最近邻已有学习粗空间方法 | 论文正式比较，不能仅比传统方法 |

最关键的是平滑误差和 U-Net 共享旧空间、变化检测、候选预算、正交化、检查、回退、粗矩阵求解与停止条件。先比较相同方向预算，再允许各方法独立在验证集调优。所有方法获得相同上一时刻压力作为初值；传统特征更新也允许使用旧基启动。

对不支持相同机制的成熟 AMG，实现上必须解释重新构造或复用策略，报告实际参数，避免把未调优工具当作最强基线。

## 7. 正确性、计时与统计

先验证常系数制造解 \(p=\sin(\pi x)\sin(\pi y)\)，再在高对比小网格上与稀疏直接解对比。区分连续 PDE 离散误差与离散线性系统迭代误差。

主指标为整条序列的壁钟总时间，包含当前实现实际执行的组装、局部更新、正交化、网络、检查、回退、粗矩阵分解、PCG，以及 CPU/GPU 数据传输。残差显式重算；同时报告相对能量误差和时间—误差曲线。

\[
T=T_{\rm assemble}+T_{\rm update}+T_{\rm network}
+T_{\rm check}+T_{\rm fallback}+T_{\rm solve}.
\]

参考解计算与离线训练不混入在线求解时间，但单列报告。若平均每序列在线节省 \(\Delta T>0\)，才有意义计算
\(N_{\rm break-even}=(T_{\rm labels}+T_{\rm train})/\Delta T\)。

固定 CPU 线程数、记录设备和软件版本；正式计时预热后至少重复三次。独立序列为统计单位，报告配对加速比和置信区间，不将相邻时刻当作独立样本。保留全部超时、回退、迭代上限与数值失败。记录网络接受率、修复次数、粗空间维数和最差迭代次数。

## 8. 推进门槛与后续实验

首次本机试验优先回答：实现是否正确；完整更新成本在哪里；检查是否比直接局部特征重建便宜；网络候选是否能独立减少回退或迭代成本。

如果检查与修复吞掉全部节省，应先改进数值算法；如果网络与平滑误差候选没有稳定差异，应保留负结果并调整学习任务。不能用较少迭代次数替代总时间，也不能把普通热启动、复用或硬件差异计为 AI 收益。

可行后扩展到多种右端、多个几何生成器、对比度外推和网格尺度测试。区分增加分区数量和固定分区内网格加密；两者检验不同性质。再完成完整理论及最近邻方法复现，形成论文稿件。
